# exam-solve — 考古題解題流程（五科通用）

每道題產出兩份正本，放在同一個資料夾 `XX/raw/solutions/XX-YYYY-N/`：

| 檔案 | 內容 | 何時定稿 |
|------|------|---------|
| `XX-YYYY-N-problem.md` | **題目正本**：考卷原文逐字、考卷給的公式／附表、附圖、判讀清單。**不寫解法** | 階段一，使用者確認判讀後凍結 |
| `XX-YYYY-N.md` | **解析正本**：三層掃描、VHA、計算、討論 | 階段二，一次一題 |

`XX` 是科目代碼（SS／RC／SA／SD／SM），所有路徑都在 `XX/` 底下。

> 為什麼拆成兩份（2026-11-02 SS-U2-1 試做）：歷次改變答案的勘誤多數是**讀錯題**，而題意過去只寫在解析 §1，從未被單獨驗證。
> 試做 10 題即查出 1 題漏抄題給參數並答錯所求的量（SS-2025-3：題給 $L_p$、$L_r$、$C_b$ 被自行重算，「標稱」強度答成 $\phi_bM_n$），
> 以及 1 題整張附表不在知識庫任何檔案（SS-2021-3 表一）。題意先單獨定稿，解答才有穩固的地基。

本 skill 只管**流程**。下列內容以知識庫內的正本為準，不要憑記憶，也不要在這裡另存一份：

| 要什麼 | 讀哪裡 |
|--------|--------|
| 不可違反的規則（`raw/` 唯讀與例外、verified 不可質疑） | 根目錄或該科 `CLAUDE.md`「重要規則」 |
| 命名、LaTeX 規範、VHA 表格模板、JSON 欄位 | `CLAUDE-SPEC.md` §1.2、§1.4、§2.1、§3.3、§3.4 |
| 子項表、designMethod 允許值、常見圖解、**設計哲學框架** | `XX/SUBJECT.md` §2、§3、§4、§8 |
| 考卷檔名 | `XX/SUBJECT.md` §1 |

> 根目錄 `CLAUDE.md` 規則 1 已把 `-problem.md` 列為例外（2026-11-08 起五科適用）。

## 0. 開始前

1. 確認科目。使用者沒說科目、對話也看不出來時，先問「哪一科？」，不要猜。
2. 讀 `CLAUDE.md`、`CLAUDE-SPEC.md`、`XX/SUBJECT.md`。
3. 確認考卷 `XX/raw/exams/XX-YYYY_<科目名>.pdf` 存在；不存在就請使用者放入，停止。
4. 讀 `XX/raw/json/question_index.json`，找出該年尚無解析（`hasSolution` 不為 true）的題目。已有解析的題目**跳過**，不覆蓋（要改既有解析用 exam-errata；只補題目正本見下方「為既有題目補題目正本」）。

## 階段一：擷取附圖、寫題目正本、請使用者確認（收到「解析 YYYY 年 XX 考卷」後）

判讀錯誤是過去最常見、影響最大的錯誤（SS 勘誤查出「靠桿」讀成「鉸接」、單柱讀成三根柱、尺寸線量錯基準、全深讀成腹板高），
所以本階段的重點是**把考卷寫了什麼、畫了什麼攤開給使用者確認，確認之後才解題**。

1. **讀考卷**：⚠️ 考卷常是 Adobe-CNS1 CID 字型，`pdftotext` 抽不到中文；poppler 缺語言包時連轉圖都會缺字，
   **一律用 PyMuPDF 轉圖**目視閱讀。公式表、附表也常是影像。全頁約 110–150 dpi 盲讀；
   尺寸線端點、支承符號、鉸接圓圈、銲接符號放大到 220–500 dpi 確認。為每道尚無解析的題目建立資料夾 `XX/raw/solutions/XX-YYYY-N/`。
2. **找附圖範圍**（有 `scripts/extract_figure.py` 時）：
   ```
   python scripts/extract_figure.py preview XX/raw/exams/XX-YYYY_<科目名>.pdf --page <頁>
   ```
   產生帶 point 座標格線的預覽圖並回報有無嵌入圖片：沒有 → 向量線條可無損抽取；有 → 記下 ppi，低於 100 ppi 的要特別小心小符號。
   ⚠️ 腳本在使用者電腦上執行時，預覽圖要 stage 到雲端才能看；剛產生的檔案在雲端同步完成前可能 stage 失敗，
   此時改把考卷 PDF 傳到雲端，在雲端跑同一支腳本找 bbox，再回使用者電腦執行 crop。
3. **擷取**（每張附圖一次）：
   ```
   python scripts/extract_figure.py crop <考卷.pdf> --page <頁> --bbox x0 y0 x1 y1 \
       --name XX-YYYY-N-fig-1 --out XX/raw/solutions/XX-YYYY-N
   ```
   - `XX-YYYY-N-fig-1.png`：500 dpi 點陣擷取，**證據圖**，之後不可修改
   - `XX-YYYY-N-fig-1-vector.svg`：向量抽取（附圖為向量線條時才有用；嵌入點陣圖的頁面可加 `--no-vector`）
   - 擷取後**看一次** PNG，確認圖完整、沒有切到符號或混進別題文字；裁歪了就調 bbox 重擷。
   - 設計圖表、曲線圖照樣擷取但**不重繪**（重繪等於自己編數據）。
   - **附表、公式表不擷取成圖，直接在題目正本 §2 照錄成表格／LaTeX**——截圖只截到圖、漏掉同頁附表，是 SS-2021-3 表一失傳的原因。
4. **寫題目正本 `XX-YYYY-N-problem.md`**（先盲讀，不參考任何既有解析；格式見下節）。
   判讀清單逐項列出：結構型式／構件數｜各支承型式（含符號依據：滾輪、鉸圓圈、固定端剖線）｜節點剛接或鉸接｜
   每條尺寸線的數值與**量測基準**｜勁度與斷面｜每個載重的大小、方向、作用點｜兩個平面的邊界是否不同｜
   考卷附的公式與參數定義｜**題目給定、不需自算的參數**（如 $L_p$、$C_b$）｜**每小題實際問什麼量**（標稱或設計、哪一個強度）。
   每項填「圖上／題文依據」與「把握」（確定／不確定）；看不清的一律標**不確定**；
   題目用字的意思（「因數化載重」「塑性極限強度」「彈性彎矩強度」）屬解讀，另標「（解讀）」。
5. **停下來給使用者確認**：輸出各題判讀清單（不確定項目排最前面），等使用者說「判讀確認，請開始解題」。
   使用者修正的項目以使用者為準。確認後：
   - 題目正本頭表「判讀狀態」改 **已確認（日期）**，不確定項的把握欄改「不確定 → 使用者確認」（或填使用者修正後的內容）
   - `question_index.json` 該題 `problemStatus` 設為 `confirmed`（建立時為 `draft`）
6. **重繪**（判讀確認後，用 `struct-diagram`）：依判讀清單寫 `gen_XX-YYYY-N.py`，產生
   `figs/XX-YYYY-N-fig-1-problem.svg`＋2× PNG；圖上的每個支承、尺寸、載重都必須對應清單上的一項。
   另產生「原圖｜重繪」並排對照圖供使用者快速比對（不進 `.md`）。只有設計圖表、或圖本身就是表格時，不重繪。

> 使用者若仍想自己截圖，照舊命名 `XX-YYYY-N-fig-1.png` 放入即可，本階段改為只做第 4–6 步。

### 題目正本格式（`XX-YYYY-N-problem.md`）

```markdown
# XX-YYYY-N 題目正本

> 本檔只記錄**考卷上寫了什麼、圖上畫了什麼**，不含任何解法。解析見同資料夾 `XX-YYYY-N.md`。
> 判讀清單經使用者確認前，狀態為「待確認」；確認後本檔原則上不再修改（改動須回考卷原圖並記 log）。

| 項目 | 內容 |
|------|------|
| 考卷 | `raw/exams/XX-YYYY_<科目名>.pdf` 第 n 頁，第○題 |
| 考年 | 民國 ○ 年（YYYY） |
| 配分 | ○ 分（小題配分） |
| 附圖 | n 張，`XX-YYYY-N-fig-1.png`；證據圖未涵蓋的內容（附表）以 §2 為準 |
| 判讀狀態 | **待確認**（日期 轉錄；轉圖方式與 dpi） |

## 1. 考卷原文（逐字）
> 引用區塊逐字轉錄；符號照考卷寫法，只把數學包成 LaTeX。不改字、不補字、不加詮釋。
> 看不清處寫「〔無法判讀〕」，禁止依題型脈絡補全。

## 2. 考卷給的公式、附表與參數
題內公式、全卷參考公式區、附表全部照錄（附表用 Markdown 表格）；標明哪些屬他題；
「考卷沒給什麼」也寫（例：公式集出現 $M_p$ 但不定義）。無則寫「無（本卷無參考公式區）」。

## 3. 附圖
![精確描述的 alt text](XX-YYYY-N-fig-1.png)
*圖面文字照錄：……*

## 4. 判讀清單
| # | 項目 | 判讀 | 圖上／題文依據 | 把握 |
|---|------|------|---------------|------|

---
*轉錄：日期｜確認：日期 使用者確認*
```

不寫：解法、規範條文、答案。推得的中間量只在必要時註明「推得值」（如腹板淨高）。

### 為既有題目補題目正本

使用者說「為某單元建立題目正本」時：已有解析的題目也照第 1、4、5 步做（盲讀時不開解析），寫完後才逐題比對解析 §1，
列出差異表（一致／重述不完整／讀題錯誤影響答案），交給使用者決定是否用 exam-errata 勘誤。比對結果寫在 `wiki/queries/` 報告，不寫進題目正本。

## 階段二：逐題解析（收到「判讀確認，請開始解題」後）

**一次只解一題**：解完、存檔、更新索引後停止，等使用者說「繼續下一題」。（避免單次輸出超過上限。）

每題的步驟：

1. 讀**已確認的題目正本**：§1 原文、§2 考卷公式與附表、§4 判讀清單。考卷給的**數值參數**優先於設計哲學框架與記憶，
   直接用、不自行重算（如 $L_p$、$L_r$、$C_b$、斷面性質表）；考卷印出的**規範公式、係數、$\phi$、載重組合**則改用現行台灣規範（見下一步）；每小題問的是哪個量（標稱／設計、哪一個強度）以題目正本為準。
2. 解題時的幾何一律以判讀清單為準。
   **規範版本一律用現行最新版台灣規範**（根目錄 `CLAUDE.md`「規範版本」；各科版本見 `XX/SUBJECT.md` §7），不依考卷年份；
   題目指定舊版台灣規範時仍用現行版，§5 註明差異；只有題目明確指定 ACI（RC）或 AISC（SS）時才依題目指定規範。
   照題目用：幾何尺寸、材料強度、載重大小與作用位置、鋼筋規格與面積、斷面性質表，以及題目直接給的數值參數（如 $L_p$、$L_r$、$C_b$、有效預力）；改用現行台灣規範：題目印出的規範公式、係數、強度折減因數 $\phi$、載重組合與載重因數、容許值、規範表格與限制值（考卷印在題目或提示裡也一樣），§5 註明差異並可附照考卷式子的對照值。
3. 做**三層掃描**（下節），再依 `XX/SUBJECT.md` §8 的設計哲學框架決定路徑。
4. 依「解析輸出格式」寫 `.md`，存到 `XX/raw/solutions/XX-YYYY-N/XX-YYYY-N.md`。
5. 計算型題目：**每個數值都用程式算一次**，不要心算或手打；最終答案與程式結果一致才存檔。
6. **圖解（交給 struct-diagram）**：題目內容屬 `XX/SUBJECT.md` §4 的常見圖解類型時（勁度矩陣、反曲點、P-M 曲線、莫爾圓、應變分佈…），
   列出建議畫哪幾張、每張攔下什麼錯，問使用者要不要畫；使用者同意才載入 `struct-diagram` skill 產圖
   （`gen_XX-YYYY-N.py`＋`figs/*.svg/.png`），並把圖插回 `.md` 對應章節。概念說明題通常不需要圖，不要硬畫。
7. 更新 `question_index.json`（見「索引更新」）。
8. 有渲染腳本時（如 `scripts/render_problem_view.py`）重生該題瀏覽頁——題目正本會渲染在解析之前。
9. 跑「完成檢核」，回報結果後停止。

### 三層掃描（解題前先做）

先見林（外在全貌）→ 再見樹（策略路徑）→ 後見土（內在意圖）

```
第一層 外在：[目標] 最後要交出什麼（數字？圖？OK/N.G.？標稱或設計強度？）
             [已知] 題目給的數字與條件（以題目正本 §1、§2 為準）
             [待算] 從已知到目標需要的中間參數（題目已給的不列入）
第二層 策略：[邏輯] 對照 XX/SUBJECT.md §8 的哪一條框架
             [陷阱] 考官可能挖坑的地方（非標準型式、模糊用字、易混觀念）
             [捷徑] 哪些條件可以跳過步驟
第三層 內在：[核心] 本題最重要的一個觀念
             [線索] 特殊用字的暗示（例：「無面外束制」→ 側扭挫屈；「忽略自重」→ 善意簡化）
```
