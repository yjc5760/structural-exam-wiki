# exam-errata — 解析勘誤與重新驗算（五科通用）

修正**已存在**的解析正本 `XX/raw/solutions/XX-YYYY-N/XX-YYYY-N.md`，並讓所有下游跟著一致。
`XX` 是科目代碼（SS／RC／SA／SD／SM），所有路徑都在 `XX/` 底下。

> 授權依據：根目錄 `CLAUDE.md` 規則 1 的「解析勘誤」例外（四個條件缺一不可）。本 skill 是執行那四個條件的標準流程。
> 規則 2 的界線：題目若仍是 `verified`，只有在**使用者明說要勘誤**時才能重算。

## 為什麼要這麼嚴

SS 在 2026-08-22 抽查 7 題，就有 3 題錯誤足以改變答案（43%）：把考卷原文「靠桿」讀成「鉸接」（挫屈載重高估 3 倍）、圖面銲接符號誤判、尺寸線量錯基準。錯誤幾乎都出在**判讀**而不是算術 —— 所以第一步永遠是回考卷看圖。

## 流程（每題）

### 1. 確認範圍
- 題號、科目、使用者指出的疑點（沒有特定疑點就做全面重驗）。
- 讀正本 `.md`、`question_index.json` 該題條目、`XX/SUBJECT.md` §8。

### 2. 回考卷原文判讀（條件 ①）
- 把考卷該題所在頁、**以及最後的參考公式頁**轉成圖：一般 300 dpi；支承符號、鉸接圓圈、尺寸線端點、銲接符號、隱藏線用 450–500 dpi。
- ⚠️ 不可只靠 `pdftotext`：CID 字型抽不到中文，公式表常是影像（SS 有多年「看似零公式」其實是圖片）。
- 逐項核對並記下證據（頁碼、位置）：
  - 題意用字（「靠桿」「有側撐」「均佈的雙向彎矩」這類中心語）
  - 支承條件、邊界在兩個平面是否不同
  - 尺寸線量到哪條線、幾何是否和解析一致
  - 考卷給的公式與參數定義（以考卷為準；若考卷公式本身有誤，照考卷算再於 §5 註明）

### 3. 數值獨立重算（條件 ②）
- 寫一支 Python 腳本，把解析裡**每一個數值**從 L1 給定量重算一次；放在工作目錄，不放進 `raw/`。
- 每個數值做量綱檢查；關鍵結果用第二條路徑交叉驗算（不同公式、邊界代入、簡化極限）。
- 腳本最後印出 `MISMATCHES: n`，列出所有與正本不符的值。**n = 0 才算驗完**；不為 0 就逐項判定是正本錯還是腳本錯。

### 4. 規範層次（需要時）
- 依考卷年份確認適用規範版本；對條文有疑義時回查規範原文，不憑二手資料。
- 現行規範與當年版本不同時，在正本新增或更新 `## 6. 依最新規範對照`（不改變當年答案的判定）。

### 5. 修改正本
- 只改有錯的地方，保留原結構與 §3.5 VHA 格式（`CLAUDE-SPEC.md` §3.4）。
- 頁尾加：`*修正日期：YYYY-MM-DD｜修正內容：…｜驗證方式：…*`

### 6. 同步全部下游（條件 ③）
依序檢查並更新，**有引用到被改數值的地方都要改**：

1. 本題 `*-viz.html`
2. `wiki/problems/XX-YYYY-N.md`（含 H1 摘要）
3. `study/problems-view/XX-YYYY-N.html`
4. `question_index.json`：`verificationStatus` → `unverified`；`tags` 只增不刪（append-only）
5. `study/study-*.html`、`study/lecture-*.html`、`study/formula-given-*.html` 中引用此題數值或結論的段落
6. 全庫 grep 被改的關鍵數值或錯誤觀念，其他題目或 wiki 頁有同樣錯誤的一併列出（不要順手改別題正本，列出來另開勘誤）
7. 最後執行 `python scripts/refresh_dashboard.py XX`

### 7. 記錄（條件 ④）
在 `XX/wiki/log.md` 依該檔慣例加一筆（最新的在最上面），三件事都要寫：

```
## YYYY-MM-DD — 解析勘誤：XX-YYYY-N（…）

**操作類型：** 解析勘誤

### 改了什麼
- 原答 → 新答（含單位）；改動章節

### 為什麼錯
- 錯誤類型：判讀／觀念／算術／規範版本／遺漏檢核
- 證據：考卷第 n 頁、何處（dpi）

### 怎麼驗證
- 腳本重算 n 個數值，MISMATCHES: 0；交叉驗算方式

### 同步的下游
- …
```

影響答案的批次勘誤，另在 `XX/SUBJECT.md` §9 CHANGELOG 加一列摘要。

### 8. 回報使用者

| 題號 | 錯誤類型 | 原答 → 新答 | 證據 | 驗證 |
|------|---------|------------|------|------|

並提醒：該題已退回 `unverified`，請人工複核後說「將 XX-YYYY-N 的 verificationStatus 改為 verified」，再 `ingest`。

## 批次勘誤（某單元或多題）

- 依子項分批，同一批用同一套重算腳本框架，最後合併報告。
- 每題仍逐一完成步驟 2–7；不要先改完全部再一起同步。
- 批次開始前可先跑分診（見下節），把可疑題排在前面。

## 分診：xcheck

```
python scripts/xcheck.py XX -o XX/wiki/queries/xcheck-XX-YYYY-MM-DD.md
```

找出係數不一致、單位制混用、條件式規定寫成絕對規則等可疑處。它只是**分診清單**（實測真陽性率約 1/6），每一筆都要回到步驟 2–3 確認，不可直接據此改正本。

## 不要做的事

- 不看考卷圖就改；只憑記憶或單一參考書改數值
- 只改下游、不改正本（下次 ingest 會被蓋回錯誤）
- 勘誤後保留 `verified`
- 刪除 `wiki/log.md` 舊紀錄或刪除舊 tags
