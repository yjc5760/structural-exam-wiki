## 2. 考題核心精神與出題者意圖 (Core Concepts & Examiner's Intent)

**核心精神：**
連續單向版設計採 **ACI 彎矩係數法**（Moment Coefficient Method）：先由撓度控制決定最小版厚，再計算各關鍵斷面之設計彎矩，確認撓曲鋼筋需求量——此題考點在於「最小鋼量（溫度收縮筋）控制」的識別。

**外支承彎矩係數：**
版與端梁一體澆築（integral with spandrel beam）→ 外支承處係數 $= 1/24$（負彎矩），若外支承為簡支（unrestrained），係數 = 0，但仍需配溫度鋼筋。

**出題者意圖：**
1. 測試 $\ell/24$ 版厚公式（一端連續；$\ell$ 為跨度，不是淨跨）
2. 測試 ACI 彎矩係數法及外支承係數選用
3. 測試溫度收縮筋（$\rho_{min} = 0.0018$）是否控制（通常外支承彎矩小，最小鋼量控制）

## 3. 解題戰略地圖與陷阱分析 (Strategic Roadmap & Trap Analysis)

**作戰計畫：**

```
Step 1：跨度 ℓ = L_cc = 480 cm（查版厚）；淨跨 l_n = L_cc - b_w = 450 cm（彎矩係數）
Step 2：版厚 h_min = ℓ/24（一端連續，外跨控制）→ 取整
Step 3：計算自重、wu（載重因數組合）
Step 4：外支承負彎矩 Mu = wu × l_n²/24（係數法）
Step 5：求 As_flex，比較 As_min = 0.0018 × b × h → 取大者
Step 6：選擇鋼筋間距
```

**關鍵陷阱：**

| # | 陷阱 | 應對策略 |
|---|------|---------|
| 1 | **版厚與彎矩用的跨度不同**：版厚表用跨度 ℓ，彎矩係數法用淨跨 l_n | 現行規範表 7.3.1.1：ℓ＝跨度（一體澆置取中心距）→ h_min = 480/24 = 20 cm；彎矩係數表 6.5.2 才用 l_n |

## 4. 步驟化詳細計算過程 (Step-by-Step Detailed Calculation)

### Part 1：設計版厚

**跨度與淨跨：** 版與梁一體澆置，最小版厚表的跨度 $\ell$ 取支承中心距；彎矩係數法另用淨跨。

$$\ell = L_{cc} = 480\ \text{cm},\qquad l_n = L_{cc} - b_w = 480 - 30 = 450\ \text{cm}$$

**最小版厚（現行規範表 7.3.1.1，一端連續；$f_y = 4200\ \text{kgf/cm}^2$ 修正係數 1.0）：**

$$h_{\min} = \frac{\ell}{24} = \frac{480}{24} = 20\ \text{cm}$$

$$\boxed{h = 20\ \text{cm}}$$

（外跨適用「一端連續」；內跨為「兩端連續」= $\ell/28 = 17.1$ cm < 20 cm，故外跨控制）

---

### Part 2：外支承處撓曲鋼筋

**載重計算：**

$$w_{SW} = 2400\ \text{kgf/m}^3 \times 0.20\ \text{m} = 480\ \text{kgf/m}^2 = 0.480\ \text{tf/m}^2$$

$$w_D = w_{SDL} + w_{SW} = 0.1 + 0.480 = 0.580\ \text{tf/m}^2$$

$$w_u = 1.2\,w_D + 1.6\,w_L = 1.2\times0.580 + 1.6\times0.600 = 0.696 + 0.960 = \boxed{1.656\ \text{tf/m}^2}$$

取 1 m 寬設計帶：$w_u = 1.656\ \text{tf/m} = 16.56\ \text{kgf/cm}$

**驗算 ACI 彎矩係數法適用條件：**
- 跨數 ≥ 2 ✓；各跨相等 ✓；均布載重 ✓
- $w_L/w_D = 0.6/0.580 = 1.03 \leq 3$ ✓

**外支承負彎矩（版與端梁一體澆築，係數 = 1/24）：**

$$M_u = \frac{w_u\,l_n^2}{24} = \frac{16.56 \times 450^2}{24} = \frac{16.56 \times 202{,}500}{24} = \frac{3{,}353{,}400}{24} = \boxed{139{,}725\ \text{kgf·cm/m}}$$

（= 1.397 tf·m/m）

**有效深度（D10 bars，clear cover = 2 cm）：**

$$d = h - c_{cover} - \frac{d_b}{2} = 20 - 2 - \frac{0.96}{2} = 20 - 2 - 0.48 = \boxed{17.52\ \text{cm}}$$

**撓曲設計（$b = 100$ cm per 1 m strip，$\phi = 0.9$）：**

$$R_n = \frac{M_u}{\phi\,b\,d^2} = \frac{139{,}725}{0.9\times100\times(17.52)^2} = \frac{139{,}725}{0.9\times100\times306.95} = \frac{139{,}725}{27{,}626} = 5.06\ \text{kgf/cm}^2$$

$$\rho_{\text{flex}} = \frac{0.85\,f'_c}{f_y}\!\left(1 - \sqrt{1 - \frac{2\,R_n}{0.85\,f'_c}}\right) = \frac{0.85\times280}{4200}\!\left(1 - \sqrt{1 - \frac{2\times5.06}{238}}\right)$$

$$= 0.05667 \times \!\left(1 - \sqrt{0.9575}\right) = 0.05667 \times (1 - 0.9785) = 0.05667 \times 0.02148 = 0.001217$$

$$A_{s,\text{flex}} = \rho_{\text{flex}}\,b\,d = 0.001217 \times 100 \times 17.52 = \boxed{2.13\ \text{cm}^2/\text{m}}$$

**最小鋼筋量（溫度收縮，$f_y = 4200$，SD420）：**

$$A_{s,\min} = \rho_t \times b \times h = 0.0018 \times 100 \times 20 = \boxed{3.60\ \text{cm}^2/\text{m}}$$

$$A_{s,\min} = 3.60 > A_{s,\text{flex}} = 2.13 \quad \Rightarrow \quad \textbf{溫度收縮筋最小量控制}$$

**使用鋼筋量：** $A_s = 3.60\ \text{cm}^2/\text{m}$

**選用鋼筋（D10，$A_b = 0.71\ \text{cm}^2$）：**

$$s = \frac{A_b \times b}{A_s} = \frac{0.71 \times 100}{3.60} = 19.72\ \text{cm} \quad \Rightarrow \quad \text{取} s = 19\ \text{cm}$$

$$A_{s,\text{provided}} = \frac{0.71 \times 100}{19} = 3.74\ \text{cm}^2/\text{m} \geq 3.60\ ✓$$

（D10@20 只有 3.55 cm²/m < 3.60，不足。）

**最大間距驗算：**

$$s_{\max} = \min(3h,\ 45\ \text{cm}) = \min(60,\ 45) = 45\ \text{cm}$$

$$s = 19\ \text{cm} \leq 45\ \text{cm}\ ✓$$

$$\boxed{\text{外支承處頂部撓曲鋼筋：D10@19 cm（}A_s = 3.74\ \text{cm}^2/\text{m}\text{）}}$$

## 5. 關鍵爭議點與進階探討 (Critical Issues & Advanced Discussion)

**① 外支承負彎矩係數：1/24 或 0？**

版規範明確區分：
- 外支承與端梁一體（integral with spandrel beam）→ 係數 **1/24**（需配頂筋）
- 外支承與柱一體 → 係數 **1/16**（較大負彎矩）
- 外支承為簡支（unrestrained）→ 係數 **0**（不需負彎矩筋，但仍需 $A_{s,\min}$ 作為溫度筋）

考場策略：題目說「多跨連續版」且有外支承設計問題 → 通常假設端梁一體，用 **1/24**。若題目明確說「簡支」則係數 = 0。

**② 最小版厚：用跨度 ℓ（20 cm），不是淨跨 ℓn（19 cm）**

現行規範（對應 ACI 318-19）把兩個長度分開定義：$\ell$＝梁或單向版的**跨度**，$\ell_n$＝支承面到支承面的**淨跨**。最小版厚表 7.3.1.1 用 $\ell$；彎矩係數法表 6.5.2 用 $\ell_n$。跨度的取法：與支承非一體澆置者取淨跨加構材深度、但不超過支承中心距；與支承一體澆置的連續構材取中心距。本題版與梁一體澆置，$\ell$＝480 cm → $h_{\min}$＝20 cm。

本庫 2026-11-20 以前的解析用淨跨查表得 $450/24$＝18.75 → 19 cm，並寫「Table 9.5(a) 用淨跨」，與條文符號不符；19 cm 低於規範免算撓度的最小厚度，若採用須另做撓度計算。照舊解 h＝19 cm 的對照：$w_u$＝1.627 tf/m²、$M_u$＝137,295 kgf·cm/m、$A_{s,\min}$＝3.42 cm²/m → D10@20。

**③ 溫度收縮筋控制的工程意義**

外支承負彎矩 $M_u = 1.40\ \text{tf·m/m}$ 遠小於第一內支承 $3.35\ \text{tf·m/m}$。外支承的設計鋼筋量（2.13 cm²/m）小於溫度收縮最小量（3.60 cm²/m），這說明外支承是本版「最不危險」的斷面，溫度裂縫控制是設計驅動力。這在薄版設計中很常見。
