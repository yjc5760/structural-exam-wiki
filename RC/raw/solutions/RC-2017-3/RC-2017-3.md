## 2. 考題核心精神與出題者意圖 (Core Concepts & Examiner's Intent)

**核心觀念：** 方形基腳的設計哲學是「倒置懸臂梁」——柱傳來的集中力透過基腳底板向四周懸挑，底部向上的土壓力為均佈載重，臨界設計截面在柱面（彎矩）與距柱面 $d/2$（穿孔剪力）、距柱面 $d$（單向剪力）處。

**出題者測試重點：**
1. 能否正確區分「服務載重驗地基」vs「因數載重驗混凝土」
2. 穿孔剪力臨界周長 $b_o$ 的計算與三公式取最小
3. 設計有效深度 $d$ 的合理假設

**現行規範（建築物混凝土結構設計規範 2023）要點：**
- 基腳無剪力筋 → 單向剪力 $V_c=2.12\lambda_s\lambda\rho_w^{1/3}\sqrt{f'_c}b_wd$（$\le1.33\lambda\sqrt{f'_c}b_wd$）
- 雙向剪力 $v_c=\lambda_s\lambda\sqrt{f'_c}\min\{1.06,\ 0.53(1+2/\beta),\ 0.265(2+\alpha_sd/b_o)\}$
- 獨立基腳的單向與雙向剪力**可忽略 $\lambda_s$（取 1.0）**（規範 13.2.6.2，同 ACI 318-19 13.2.6.2）

## 3. 解題戰略地圖與陷阱分析 (Strategic Roadmap & Trap Analysis)

**作戰計畫：**
1. 假設有效深度 $d$（根據 $h=80\text{ cm}$、保護層、鋼筋尺寸）
2. 地基驗核（服務載重）
3. 因數載重 $P_u$、淨因數土壓力 $q_u$
4. 彎矩設計（臨界截面：柱面）→ $A_s$ → 選筋
5. 單向剪力驗核（臨界截面：距柱面 $d$；用所選配筋的 $\rho_w$）
6. 雙向穿孔剪力驗核（臨界截面：距柱面 $d/2$）

**關鍵陷阱：**

| # | 陷阱 | 正確做法 |
|---|------|---------|
| 1 | **服務/因數載重混用**：用因數載重驗地基、用服務載重設計混凝土 | 地基用 $P_D+P_L=300\text{ tf}$；混凝土用 $P_u=408\text{ tf}$ |
| 2 | **穿孔剪力臨界面位置**：放在柱面 | 距柱面 $d/2$ 處 → $b_o = 4(c+d)$ |
| 3 | **彎矩臨界截面位置**：放在柱中心 | 在柱**面**（不是柱中心） |
| 4 | **$d$ 進位**：71.23 進位成 72 | 雙向剪力取兩向平均 $d$（69.96），且只可往保守方向取整；本題穿孔剪力結論對 $d$ 很敏感 |

## 3.5 變數層次分析 (Variable Hierarchy Analysis)

### 最終目標
`求 As（底版鋼筋量），驗核 φVc ≥ Vu（單向剪力 + 穿孔剪力）`

### 本題關鍵公式（依計算順序）

> $\boxed{\cdot}$ = 需由前步驟推導，非題目直接給定的變數

$$\text{Step 1: } d = h - \text{cover} - d_b \;(\text{兩向平均}) = 69.96\text{ cm}$$

$$\text{Step 2: } P_u = 1.2P_D + 1.6P_L \quad\Rightarrow\quad q_u = \frac{\boxed{P_u}}{B^2}$$

$$\text{Step 3（彎矩）: } M_u = q_u \cdot B \cdot \frac{L^2}{2},\quad L = \frac{B-c}{2}$$

$$\text{Step 5（單向剪力）: } V_{u,1} = \boxed{q_u} \cdot B \cdot \left(\frac{B-c}{2}-d\right) \leq \phi V_c = \phi \cdot 2.12\lambda_s\,\boxed{\rho_w}^{1/3}\sqrt{f'_c}\,b_w d\quad(\lambda_s=1)$$

## 4. 步驟化詳細計算過程 (Step-by-Step Detailed Calculation)

### 【前置】材料參數

$$f'_c = 210\text{ kgf/cm}^2,\quad f_y = 4{,}200\text{ kgf/cm}^2\ (\text{假設}),\quad \beta_1 = 0.85 \quad (f'_c \leq 280)$$

$$\phi_{\text{flex}} = 0.9 \text{（拉力控制，待驗）},\quad \phi_{\text{shear}} = 0.75$$

---

### 【Step 1】有效深度假設

基腳與土壤接觸面之保護層：$7.5\text{ cm}$。採用 D25 鋼筋（$d_b = 2.54\text{ cm}$）兩向疊放：

$$d_{\text{下層}} = 80 - 7.5 - 1.27 = 71.23\text{ cm},\qquad d_{\text{上層}} = 71.23 - 2.54 = 68.69\text{ cm}$$

$$\boxed{d = \frac{71.23+68.69}{2} = 69.96\text{ cm}}\quad(\text{兩向平均，彎矩與剪力皆採用})$$

> 📝 **策略註解：** 題目未給 $d$ 時，明列假設並取保守值；不可把 71.23 進位成 72（偏不保守，且本題穿孔剪力結論對 $d$ 敏感，見 §5）。

---

### 【Step 2】地基承載力驗核（服務載重）

$$P_{\text{service}} = P_D + P_L = 180 + 120 = 300\text{ tf}$$

$$W_f = 4.0\times4.0\times0.80\times2.4 = 30.72\text{ tf},\qquad W_s = 4.0\times4.0\times1.00\times1.9 = 30.40\text{ tf}$$

$$q = \frac{300 + 30.72 + 30.40}{4.0\times4.0} = \frac{361.12}{16} = \boxed{22.57\text{ tf/m}^2} < q_a = 30\text{ tf/m}^2 \quad \checkmark$$

（等價寫法：淨承載力 $30-(0.8\times2.4+1.0\times1.9)=26.18$ tf/m²，需面積 $300/26.18=11.46\text{ m}^2\le16$ ✓）

---

### 【Step 3】因數載重與淨因數土壓力

$$P_u = 1.2P_D + 1.6P_L = 1.2\times180 + 1.6\times120 = 216 + 192 = \boxed{408\text{ tf}}$$

$$q_u = \frac{P_u}{B^2} = \frac{408}{4.0\times4.0} = \boxed{25.5\text{ tf/m}^2 = 2.55\text{ kgf/cm}^2}$$

---

### 【Step 4】彎矩設計（臨界截面：柱面）

**懸臂長度：**
$$L = \frac{B - c}{2} = \frac{400 - 45}{2} = 177.5\text{ cm}$$

**因數化彎矩：**
$$M_u = q_u \times B \times \frac{L^2}{2} = 2.55 \times 400 \times \frac{177.5^2}{2} = 16{,}068{,}000\text{ kgf·cm} = \boxed{160.68\text{ tf·m}}$$

**求所需 $A_s$**（$M_u=\phi A_sf_y\left(d-\dfrac{A_sf_y}{1.7f'_cB}\right)$ 解二次式）：

$$\frac{0.9\times4200^2}{1.7\times210\times400}A_s^2 - 0.9\times4200\times69.96\,A_s + 16{,}068{,}000 = 0$$

$$\boxed{A_{s,req} = 62.40\text{ cm}^2\ (\text{每向})}$$

驗算：$a=62.40\times4200/(0.85\times210\times400)=3.67$ cm，$0.9\times62.40\times4200\times(69.96-1.84)=160.68$ tf·m ✓

**最小鋼筋量（版、基腳 $0.0018A_g$）：**
$$A_{s,\min} = 0.0018\times400\times80 = 57.6\text{ cm}^2 < 62.40\text{ cm}^2 \quad \checkmark$$

**鋼筋選配（各方向）：** D25（$A_b = 5.067\text{ cm}^2$）

$$n = \left\lceil\frac{62.40}{5.067}\right\rceil = 13\text{ 支},\qquad s = \frac{400 - 2\times7.5 - 2.54}{13 - 1} = 31.9\text{ cm}$$

$$A_{s,\text{prov}} = 13\times5.067 = 65.87\text{ cm}^2$$

**延性確認：** $a=65.87\times4200/71{,}400=3.87$ cm，$c=4.56$ cm，$\varepsilon_t=0.003\times(69.96-4.56)/4.56=0.043\ge0.005$ → $\phi=0.9$ ✓

> **∴ 底版配筋：各方向 $\boxed{13\text{-D25}\ (\text{中心距約 }31.9\text{ cm})}$，$A_s = 65.87\text{ cm}^2 \ge 62.40\text{ cm}^2$**

---

### 【Step 5】單向剪力強度驗核（臨界截面：距柱面 $d$）

$$L_{\text{crit,1}} = \frac{B-c}{2} - d = 177.5 - 69.96 = 107.54\text{ cm}$$

$$V_{u,1} = q_u \times B \times L_{\text{crit,1}} = 2.55\times400\times107.54 = \boxed{109.69\text{ tf}}$$

**混凝土剪力強度**（現行規範表 22.5.5.1，基腳無剪力筋；$\lambda$＝1；依 13.2.6.2 取 $\lambda_s$＝1）：

$$\rho_w = \frac{65.87}{400\times69.96} = 0.002354,\qquad \rho_w^{1/3}=0.1330$$

$$V_c = 2.12\times1.0\times0.1330\times\sqrt{210}\times400\times69.96 = 114{,}360\text{ kgf}$$

$$\phi V_c = 0.75\times114.36 = \boxed{85.77\text{ tf}} < V_{u,1} = 109.69\text{ tf} \quad \boxed{\times\ \text{單向剪力不足}}$$

---

### 【Step 6】穿孔剪力（雙向衝剪）強度驗核（臨界截面：距柱面 $d/2$）

$$b_o = 4(c + d) = 4\times(45 + 69.96) = \boxed{459.84\text{ cm}}$$

$$V_{u,2} = q_u\times\bigl[B^2 - (c+d)^2\bigr] = 25.5\times(16 - 1.1496^2) = \boxed{374.30\text{ tf}}$$

**穿孔剪力強度**（$\beta = 1$，$\alpha_s = 40$，$\lambda_s$＝1，係數三式取最小）：

| 式 | 係數 |
|------|:----------:|
| $0.53(1+2/\beta)$ | 1.59 |
| $0.265(2+\alpha_sd/b_o)=0.265(2+40\times69.96/459.84)$ | 2.14 |
| $1.06$ | **1.06 ← 控制** |

$$\phi V_c = 0.75\times1.06\times\sqrt{210}\times459.84\times69.96 = \boxed{370.62\text{ tf}} < V_{u,2} = 374.30\text{ tf} \quad \boxed{\times\ \text{穿孔剪力略不足}}$$

（$V_u/\phi V_c$＝1.010，不足 1%。）

---

### 【結論】

| 驗核項目 | 需求 | 供給 | 結果 |
|---------|------|------|:----:|
| 地基承載力 | $q = 22.57\text{ tf/m}^2$ | $q_a = 30\text{ tf/m}^2$ | ✅ 合格 |
| 底版鋼筋（各方向） | $A_s = 62.40\text{ cm}^2$ | **13-D25**（$65.87\text{ cm}^2$） | ✅ $\phi M_n \geq M_u$ |
| 單向剪力 | $V_u = 109.69\text{ tf}$ | $\phi V_c = 85.77\text{ tf}$ | ❌ 不足 |
| 穿孔（雙向）剪力 | $V_u = 374.30\text{ tf}$ | $\phi V_c = 370.62\text{ tf}$ | ❌ 略不足（1%） |

$$\boxed{\text{彎矩鋼筋：每向 }A_s=62.40\text{ cm}^2\ (13\text{-D25})；\ \text{依現行規範單向與穿孔剪力皆不足}}$$

## 5. 關鍵爭議點與進階探討 (Critical Issues & Advanced Discussion)

**爭議1：規範版本對照（考卷指定土木 401-100、印出 $V_c=0.53\sqrt{f'_c}b_wd$）**

| 項目 | 舊式（考卷印出／401-100，$d$＝69.96） | 現行規範主線（$\lambda_s$＝1） | 若計入 $\lambda_s$＝0.7256 |
|------|------|------|------|
| 單向 $\phi V_c$ | $0.75\times0.53\sqrt{f'_c}b_wd$＝161.2 tf ✓ | 85.77 tf ✗ | 62.24 tf ✗ |
| 雙向 $\phi V_c$ | 370.62 tf ✗（舊式與主線同式） | 370.62 tf ✗ | 268.94 tf ✗ |

- 舊解以 $d$＝72（71.23 進位）得單向 166.0 ≥ 107.6、穿孔 388.5 ≥ 373.1，結論「均符合」；單向剪力依舊式確實充足，現行式因 $\rho_w^{1/3}$ 降為 85.77 tf 而不足。
- $\lambda_s=\sqrt{2/(1+0.04d)}$；規範 13.2.6.2（同 ACI 318-19 13.2.6.2）允許獨立基腳忽略 $\lambda_s$，若保守計入則不足更多。

**爭議2：穿孔剪力對 $d$ 的敏感度（$\lambda_s$＝1，1.06 式）**
