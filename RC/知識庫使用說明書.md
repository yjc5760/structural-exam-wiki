## 2. 核心工作流程

```
【解析新考題】（exam-solve skill）
  對 Cowork 說：「解析 XXXX 年 RC 考卷」
    ↓ Cowork 建立題目資料夾、從考卷擷取附圖、寫題目正本 RC-YYYY-N-problem.md（考卷原文＋判讀清單）
  你檢查判讀清單（尤其標「不確定」的項目）
    ↓
  告知 Cowork：「判讀確認，請開始解題」
    ↓ Cowork 一次解一題，存 .md 檔（含 LaTeX 公式）
  你驗算後對 Cowork 說：「將 RC-XXXX-N 的 verificationStatus 改為 verified」

【為既有題目補題目正本】（exam-problem-split skill）
  對 Cowork 說：「RC 題目正本 第 n 批」

【新增方法】
  對 Cowork 說：「add method [方法名]」（只寫 raw/solutions/methods/）

【複習查詢】
  直接向 Cowork 提問，或開 index.html、study/ 講義
```

> **所有操作都對 Cowork 說即可，不需要終端機。**

## 3. Cowork 指令速查

完整說明見根目錄 [CLAUDE-CODE.md](../CLAUDE-CODE.md)。

### 3.1 解題與 raw 資料維護

| 觸發語句 | 功能 |
|---------|------|
| `解析 XXXX 年 RC 考卷` | 建立題目資料夾、擷取附圖、寫題目正本待確認（exam-solve） |
| `判讀確認，請開始解題` | 題目正本凍結，一次解一題 |
| `勘誤 RC-XXXX-N` | 回考卷重判、重算、同步下游（exam-errata） |
| `繼續下一題` | 觸發解析同一份考卷的下一題 |
| `將 RC-XXXX-N 的 verificationStatus 改為 verified` | 人工驗算通過後標記 |
| `將 RC-XXXX-N 的 verificationStatus 改為 needs-review` | 發現錯誤時標記 |

### 3.2 知識庫維護（ingest／compile／lint／add concept 已隨 2026-11-01 wiki 封存停用）

| 觸發語句 | 功能 |
|---------|------|
| `status RC` | 驗證進度統計 |
| `reindex` | 修正 hasSolution 不一致 |
| `add method [名稱]` | 新增解題方法論（raw/solutions/methods/） |
| `更新儀表板資料` | ⚠️ RC 目前暫用原 repo 儀表板，改回共用樣板前不要執行（見 `SUBJECT.md` §10） |

### 3.3 備考分析類

| 觸發語句 | 功能 | 輸出 |
|---------|------|------|
| `frequency` | 統計各考點歷年出現次數 | 對話回覆；全科熱圖見 `study/frequency-RC.html` |
| `analyze YYYY` | 深度分析某一年考卷的考點分布 | 對話回覆 |
| `predict` | 根據歷年頻率推測最可能出現的考點 | 對話回覆 |
| `study RC-UN-n` | 子項單元總覽（考什麼＋公式給／背＋考題總表，unit-overview skill） | `study/unit-RC-UN-n.html` |

### 3.4 查詢快捷類

| 觸發語句 | 功能 |
|---------|------|
| `find [關鍵字]` | 搜尋含某關鍵字的題目 |
| `related RC-XXXX-N` | 找出與某題考點相似的其他題目 |
| `unverified` | 列出所有有解析但尚未驗算的題目 |
| 直接提問 | 自由查詢知識庫 |

## 5. 常見問題

**Q：解析 .md 放在哪裡？**
- 原始來源（唯讀，例外見根目錄規則 1）：`raw/solutions/RC-XXXX-N/RC-XXXX-N.md`
- 題目瀏覽頁：`study/problems-view/RC-XXXX-N.html`（舊 `wiki/problems/` 已封存）

**Q：如何更正已 verified 的答案？**
對 Cowork 說「勘誤 RC-XXXX-N」→ 回考卷重判、重算、改正本、同步下游，`verificationStatus` 退回 `unverified`，在 `wiki/queries/log.md` 記錄；你複核後再改回 verified。

**Q：截圖要怎麼命名？**

| 類型碼 | 內容 | 範例 |
|--------|------|------|
| `fig` | 題目附圖 | `RC-2018-1-fig-1.png` |
| `chart` | 設計圖表截圖 | `RC-2018-1-chart-1.png` |
| `eqn` | 公式截圖 | `RC-2018-1-eqn-1.png` |
| `hand` | 手寫補充 | `RC-2018-1-hand-1.png` |

**Q：目前解析進度？**
對 Cowork 說 `status RC` 即可取得最新統計。
