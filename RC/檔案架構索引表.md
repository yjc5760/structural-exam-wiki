## 二、資料夾結構

```
RC/
├── SUBJECT.md               ← 科目層設定（子項表、設計法、標籤詞彙、解題邏輯、CHANGELOG）
├── README.md                ← 冷啟動導覽
├── 知識庫使用說明書.md
├── index.html               ← 離線儀表板（暫用原 repo 版）
├── dashboard-data.js        ← 儀表板資料快照（RC_*）
├── scripts/                 ← RC 專屬腳本：gen_lecture_RC-*_figs.py（講義附圖）、apply_figs.py（2026-10 一次性插圖）
├── 影片講義/                 ← 影片圖文講義（img/、video/）
├── 解題過程影片/             ← 本機影片（.gitignore，不進 repo）
│
├── study/                   ← 單元總覽、觀念講義、頻率熱圖、轉址頁、problems-view/、data/、assets/katex/
│
├── raw/
│   ├── exams/               ← RC-YYYY_鋼筋混凝土設計與預力.pdf（24份）
│   ├── json/
│   │   ├── question_index.json   ← 題目總索引 ✏️
│   │   ├── concepts.json         ← 概念定義（備查）
│   │   ├── syllabus_taxonomy.json ← 命題大綱分類樹（副本，正本在根目錄）
│   │   └── pdf_*.txt             ← 考卷文字抽取（備查）
│   └── solutions/
│       ├── RC-YYYY-N/       ← 解析、考卷附圖、figs/
│       └── methods/         ← 解題方法論文件 ✏️
│
├── wiki/
│   └── queries/             ← 查詢結果、稽核／複核報告、log.md（變更紀錄）
│
└── archive/
    ├── wiki/                ← 2026-11-01 封存的舊 wiki 各層（唯讀）
    └── exam-wiki-RC-root/   ← 搬入前原 repo 根目錄的 CLAUDE*.md、xcheck.py、知識圖譜（唯讀參考）
```

> 共用腳本（render_problem_view、build_unit_page、build_frequency、xcheck、audit_classification…）在知識庫根目錄 `scripts/`。
