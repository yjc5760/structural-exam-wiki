§0 全景：偏心是一個「窗口」，不是一個值

一句話：偏心太大，傳遞時（預力最大、載重最小）頂纖維被拉裂；偏心太小，使用時（預力最小、載重最大）底纖維被拉裂。
上限看最輕的時刻，下限看最重的時刻——兩個時刻之間夾出的那一段，就是可以放鋼腱的窗口。

U4-1 教的是「給你預力和偏心，算應力」；U4-2 把問題倒過來：「給你載重，問預力和偏心該怎麼選」。 倒過來之後，問題的本質變成一組不等式——同一條應力疊加式，在兩個階段、兩根纖維各寫一次， 四條不等式的交集就是答案。本單元 5 題主考點裡，2010-4、2015-4、2025-4 三題直接考這個窗口。

另外兩題（2020-4、2024-4）換成超靜定梁，多出一件簡支梁沒有的事：支承會把預力的偏心「改寫」。 在簡支梁，鋼腱放在哪裡，預力的合力就在哪裡；在連續梁或受撐懸臂梁，多餘支承產生的二次反力會讓合力（壓力線、C 線）偏離鋼腱。 §6 會說明這件事為什麼只在超靜定結構發生。

圖 0　RC-2010-4 跨中斷面兩種極端配置（應力壓為正、畫向右）。左：鋼腱放在上限 \(e=34.71\) cm，傳遞階段頂纖維剛好達到容許拉應力 \(-0.8\sqrt{f'_{ci}}=-13.39\)；右：放在下限 \(e=12.83\) cm，使用階段底纖維剛好達到 U 類限值 \(-2.0\sqrt{f'_c}=-37.42\) kgf/cm²。 這張圖攔的錯：以為「偏心越大越好」——偏心大對使用階段有利，但傳遞時沒有活載重幫忙，頂纖維先被拉裂。
為什麼是對角線兩端？ 預力隨時間變小（損失），載重隨時間變大（活載重上來）。傳遞階段是「預力最大 × 載重最小」，使用階段是「預力最小 × 載重最大」。 鋼腱在形心下方，所以預力的偏心彎矩讓頂纖維受拉、底纖維受壓；外載重的彎矩正好相反。 傳遞時預力的彎矩佔上風 → 頂纖維危險；使用時載重的彎矩佔上風 → 底纖維危險。這和 U4-1 §0 是同一句話，只是現在拿來反推 \(e\)。

§1 四控制條件：一條式子寫四次

這一節在怕的是：四條不等式列錯一條、或兩邊符號弄反，整個窗口就跑掉。解法是把四條都從同一條應力式寫出來，不要背四個結果。

1.1 從應力式出發

矩形斷面、鋼腱在形心下方 \(e\)（向下為正），應力以壓為正：

$$f_t=\frac{P}{A}-\frac{Pe}{S}+\frac{M}{S},\qquad f_b=\frac{P}{A}+\frac{Pe}{S}-\frac{M}{S}$$

把「傳遞（\(P_i\)、\(M_G\)）」與「使用（\(P_e=\eta P_i\)、\(M_T=M_G+M_L\)）」各代一次，並分別要求「不低於容許拉應力」「不高於容許壓應力」：

#階段 × 纖維怕什麼不等式解出
①傳遞 × 頂頂被拉裂\(\dfrac{P_i}{A}-\dfrac{P_ie}{S}+\dfrac{M_G}{S}\ge-f_{ti}\)\(e\le k+\dfrac{M_G+f_{ti}S}{P_i}\)（上限）
②傳遞 × 底底被壓壞\(\dfrac{P_i}{A}+\dfrac{P_ie}{S}-\dfrac{M_G}{S}\le f_{ci}\)\(e\le -k+\dfrac{f_{ci}S+M_G}{P_i}\)（上限）
③使用 × 底底被拉裂\(\dfrac{P_e}{A}+\dfrac{P_ee}{S}-\dfrac{M_T}{S}\ge-f_t\)\(e\ge -k+\dfrac{M_T-f_tS}{P_e}\)（下限）
④使用 × 頂頂被壓壞\(\dfrac{P_e}{A}-\dfrac{P_ee}{S}+\dfrac{M_T}{S}\le f_c\)\(e\ge k+\dfrac{M_T-f_cS}{P_e}\)（下限）

其中 \(k=S/A=h/6\) 是矩形斷面的核心距。極限檢查：令 \(M_G=f_{ti}=0\)，① 變成 \(e\le k\)——沒有任何彎矩幫忙時，預力必須落在核心內才不會讓頂纖維受拉，這正是核心距的定義。

為什麼控制的幾乎總是 ① 與 ③？ ② 與 ④ 是壓應力條件，容許壓應力（\(0.60f'_{ci}\)、\(0.60f'_c\)）比容許拉應力大一個數量級，所以壓應力那兩條的界線離得很遠。 2010-4 的 ② 給 \(e\le56.89\)、④ 給 \(e\ge-25.70\)，都遠在窗口之外；2025-4 的 ② 給 \(e\le82.53\)，連斷面都放不下。 要記的是「拉應力兩條定窗口，壓應力兩條列出來、但通常不控制」。
圖 1　RC-2010-4 的可行區（橫軸 \(P_i\)，縱軸跨中偏心 \(e\)）。四條曲線由 §1.1 表中的四個解直接取點畫出；灰色是可行區，紅色豎線是題目給的 \(P_i=200\) tf，與可行區相交得 \(12.83\le e\le34.71\) cm。 這張圖攔的錯：把 ② 或 ④ 當成控制條件。另外看得出預力越大，上限 ① 越往下壓、下限 ③ 越往下放——預力太大時窗口反而被傳遞階段卡住。

1.2 RC-2010-4、RC-2025-4：同一題考兩次

題目條件（RC-2010-4）：簡支 \(l=15\) m，矩形 50×90 cm，\(P_i=200\) tf、\(f_{pe}/f_{pi}=0.85\)，\(f'_{ci}=280\)、\(f'_c=350\) kgf/cm²，活載 1.5 tf/m，另有自重（單位重考卷沒給，假設 2.4 tf/m³）。
斷面與彎矩：\(A=4500\) cm²、\(S=67{,}500\) cm³、\(k=15\) cm；\(M_G=30.375\)、\(M_L=42.19\) tf·m。
容許應力（現行規範、kgf 制）：\(f_{ti}=0.8\sqrt{280}=13.39\)、\(f_{ci}=0.60\times280=168\)、\(f_t=2.0\sqrt{350}=37.42\)（U 類）、\(f_c=0.60\times350=210\)。
四條件：① \(e\le34.71\)　② \(e\le56.89\)　③ \(e\ge12.83\)　④ \(e\ge-25.70\)　→ \(12.83\le e\le34.71\) cm（幾何上 \(e\le45-10=35\) cm，放得下）。

RC-2025-4 是同一個模子：\(P_i=200\) tf、\(f_{pe}/f_{pi}=0.85\)、活載 1.5 tf/m 都相同，只換成 \(l=12\) m、40×120 cm、\(f'_{ci}=320\)、\(f'_c=420\)。 算得 \(S=96{,}000\) cm³、\(k=20\) cm、\(M_G=20.74\) tf·m，① \(e\le37.24\)、③ \(e\ge-15.07\)，窗口 \(-15.07\le e\le37.24\) cm。 下限是負的，意思是：這根梁很深（\(h=120\) cm）、載重不大，即使把鋼腱放到形心上方 15 cm，使用階段底纖維仍在 U 類以內。負偏心不是算錯。

陷阱：題目沒說自重，就不算自重。 觸發信號：2025-4 題文只寫「承受均布活載重 1.5 tf/m」。錯誤思維：題目沒提就忽略。正確認知：自重恆存在，而且傳遞階段就是靠 \(M_G\) 抵銷偏心彎矩——漏掉 \(M_G\)，上限 ① 會少 \(M_G/P_i=10.4\) cm。單位重沒給就寫「假設 2.4 tf/m³」。（2010-4 題文寫「除自重外」，比較明白。）

因果鏈：預力大、載重小（傳遞）→ 頂纖維受拉 → 偏心上限 ①；預力小、載重大（使用）→ 底纖維受拉 → 偏心下限 ③；壓應力兩條通常很遠 → 窗口 = [③, ①] → 再檢查幾何放得下。

§2 容許應力：每個係數都有出處

這一節在怕的是：考卷不給容許應力（2010-4、2025-4 都沒給），而你背不出來或背錯單位。背不出來時，記住每個係數「在防什麼」就能自己重建。

位置現行規範（kgf/cm²）SI 原式（MPa）在防什麼
傳遞 壓\(0.60f'_{ci}\)（簡支端部 \(0.70f'_{ci}\)）同左混凝土剛硬化、強度只有 \(f'_{ci}\)，壓應力過高會產生非線性潛變與微裂縫；端部沒有自重彎矩，但也沒有後續載重，所以略放寬
傳遞 拉\(0.8\sqrt{f'_{ci}}\)（簡支端部 \(1.6\sqrt{f'_{ci}}\)）\(0.25\sqrt{f'_{ci}}\)（端部 \(0.50\sqrt{f'_{ci}}\)）不讓頂纖維開裂；超過時規範要求配置輔助鋼筋承擔拉力
使用 壓\(0.45f'_c\)（持續載重）／\(0.60f'_c\)（全部載重）同左持續應力超過約 \(0.45f'_c\) 後潛變不再與應力成正比；短暫的全部載重可放寬到 \(0.60f'_c\)
使用 拉U 類 \(\le 2.0\sqrt{f'_c}\)；T 類 \(2.0\sim3.2\sqrt{f'_c}\)；C 類 \(\gt 3.2\sqrt{f'_c}\)U \(\le0.62\sqrt{f'_c}\)；T \(\le1.0\sqrt{f'_c}\)U 類＝未開裂，可用全斷面性質；T 類＝過渡；C 類＝已開裂，要用開裂斷面算應力與裂縫控制
kgf 制係數為什麼是 SI 的 3.19 倍？ \(\sqrt{f'_c}\) 這種式子不是無因次的：\(f'_c\) 從 MPa 換成 kgf/cm² 要乘 10.197，開根號後只乘 \(\sqrt{10.197}=3.19\)， 所以係數要乘 3.19 才能維持同一個應力。\(0.25\times3.19=0.80\)、\(0.62\times3.19=1.98\approx2.0\)、\(1.0\times3.19=3.19\approx3.2\)。 把 SI 係數直接配 kgf 單位，拉應力限值會小約 3.2 倍，窗口整個算錯。（同一個道理也解釋了 U3-2 穿孔剪力的 1.06 ＝ 0.33×3.19。）
為什麼拉應力管得比壓應力嚴？ 用「破壞有沒有預警」解釋：混凝土受拉一裂就裂，裂縫讓鋼腱暴露、讓斷面勁度突降，而且沒有延性——所以拉應力只允許到開裂強度附近（U 類 \(2.0\sqrt{f'_c}\) 大約就是開裂模數）。 受壓則有一段非線性可以重新分配，容許值可以到 \(0.45\sim0.60f'_c\)。這也是 §1 中拉應力兩條總是控制的根本原因。

2.1 拉應力取 0：舊解的錯在哪裡

本庫舊解把 2010-4 的兩個容許拉應力都取 0，得到 \(27.68\le e\le30.19\) cm；現行規範（U 類）得到 \(12.83\le e\le34.71\) cm——窗口寬了將近 9 倍。 拉應力取 0 是「完全預力（全斷面受壓）」的設計條件，它是可以選擇的嚴格做法，但不是規範要求。 考卷沒給容許值時依現行規範取值；考卷明寫 \(f_{ta}=0\)（2015-4）時才照用——這是本庫「容許值例外」規則：考卷給的值比規範嚴，視為題目的設計條件。

陷阱：題目給了一組容許值，就換成規範值。 觸發信號：2015-4「容許壓應力均為 \(f_{ca}=140\)，容許拉應力均為 \(f_{ta}=0\)」。錯誤思維：現行規範比較寬，應該用規範值。正確認知：140（\(=0.4f'_c\)）與 0 都比規範嚴，是題目的設計條件，照用；在 §5 註明它在現行規範屬 U 類即可。

因果鏈：開裂無預警 → 拉應力限在開裂強度附近 → \(\sqrt{f'_c}\) 有單位 → kgf 制係數 ×3.19 → 傳遞 \(0.8\)、使用 U 類 \(2.0\) → 考卷給的值比規範嚴就照用。

§3 最優設計：四條同時達限，自重是「免費」的

2015-4 問的不是「給你 \(P\) 求 \(e\) 的範圍」，而是「\(F\)、\(e_p\) 都讓你選，最多能扛多少活載重」。答案是讓四條不等式同時取等號——任何一條還有餘裕，就代表斷面還沒用完。

3.1 兩兩相加，\(e\) 自己消掉

設對稱斷面（\(S_t=S_b=S\)）、兩階段同一個預力 \(F\)（題目沒給損失）。令 \(a=F/A\)、\(b=Fe_p/S\)，四條等式為：

$$\text{①}\ a-b+\frac{M_D}{S}=f_{ta}\qquad \text{②}\ a+b-\frac{M_D}{S}=f_{ca}\qquad \text{③}\ a+b-\frac{M_D+M_L}{S}=f_{ta}\qquad \text{④}\ a-b+\frac{M_D+M_L}{S}=f_{ca}$$

①＋③ 得 \(2a-M_L/S=2f_{ta}\)；②＋④ 得 \(2a+M_L/S=2f_{ca}\)。兩式相減、相加：

$$M_{L,\max}=(f_{ca}-f_{ta})\,S,\qquad F=\frac{(f_{ca}+f_{ta})A}{2},\qquad e_p=\Big(\frac{F}{A}-f_{ta}+\frac{M_D}{S}\Big)\frac{S}{F}$$
RC-2015-4：30×50 cm、\(L=12\) m、\(f_{ca}=140\)、\(f_{ta}=0\)。\(A=1500\) cm²、\(S=12{,}500\) cm³、\(M_D=6.48\) tf·m（假設 2.4 tf/m³）。
\(M_{L,\max}=140\times12{,}500=17.5\) tf·m → \(w_{L\max}=8M_L/L^2=0.972\) tf/m；\(F=140\times1500/2=105\) tf；\(e_p=(70+51.84)\times12{,}500/105{,}000=14.50\) cm。
自我檢查：把四個值代回應力式，四根纖維應分別是 0、140、140、0——一個不差才算對。
圖 3　RC-2015-4 最優設計的「應力翻轉」：傳遞階段（左）頂 0、底 140；使用階段（右）頂 140、底 0 kgf/cm²。四根纖維全部碰到容許值，斷面一點餘裕都沒有。 這張圖攔的錯：只讓兩條取等號（例如只管 ① 與 ③）——那樣仍可求出一組 \(F\)、\(e_p\)，但活載重不是最大。
\(M_{L,\max}\) 裡為什麼沒有 \(M_D\)？ 因為自重從傳遞階段就在，它的效果可以被「多放一點偏心」完全抵銷——\(e_p\) 的式子裡有 \(M_D/S\)，就是這件事。 所以在幾何放得下的前提下，對稱斷面的活載容量只取決於容許應力的範圍乘以斷面模數。 自重太大時代價出現在 \(e_p\)：\(e_p\) 超出斷面能放的位置（扣保護層），這個「免費」就不成立了，2015-4 的 \(e_p=14.50\) cm 遠小於 \(25-\text{保護層}\)，可行。
陷阱：有損失比時照搬封閉解。 觸發信號：題目給了 \(P_e/P_i\)。錯誤思維：直接用 \(F=(f_{ca}+f_{ta})A/2\)。正確認知：封閉解建立在「兩階段同一個 \(F\)」上；有損失時 ①② 用 \(P_i\)、③④ 用 \(P_e\)，要回到 §1 的四條不等式。

因果鏈：任何一條還有餘裕 → 斷面沒用完 → 四條同時取等號 → 兩兩相加消去 \(e\) → \(M_L=(f_{ca}-f_{ta})S\)、\(F=(f_{ca}+f_{ta})A/2\) → 代回求 \(e_p\) → 檢查幾何放得下。

§4 直線 vs 曲線鋼腱：偏心被誰卡住

這一節在怕的是一個流傳很廣的錯誤答案：「兩種鋼腱跨中偏心相同、跨中彎矩相同，差別只在剪力與撓度。」2005-5 與 2010-4 ㈠ 的舊解都這樣寫，2026-11-15 勘誤。

4.1 關鍵在梁端沒有自重彎矩

簡支梁的自重彎矩在跨中最大、梁端為零。§1 的上限 ① 裡有 \(M_G\)：

$$e\le k+\frac{M_G(x)+f_{ti}S}{P_i}$$

它的意思是：哪個斷面的 \(M_G\) 越大，那裡的鋼腱就可以放越低。

  • 直線鋼腱全長同一個偏心，所以要同時滿足每一個斷面——最不利的是梁端（\(M_G=0\)）：\(e_s\le k+f_{ti,\text{end}}S/P_i\)。
  • 曲線鋼腱在梁端可以回到形心（\(e=0\)），跨中再放到最大：\(e_c\le k+(M_G+f_{ti}S)/P_i\)。

兩者在跨中的偏心差約 \(M_G/P_i\)；換成使用階段可多抵抗的彎矩，約 \(P_e\cdot M_G/P_i=\eta M_G\)——相當於把自重「免費」抵銷掉。跨度越長，\(M_G\propto L^2\)，差距越大（2005-5 的 \(L=30\) m 就是在暗示這一點）。

圖 2　RC-2010-4（\(P_i=200\) tf）兩種鋼腱的比較。上：立面（垂直方向放大），直線鋼腱全長 \(e=24.04\) cm，由梁端（\(M_G=0\)、端部容許拉應力 \(1.6\sqrt{f'_{ci}}=26.77\)）控制；曲線鋼腱梁端 0、跨中 34.71 cm。下：使用階段可承受的活載彎矩 61.24 vs 79.38 tf·m，差 18.1 tf·m（約 +30%）。 這張圖攔的錯：把曲線鋼腱的平衡載重 \(8P_ee/l^2\) 當成「比直線多的載重」——直線鋼腱的 \(P_ee\) 一樣能抵抗彎矩，差別只在偏心能放多大。

曲線：\(e=34.71\) → \(M_L\le(37.78+2.519\times34.71+37.42)\times67{,}500-M_G=79.38\) tf·m。
直線：梁端 \(44.44-2.963e\ge-26.77\) → \(e\le24.04\) → \(M_L\le61.24\) tf·m。
提升 \(\Delta M=18.1\) tf·m（\(\approx0.645\) tf/m）。概念值 \(\eta M_G=0.85\times30.375=25.8\) tf·m 比較大，因為端部容許拉應力是一般位置的兩倍，直線鋼腱的劣勢被抵銷一部分。
陷阱：「直線鋼腱」等於「零偏心、只給軸壓」。 觸發信號：2010-4 只寫「直線型鋼腱」。錯誤思維：直線就是放在形心。正確認知：題目沒說無偏心；直線鋼腱可以偏心配置，只是偏心受梁端限制。把直線當零偏心，比較的就不是同一件事。
補充：端部放寬的範圍 規範只寫「簡支構材端部」適用 \(0.70f'_{ci}\)、\(1.6\sqrt{f'_{ci}}\)，沒有給出端部的長度。直線鋼腱的 24.04 cm 是用梁端斷面算的； 若一般位置的限值 \(0.8\sqrt{f'_{ci}}\) 從離端不遠處就開始適用，直線鋼腱在那一段（\(M_G\) 還很小）會更吃緊。 作答時寫明「依端部斷面檢核」即可；實務上直線先拉鋼腱常在端部去黏結（debonding）或改成折線來處理這一段。

因果鏈：簡支梁 \(M_G\) 端部為零 → 直線鋼腱的偏心由梁端控制 → 曲線鋼腱跨中可多放 \(M_G/P_i\) → 使用時多抵抗約 \(\eta M_G\) → 長跨差距更大。

§5 等效載重：把鋼腱換成一組外力

超靜定預力題的入口。鋼腱對混凝土的作用，可以完全用一組「等效載重」取代：彎曲的鋼腱對混凝土有側向推力，錨碇處有集中力與力矩。等效載重算對了，後面的二次反力、C 線都是結構學。

5.1 曲率 × 預力 ＝ 側向推力

一段曲率為 \(\kappa\) 的鋼腱，張力 \(P\) 對它的支撐物施加的側向力密度是 \(P\kappa\)（就像拉緊的繩子壓在曲面上）。對淺曲線 \(\kappa\approx|e''(x)|\)，所以

$$w(x)=-P\,e''(x)\quad(\text{e 向下為正，w 向上為正})$$

拋物線 \(e''\) 是常數。若拋物線相對兩端連線（弦）的下垂量是 \(f\)、跨長 \(L\)，則 \(e''=8f/L^2\)：

$$w_p=\frac{8Pf}{L^2}$$

極限檢查：\(f\to0\)（直線）→ \(w_p\to0\)，直線鋼腱沒有側向推力，只剩錨碇處的力與力矩。

圖 4　RC-2020-4 跨 AB 的鋼腱（垂直放大）。A 端偏心 0、B 支承在形心上方 35 cm、跨中 D 在形心下方 17.5 cm。下垂量 \(f\) 要從兩端連線（弦）量起：\(f=17.5-(0-35)/2=35\) cm，不是 17.5 cm。\(w_p=8\times128.6\times0.35/15^2=1.6\) tf/m，恰好等於外載。 這張圖攔的錯：把 \(f\) 量到形心線，等效載重少一半，載重平衡就驗不過。

5.2 錨碇處的力：不要漏

鋼腱在錨碇處以斜率 \(e'\) 離開，錨碇板受到預力 \(P\) 的垂直分量 \(Pe'\)；若錨碇不在形心上，還有力矩 \(Pe\)。 預力是內力，所以整組等效載重必須自平衡（合力為零、合力矩為零）。2024-4 的舊解只列了跨內均佈力與固定端力矩，合力 22 tf、合力矩 102 tf·m 都不為零——等效載重不自平衡，就是漏了東西的警訊。

RC-2024-4 的等效載重（\(P=120\) tf，\(e(x)=-0.76389x^2+11.25x-25\) cm）：
跨內 \(w=-Pe''=1.8333\) tf/m 向上（合力 22.0 tf）；A 端錨碇 \(Pe'(0)=13.5\) tf 向下、力矩 \(Pe(0)=30\) tf·m；B 端錨碇 \(P|e'(12)|=8.5\) tf 向下。
自平衡：\(22.0-13.5-8.5=0\)；對 A 取矩 \(22.0\times6-8.5\times12-30=0\)。✓

因果鏈：鋼腱彎曲 → 側向推力 \(P\kappa\) → 拋物線 \(w=8Pf/L^2\)（\(f\) 從弦量）＋錨碇力 \(Pe'\)、\(Pe\) → 整組自平衡 → 放到結構上求反力。

§6 超靜定預力：主彎矩、二次彎矩與 C 線

一句話：等效載重自平衡，所以在靜定梁上它不會產生任何反力；在超靜定梁上，多餘支承擋住了預力造成的變形，才產生「二次反力」與「二次彎矩」。

6.1 三種彎矩

名稱定義在靜定梁在超靜定梁
主彎矩 \(M_1\)\(-Pe(x)\)：預力合力在鋼腱上時造成的彎矩就是全部只是一部分
二次彎矩 \(M_2\)由二次反力造成；兩支承之間是直線（反力是集中力）0\(\ne0\)（除非是同位鋼腱）
淨彎矩 \(M\)\(M_1+M_2\)\(M_1\)\(M_1+M_2\)

壓力線（C 線）是「預力合力真正的位置」：\(e_C(x)=-M(x)/P=e(x)-M_2(x)/P\)。在靜定梁 \(M_2=0\)，C 線與鋼腱重合；在超靜定梁，C 線偏離鋼腱 \(M_2/P\)。 同位（一致）鋼腱就是讓 \(M_2=0\) 的鋼腱，此時 C 線又回到鋼腱上。

6.2 載重平衡（2020-4）：一次滿足兩件事

2020-4 ㈠ 要「預力不產生二次彎矩，且梁斷面受均勻軸壓」。均勻軸壓代表每個斷面的淨彎矩為零，也就是預力的主彎矩處處抵銷外載彎矩：

$$P_e\,e(x)=M_{\text{ext}}(x)\quad\forall x$$

鋼腱形狀因此就是外載彎矩圖的形狀（比例 \(1/P_e\)）。外載彎矩本身是相容的（它就是那根連續梁的真實彎矩），所以這樣的鋼腱自動是同位鋼腱，\(M_2=0\)。

圖 5　RC-2020-4 兩跨連續梁（各 15 m、\(w=1.6\) tf/m）。上：外載彎矩圖，\(M_B=-wL^2/8=-45\)、跨中 \(M_D=+wL^2/16=22.5\) tf·m；下：鋼腱 \(e(x)=M(x)/P_e\)，\(P_e=45/0.35=128.6\) tf，\(e_D=17.5\) cm。兩條曲線由同一個函式取點，形狀完全相同。 這張圖攔的錯：把 B 點偏心畫在形心下方——負彎矩區鋼腱要在形心上方，才能抵銷上緣受拉。
RC-2020-4 ㈡：改用 \(P_i\) 之後
\(P_i=P_e/0.8=160.7\) tf，等效上揚力變成 \(1.25w=2.0\) tf/m，比外載大。B 點淨彎矩 \((P_i/P_e-1)\,wL^2/8=+11.25\) tf·m（使上緣受壓）。
\(f_{\text{頂}}=35.71+16.67=52.4\)、\(f_{\text{底}}=35.71-16.67=19.0\) kgf/cm²（皆壓）。直接寫 \(P_i/A=35.7\) 就漏了這一項。

6.3 受撐懸臂梁（2024-4）：相容法求二次反力

以輥支承反力 \(R_B\) 為贅餘力，基本結構是固定端懸臂梁。主曲率 \(M_1/EI=-Pe/EI\) 讓 B 端產生撓度，\(R_B\) 要把它推回零：

$$R_B=\frac{3P}{L^3}\int_0^L e(x)(L-x)\,dx=\frac{3\times120}{12^3}\times\frac{120}{100}=0.25\ \text{tf（向上）}$$

另一條路（等效載重法）：B 端錨碇的 8.5 tf 直接由輥支承吸收；跨內向上 1.8333 tf/m 在受撐懸臂梁的輥支承反力為 \(-3wL/8=-8.25\) tf；合計 \(R_B=0.25\) tf。兩條路一致。

於是 \(M_2(x)=R_B(L-x)\)，固定端 \(M_{2,A}=3.0\) tf·m；C 線 \(e_C=e-M_2/P\)：固定端 \(-27.5\) cm、梁中央 \(+13.75\) cm、輥支承端 0。

圖 6　RC-2024-4 的完整鏈條。(a) 等效載重自由體：跨內 1.8333 tf/m 向上、A 端 13.5 tf 與 30 tf·m、B 端 8.5 tf。(b) 彎矩：主彎矩 \(M_1=-Pe\)（藍）、二次彎矩 \(M_2=0.25(12-x)\)（紅，直線）、淨彎矩 \(M\)（黑）。(c) 鋼腱（藍）與 C 線（紅虛線），C 線在固定端高出鋼腱 2.5 cm、線性遞減到輥支承端 0。 這張圖攔的錯：二次彎矩畫成曲線——它由集中反力產生，兩支承之間一定是直線。

6.4 怎麼改成同位鋼腱

  • 把鋼腱放到 C 線上（理論標準答案）：固定端 \(-27.5\)、梁中央 \(+13.75\)、輥支承端 0。它與原鋼腱只差一個線性函數，等效載重不變（線性函數的二次導數為零），所以 C 線不變而與鋼腱重合。
  • 保留兩端偏心、改梁中央偏心：要求 \(\int_0^L e(x)(L-x)\,dx=0\)，得 \(e_m=+12.5\) cm。
線性轉換為什麼不改變 C 線？ C 線由等效載重決定（它就是外力造成的淨彎矩除以 \(P\)）。在支承處改變偏心、跨內形狀不變，等於在 \(e(x)\) 上加一個線性函數——\(e''\) 不變，跨內等效載重不變； 多出來的只是支承處的錨碇力與力矩，它們直接被支承吸收，不改變梁內彎矩。所以「線性轉換」只把鋼腱上下搬動，C 線不動。

因果鏈：預力是內力 → 等效載重自平衡 → 靜定梁無反力、C 線＝鋼腱 → 超靜定梁多餘支承擋住變形 → 二次反力 → \(M_2\) 在支承間呈直線 → \(e_C=e-M_2/P\) → \(M_2=0\) 即同位鋼腱。

§7 摩擦損失：直線鋼腱也會有（2005-5 ㈡）

2005-5 ㈡ 問「直線型鋼腱是否會產生摩擦預力損失」。答案取決於施預力方法：先拉法沒有套管，沒有摩擦；後拉法有套管，即使設計上是直線，也有擺動（wobble）摩擦。

$$P_x=P_j\,e^{-(\mu\alpha+Kx)},\qquad \text{直線鋼腱 }\alpha=0:\ P_x=P_je^{-Kx}\approx P_j(1-Kx)$$
  • \(\mu\alpha\) 是曲率摩擦：對應設計曲線的角變 \(\alpha\)。
  • \(Kx\) 是擺動摩擦：套管因定位公差、澆置振動、支架間下垂產生的非預期偏轉，與長度成正比。直線鋼腱只剩這一項。
圖 7　直線後拉鋼腱的擺動摩擦損失 \(1-e^{-Kx}\)，\(K\) 取 ACI 舊版解說七股鋼絞線、金屬套管的範圍 0.0016～0.0066 /m（現行台灣規範條文不給係數）。一端張拉、\(x=30\) m 時損失 4.7%～18.0%；兩端張拉時最遠點 \(x=15\) m，約減半。 這張圖攔的錯：「直線鋼腱一律沒有摩擦損失」——長跨後拉時，擺動摩擦不可忽略。

因果鏈：後拉 → 鋼腱在套管內 → 套管不可能絕對筆直 → 擺動摩擦 \(Kx\) → 直線鋼腱也有損失；先拉 → 無套管 → 無摩擦。

§11 自我檢測：10 個「為什麼」

1. 為什麼偏心上限由傳遞階段的頂纖維決定？

傳遞時預力最大、只有自重彎矩，鋼腱在形心下方的偏心彎矩使頂纖維受拉；偏心越大頂纖維拉得越多，所以「不能再大」的界線在這裡。

2. 令 \(M_G=f_{ti}=0\)，條件 ① 會變成什麼？代表什麼？

\(e\le k=h/6\)。沒有任何彎矩幫忙時，預力合力必須在核心內，斷面才不出現拉應力——這就是核心距的定義。

3. 為什麼 kgf 制的 \(\sqrt{f'_c}\) 係數是 SI 的 3.19 倍？

\(f'_c\) 換單位乘 10.197，開根號後只乘 3.19；要維持同一個應力，係數就得乘 3.19。

4. 拉應力為什麼比壓應力管得嚴？

受拉開裂沒有預警、沒有延性，且讓鋼腱暴露、勁度突降；受壓有非線性可重分配。所以拉應力限在開裂強度附近（U 類 \(2.0\sqrt{f'_c}\approx f_r\)）。

5. 2015-4 的最大活載彎矩為什麼與自重無關？

自重從傳遞階段就在，可以被多放 \(M_D/P\) 的偏心完全抵銷（\(e_p\) 式中有 \(M_D/S\)）。只要偏心放得下，容量只取決於 \((f_{ca}-f_{ta})S\)。

6. 直線鋼腱為什麼由梁端控制？

直線鋼腱全長同一偏心，必須滿足每個斷面；梁端 \(M_G=0\)，沒有自重彎矩抵銷偏心彎矩，最不利。

7. 為什麼等效載重一定要自平衡？

預力是鋼腱與混凝土之間的內力，對整根梁而言合力、合力矩都是零。不自平衡代表漏了錨碇力或錨碇力矩。

8. 為什麼靜定梁沒有二次彎矩？

自平衡的等效載重放在靜定梁上不需要任何反力；梁可以自由變形（起拱），支承不擋，所以沒有二次反力，也就沒有 \(M_2\)。

9. 二次彎矩為什麼在支承之間是直線？

它只由二次反力（集中力）產生；兩個集中力之間沒有分布載重，彎矩隨位置線性變化。

10. 線性轉換為什麼不改變 C 線？

在 \(e(x)\) 上加線性函數不改變 \(e''\)，跨內等效載重不變；多出的錨碇力與力矩直接由支承吸收，梁內淨彎矩不變，所以 C 線不動。

§13 因果鏈總表：能用嘴巴講出來才算懂

  1. 窗口：預力大、載重小（傳遞）→ 頂纖維受拉 → 上限；預力小、載重大（使用）→ 底纖維受拉 → 下限；壓應力兩條通常很遠 → 窗口 = [③, ①]。
  2. 容許應力：開裂無預警 → 拉應力限在開裂強度附近 → \(\sqrt{f'_c}\) 有單位 → kgf 係數 ×3.19 → 考卷值比規範嚴就照用。
  3. 最優設計：有餘裕 = 斷面沒用完 → 四條同時取等號 → 兩兩相加消去 \(e\) → \(M_L=(f_{ca}-f_{ta})S\) → 自重被偏心抵銷。
  4. 線形：\(M_G\) 端部為零 → 直線鋼腱由梁端控制 → 曲線鋼腱多放 \(M_G/P_i\) → 多抵抗約 \(\eta M_G\)。
  5. 等效載重：鋼腱彎曲 → 側向推力 \(P\kappa\) → \(w=8Pf/L^2\)（\(f\) 從弦量）＋錨碇力 → 整組自平衡。
  6. 二次彎矩：自平衡 → 靜定梁無反力 → 超靜定梁擋住變形 → 二次反力 → \(M_2\) 直線 → \(e_C=e-M_2/P\) → \(M_2=0\) 即同位鋼腱。
  7. 摩擦：後拉 → 套管 → 擺動摩擦 \(Kx\) → 直線鋼腱也有損失。
