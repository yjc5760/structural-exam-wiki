## RC-2003-3　中間層內跨梁柱接頭 X 向剪力（20 分）

**題意（取自題目正本）**：$f'_c=280$、$f_y=4200$；X 向梁 24×60，頂 4-#6（11.48 cm²）、底 2-#6（5.74 cm²）；$M_n^- \approx 24$、$M_n^+ \approx 12$ tf-m；Y 向梁 40×65；柱 X 向 40、Y 向 50（判讀 #1）；X 向梁上緣與柱 +Y 面齊平（偏心，判讀 #2）；樓高 350 cm。求 $V_u$、$V_n$、檢核。

**附圖核對**：斷面 A-A：X 向梁上緣線、24cm 尺寸線上端、50cm 尺寸線上端同一水平線；40cm 為水平尺寸 → 與判讀 #1、#2 一致。

**解**
1. 由題給 $M_n$ 反推 $d$：$a = 11.48\times4200/(0.85\times280\times24) = 8.44$ cm，$M_n = 48.2(d-4.22)=24$ tf-m → $d \approx 54$ cm（正彎矩核得 12.5 ≈ 12 ✓）。
2. 梁筋拉力（$1.25f_y$）：$T_1 = 1.25\times4200\times11.48 = 60.27$ tf；$C_2 = T_2 = 1.25\times4200\times5.74 = 30.14$ tf。
3. $M_{pr}^- = 60.27(0.54-0.1055/2) = 29.37$、$M_{pr}^+ = 30.14(0.54-0.0528/2)=15.48$ tf-m（≈ 1.25×題給 $M_n$）。
   柱剪力（柱反曲點在樓高中點，樓高 3.5 m）：$V_{col} = (29.37+15.48)/3.5 = 12.81$ tf。
4. **$V_u = T_1 + C_2 - V_{col} = 60.27 + 30.14 - 12.81 = 77.6$ tf**
5. 圍束：Y 向梁寬 40 = 柱面寬 40（≥ 3/4）→ 圍束；X 向梁寬 24 / 柱面寬 50 = 0.48 < 3/4 → 不算圍束 → **兩對面圍束 → $4.0\sqrt{f'_c}$**（連續柱）。
6. 有效寬：$b_j \le \min(b+h,\ b+2x)$，梁偏心齊平，$x$（梁緣至柱側面較小距離）$=0$ → $b_j = 24$ cm（另式：$2\times$梁軸至柱側較小距離 $=2\times12=24$，同）；$h = 40$ cm。$A_j = 40\times24 = 960$ cm²。
7. **$V_n = 4.0\times16.733\times960 = 64.3$ tf**；$\phi = 0.85$（現行規範接頭）→ $\phi V_n = 54.6$ tf **< 77.6 tf → 不符合（NG）**。

**不確定處／替代解讀**
- 若誤當四面圍束（5.3）：$V_n=85.1$、$\phi V_n=72.4$ 仍 NG；若梁置中（$b_j = 50$）：4.0 → $V_n = 133.9$、$\phi V_n = 113.8$ OK——梁偏心是判定關鍵（判讀 #2 已確認偏心）。
- 題目印舊規範（92 年）無 $\phi$ 時 $V_n=64.3 < V_u$，結論相同（NG）。
- $V_{col}$ 用題給 $M_n\times1.25$：$V_u = 77.5$，差異可忽略。

**盲分類**：主 RC-U3-3（梁柱接頭剪力）；副無（同意索引主分類 RC-U3-3、副 []）。

## RC-2003-4　兩層剪力牆設計（40 分）

**題意**：$l_w = 930$（900 為邊界構材中心距）、$t_w=15$、邊界構材 30×30、$h_w=800$（350＋450）；兩端各 $P$ = 50D＋25L；屋頂 $w$ = 5D＋1L tf/m；$V_R=30$（屋頂）、$V_2=20$（二樓）；題給組合 $0.9D\pm1.43E$、$0.75(1.4D+1.7L\pm1.87E)$；剪力 $\phi=0.6$；彎鉤錨定 $0.06f_yd_b/\sqrt{f'_c}$。

**附圖核對**：900 延伸線落在兩端邊界構材中心；350／450 兩段；兩支 P 各在一端 → 與判讀 #1、#4、#6 一致。

**載重**（$w$ 取作用長 9.0 m）：$D = 2\times50+5\times9 = 145$ tf；$L = 2\times25+9 = 59$ tf；基底 $V = 50$ tf；$M = 30\times8 + 20\times4.5 = 330$ tf-m。

| 組合 | $P_u$ | $V_u$ | $M_u$ | 受壓邊界 $P_u/2+M_u/9$ | 另一端 |
|---|---|---|---|---|---|
| 考卷 0.9D＋1.43E | 130.5 | 71.5 | 471.9 | 117.7 | 12.8（仍受壓） |
| 考卷 0.75(1.4D+1.7L+1.87E) | 227.5 | 70.1 | 462.8 | **165.2** | 62.3 |
| 現行 1.2D＋1.0L＋1.0E | 233.0 | 50 | 330 | **153.2** | 79.8 |
| 現行 0.9D＋1.0E | 130.5 | 50 | 330 | 101.9 | 28.6 |

（E 為題給「使用載重值」，現行組合係數 1.0 是否足夠屬題意疑點：題給 1.43／1.87 顯示原題 E 為工作應力層級。主線依「規範版本」規則套現行組合，考卷組合並列。）

**1. 邊界構材**（以邊界構材承受全部軸力＋傾覆力偶，力臂 900 cm）
- 任一組合邊界構材皆不受拉。短柱 $\phi P_{n,max} = 0.8\phi[0.85f'_c(A_g-A_{st})+f_yA_{st}]$，$\phi=0.65$：
  4-#8：153.2 tf；6-#8：174.1 tf；8-#8：194.9 tf。
- 現行組合需求 153.2 → 4-#8 D/C ≈ 1.00（恰好）；考卷組合 165.2 → 需 6-#8。**採 6-#8**（$\rho = 3.4\%$，介於 1%–6%）。
- 特殊邊界構材需求（應力法）：$\sigma_{max} = P_u/A + M_u y/I$ = 27～33 kgf/cm² < $0.2f'_c = 56$ → 依現行規範**不須**特殊邊界構材；題目已明示設邊界構材，仍按特殊邊界構材配箍（保守）。
- 箍筋 #4（2 肢，$A_{sh}=2.54$），保護層取 4 cm → $b_c = 22$、$A_{ch}=484$，$A_g/A_{ch}-1 = 0.860$：
  $0.3(0.860)f'_c/f_{yt} = 0.258 f'_c/f_{yt}$ > $0.09$ → $s \le 2.54\times4200/(0.258\times22\times280) = 6.7$ cm；間距上限 $b/3 = 10$、$6d_b = 15.2$。
  **→ #4 閉合箍 @ 6 cm**（若只用舊式 $0.09$：$s \le 19.2$，由 $b/3$ 控制 → @10 cm）。

**2. 腹版水平筋**
- $A_{cv} = 15\times930 = 13{,}950$ cm²；單層網條件 $0.53\sqrt{f'_c}A_{cv} = 123.7$ tf ≥ $V_u$（71.5／50）→ **可用單層網**；$h_w/l_w = 0.86 < 2$。
- $\alpha_c = 0.8$（$h_w/l_w \le 1.5$）：$0.8\sqrt{f'_c}A_{cv} = 186.7$ tf ≥ $V_u/\phi = 119.2$ tf → 僅需最小筋 $\rho_t \ge 0.0025$（$V_u > 0.265\phi\sqrt{f'_c}A_{cv} = 37.1$ tf）。
- 單層 #4：$s \le 1.27/(15\times0.0025) = 33.9$ cm（≤ 45 cm）→ **#4 @ 30 cm 單層**，$\rho_t = 0.00282$。
- 驗算：$V_n = A_{cv}(0.8\sqrt{f'_c}+\rho_tf_y) = 352.1$ tf，$\phi V_n = 211.3$ tf（$\phi$=0.6）≥ 71.5 ✓；上限 $2.65\sqrt{f'_c}A_{cv} = 618.6$ ✓。
- 錨定：$l_{dh} = 0.06\times4200\times1.27/16.733 = 19.1$ cm（考卷式）；現行式（ACI 318-19，$\psi_r=\psi_o=1$）約 13.4 → 取下限 15.2 cm。邊界構材內可用 30 − 4 = 26 cm ≥ 19.1 ✓（彎鉤伸入邊界構材圍束核心、勾住遠側縱筋）。

**3. 腹版垂直筋**
- $\rho_l \ge 0.0025$，且 $h_w/l_w = 0.86 \le 2.0$ → $\rho_l \ge \rho_t$（缺字推測為「檢查高度／長度比並據以調整」，與圖旁孤立「度」字相合）。
- **#4 @ 30 cm 單層**（$\rho_l = 0.00282 = \rho_t$）。

**4. 斷面圖**：兩端 30×30 邊界構材 6-#8＋#4 箍 @6；腹版 15 cm 單層 #4@30 雙向，水平筋兩端 90°／135° 彎鉤錨入邊界構材核心。

**不確定處**：E 層級（見上）；$w$ 作用長取 9.0 或 9.3 m（差 1.5 tf，不影響配筋）；保護層自訂；邊界構材是否計入牆腹垂直筋（未計，保守）。

**盲分類**：主 RC-U3-3（耐震剪力牆）；副 RC-U2-1（剪力）、RC-U2-3（錨定）可考慮。索引主 RC-U3-3、副 RC-U2-1：同意（RC-U2-3 屬可選）。

## RC-2004-1　簡答：混凝土品質判定、耐震受撓筋搭接橫向筋（15 分）

**得分要點**
㈠ 混凝土強度合格判定（現行規範第 26 章「施工」相關；ACI 318-19 26.12）
1. 取樣頻率：每種配比每日至少一次、每約 110 m³（150 yd³）至少一次、每約 460 m²（5000 ft²）樓版或牆面至少一次；同一類混凝土總強度試驗數不少於 5 次（總量少時可減）。（台灣條文數值〔110／460〕不確定，以規範原文為準）
2. 一次「強度試驗」＝同批取樣、同齡期（通常 28 天）兩支 15×30 cm（或三支 10×20 cm）圓柱試體的平均。
3. 合格準則（兩者皆須滿足）：(a) 任連續三次強度試驗的平均 ≥ $f'_c$；(b) 單次試驗不低於 $f'_c - 35$ kgf/cm²（$f'_c \le 350$）或 $0.9f'_c$（$f'_c > 350$）。
4. 取樣時同時做坍度、溫度、含氣量（需要時）、單位重。
5. 不合格處理：鑽心取樣，每一不合格試驗取 3 個試體；3 個平均 ≥ $0.85f'_c$ 且無單一 < $0.75f'_c$ 即認可；仍不合格可載重試驗或分析評估。
6. 現場養護試體用於判斷保護與養護是否足夠（現場養護強度 ≥ 0.85 標準養護，或超過 $f'_c$ 35 kgf/cm² 以上）。

㈡ 耐震受撓筋搭接（ACI 318-19 18.6.3.3；台灣規範對應條文）
1. 搭接長度範圍內須配置**閉合箍筋或螺箍筋**。
2. 包圍搭接筋之橫向筋間距 ≤ $d/4$ 且 ≤ 10 cm。
3. 搭接不得位於：(a) 接頭內；(b) 距接頭面 $2h$ 範圍內；(c) 依分析預期發生撓曲降伏之臨界斷面兩側 $2h$ 內。
4. 機械式續接／銲接續接另依規定（第 2 類機械續接可用於任何位置）。
5. 柱縱筋搭接只能在柱中央一半長度內、須為拉力搭接並以圍束箍筋包覆（補充）。

**盲分類**：主 RC-U3-3；副 RC-U2-3（搭接）。同意索引（主 RC-U3-3、副 RC-U2-3）。㈠屬材料品質，大綱無專屬子項。

## RC-2004-3　柱圍束箍筋間距（15 分）

**題意**：50×50 柱，8-D25（$f_y=4200$），D13 箍筋＋兩支繫筋（$f_{yh}=2800$），每向 3 肢；$f'_c=280$；保護層未給。考卷印 $0.3(s h_c f'_c/f_{yh})(A_g/A_{ch}-1)$、$0.09 s h_c f'_c/f_{yh}$。

**附圖核對**：8 根（角＋邊中點），外箍＋十字繫筋，只有 50 cm 外緣尺寸 → 與判讀一致。

**解**（現行規範，$P_u \le 0.3A_gf'_c$ 假設——題未給軸力）
- 保護層取 4 cm（至箍筋外緣）→ $b_c = 42$ cm（量到箍筋外緣，本庫慣例），$A_{ch} = 42^2 = 1764$ cm²。
- $A_g/A_{ch}-1 = 2500/1764 - 1 = 0.417$ → $0.3\times0.417 = 0.125$ > 0.09 → 第一式控制。
- $A_{sh} = 3\times1.29 = 3.87$ cm²：$s \le 3.87\times2800/(0.125\times42\times280) = 7.36$ cm。
- 間距上限：$b/4 = 12.5$；$6d_b = 15.2$；$s_o = 10+(35-h_x)/3$，$h_x = 18.5$ → 15.5 → 取 15。
- **→ 圍束區 $s \le 7.3$ cm，採 D13 @ 7 cm**；圍束區長 $l_o \ge \max(h=50,\ l_u/6,\ 45)$ cm；區外 $s \le \min(6d_b, 15)$ = 15 cm。
- 若 $h_c$ 取箍筋中心距（舊 ACI-99：40.73）：$s \le 7.59$；若保護層 5 cm：$s \le 5.7$——答案對保護層假設敏感。

**盲分類**：主 RC-U3-3；副 RC-U1-2。同意索引。

## RC-2005-3　角柱接頭剪力檢核（20 分）

**題意**：樓高 365；柱 60×60；梁寬 60（同柱寬），$d=70$，拉力筋 6-#8（取 $A_b = 5.07$）；$f'_c=280$、$f_y=4200$；接頭樓層未給（取中間層）。

**解**
1. $T = 1.25\times4200\times30.42 = 159.7$ tf；$a = 11.18$ cm；$M_{pr} = 159.7(0.70-0.0559) = 102.9$ tf-m。
2. 柱剪力（上下柱反曲點在中點）：$V_{col} = M_{pr}/3.65 = 28.2$ tf → **$V_u = 159.7 - 28.2 = 131.5$ tf**。
3. 角柱：僅兩相鄰面有梁 → 「其他」→ $3.2\sqrt{f'_c}$；$A_j = 60\times60 = 3600$ cm²（梁寬 = 柱寬）。
4. **$V_n = 3.2\times16.733\times3600 = 192.8$ tf**，$\phi V_n = 0.85\times192.8 = 163.9$ tf ≥ 131.5 → **OK**（D/C = 0.80）。

**不確定處**：若為屋頂層（柱不連續）：$V_{col} = M_{pr}/1.825 = 56.4$、$V_u = 103.3$；現行規範非連續柱「其他」$2.1\sqrt{f'_c}$ → $\phi V_n = 107.5$ ≥ 103.3 OK（D/C 0.96）。不扣 $V_{col}$（$V_u = T = 159.7$）也 ≤ 163.9。結論各種解讀皆 OK。

**盲分類**：主 RC-U3-3；副 RC-U1-1（梁 $M_{pr}$）可接受。同意索引。

## RC-2009-1　說明：耐震柱橫向鋼筋配置（$P_u < 0.05A_gf'_c$）（25 分）

**得分要點**（現行規範第 18 章對應 ACI 318-19 18.7.5、18.7.6）
1. **圍束區** $l_o$：兩端（及接頭面）各 $\ge \max(h,\ l_u/6,\ 45$ cm$)$；柱支承不連續剛性構材且 $P_u > A_gf'_c/10$ 時全高圍束（本題軸力小，不適用）。
2. **圍束量**：矩形箍 $A_{sh}/(s b_c) \ge \max[0.3(A_g/A_{ch}-1)f'_c/f_{yt},\ 0.09f'_c/f_{yt}]$；螺箍 $\rho_s \ge \max[0.45(A_g/A_{ch}-1)f'_c/f_{yt},\ 0.12f'_c/f_{yt}]$；$P_u > 0.3A_gf'_c$ 或 $f'_c > 700$ 時另加 $0.2k_fk_nP_u/(f_{yt}A_{ch})$——本題 $P_u$ 很小，不適用。
3. **間距**（$l_o$ 內）：$\le b_{min}/4$、$6d_b$、$s_o = 10+(35-h_x)/3$（10 ≤ $s_o$ ≤ 15 cm）。
4. **橫向支撐**：每根角筋與隔根縱筋由箍筋角或繫筋（135° 耐震彎鉤，延伸 $6d_b \ge 7.5$ cm）支撐；未支撐筋與已支撐筋淨距 ≤ 15 cm；$h_x \le 35$ cm；繫筋兩端 90°／135° 交替。
5. **剪力設計**：$V_e = (M_{pr,top}+M_{pr,bot})/l_u$（$1.25f_y$、$\phi = 1$，取軸力範圍內最大），不必大於由梁 $M_{pr}$ 推得者，且不小於分析值。
6. **與 0.05 的關係（本題重點）**：$l_o$ 內 $V_c = 0$ 的條件為 (a) 地震引致剪力 ≥ 最大需求剪力之半，**且** (b) $P_u < A_gf'_c/20$（= 0.05）——題給軸力滿足 (b)，故圍束區通常取 $V_c = 0$，$V_s = V_e/\phi$ 全由箍筋承擔（$\phi$=0.75）。
7. **圍束區外**：$s \le \min(6d_b, 15$ cm$)$，並滿足剪力需求。
8. **搭接**：只能在柱中央一半長度，並以圍束箍包覆。
9. **接頭內**：橫向筋延續穿過接頭（四面梁寬 ≥ 3/4 柱寬時可減半、$s \le 15$ cm）。
10. 繪圖：柱立面標 $l_o$、箍筋間距分區；斷面示閉合箍＋繫筋與 135° 彎鉤。

**盲分類**：主 RC-U3-3；副 RC-U2-1（$V_c=0$ 的剪力設計）。同意索引。

## RC-2010-2　㈠耐震柱搭接規定 ㈡抗拉搭接長度（20 分）

**附圖核對**：50×50，D29 實心 12（下層彎折）＋空心 12（上層），D13 @10（外箍＋兩支內箍），下排第 2、3 根實心淨距 9.3 cm → 與判讀一致。

㈠ **要點**（ACI 318-19 18.7.4）
1. 縱筋比 $0.01 \le \rho_g \le 0.06$（搭接處兩組並排，實務上應檢討擁擠；本題每組 3.1%，搭接段合計 6.2%）。
2. 搭接只能在柱**中央一半**長度內，須為**拉力搭接**（全數同處搭接 → 乙級 1.3$l_d$）。
3. 搭接範圍以符合 18.7.5.2、18.7.5.3 之圍束箍筋（間距、$A_{sh}$）包覆。
4. 機械續接、銲接續接依其分類位置限制。

㈡ **抗拉搭接長度**（詳細式）
