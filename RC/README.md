## 如何開始

```
1. 把考卷 PDF 放進 raw/exams/，命名 RC-YYYY_鋼筋混凝土設計與預力混凝土設計.pdf
2. 對 Cowork 說：「解析 YYYY 年 RC 考卷」
3. 依提醒截圖題目附圖，存入 raw/solutions/RC-YYYY-N/RC-YYYY-N-fig-1.png
4. 告知 Cowork「截圖完成，請開始解題」（一次解一題）
5. 人工驗算後：「將 RC-YYYY-N 的 verificationStatus 改為 verified」
6. 「ingest RC-YYYY-N」→ wiki 自動更新
7. 「更新儀表板資料」→ index.html 題庫同步
```
