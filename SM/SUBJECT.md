## 8. 設計哲學框架（解題邏輯）

> 以下為原 repo `CLAUDE-SOLVE.md`「設計哲學框架」原文（2026-07 起，涵蓋 14 個子項），搬入時未改字，**也未逐項核對**；
> SOLVE 時與 `skills/exam-solve` 的三層掃描法一起使用。內容若與現行台灣規範牴觸，以現行規範為準；考卷給的數值參數照用，考卷印出的舊規範公式、係數改用現行規範（根目錄 `CLAUDE.md`「規範版本」）
> （例：原 repo 2026-08-28 勘誤 `SM-2019-2` 時，查出考卷「平均壓密度」表其實是中央面局部壓密度，不可直接套課本 $U$–$T_v$ 式）。

**土壤基本性質與分類（SM-U1-1）**
```
核心：由三相圖（土粒-水-空氣）建立各物理量的相互換算
三相關係：
  e = Vv/Vs（孔隙比）；n = Vv/V（孔隙率）；n = e/(1+e)
  w = Ww/Ws（含水量）；S = Vw/Vv（飽和度）
  γ = (Gs + Se)/(1+e) · γw（濕單位重）；γsat（S=1）；γ' = γsat - γw（水下單位重）
Atterberg 限度：
  塑性指數 PI = LL - PL；液性指數 LI = (w - PL)/PI
  LI > 1 → 靈敏黏土（受擾動強度大幅降低）
USCS 分類：
  粗粒土（過篩#200 < 50%）：礫石G / 砂S，依級配 Cu=D60/D10、Cc=D30²/(D10·D60) 判斷 W/P
  細粒土（過篩#200 ≥ 50%）：粉土M / 黏土C，依塑性圖（A-line：PI=0.73(LL-20)）判斷
```

**土壤滲透（SM-U1-2）**
```
核心：Darcy 定律 v = ki（層流假設，僅適用於低雷諾數）
流速與流量：v = ki；q = kiA = k·(Δh/L)·A
滲透係數試驗：定水頭法（適用粗粒土）／變水頭法（適用細粒土，k = 2.3(aL)/(At)·log(h1/h2)）
滲流網（Flow Net）：
  q = k·H·(Nf/Nd)（Nf=流槽數，Nd=等勢降數）
  任一點孔隙水壓 u = γw·(h - 已消散水頭)
臨界水力坡降（砂湧 / quick condition）：
  icr = (Gs - 1)/(1+e) ≈ γ'/γw
  安全係數 FSboiling = icr/iexit
```

**土壤夯實及壓密（SM-U1-3）**
```
核心：夯實控制施工品質；壓密推估長期沉陷與速率
夯實：
  夯實曲線峰值 = (wopt, γd,max)；零氣孔曲線 γzav = Gs·γw/(1+w·Gs)
Terzaghi 一維壓密理論：
  Tv = Cv·t/Hdr²（Hdr = 排水路徑長，雙面排水取層厚一半）
  平均壓密度 U(%) 與 Tv 對照（U<60%：Tv=π/4·(U/100)²；U≥60%：Tv=1.781-0.933log(100-U)）
  t = Tv·Hdr²/Cv
沉陷量（e-log p' 曲線）：
  判斷應力歷史：OCR = pc'/p0'
  正常壓密（p0'=pc'）：Sc = Cc·H/(1+e0)·log[(p0'+Δp)/p0']
  過壓密未超過 pc'（p0'+Δp ≤ pc'）：Sc = Cr·H/(1+e0)·log[(p0'+Δp)/p0']
  過壓密超過 pc'（p0'+Δp > pc'）：Sc = Cr·H/(1+e0)·log(pc'/p0') + Cc·H/(1+e0)·log[(p0'+Δp)/pc']
次壓縮沉陷：Ss = Cα·H/(1+ep)·log(t2/t1)（壓密完成後持續發生，與有效應力無關）
```

**土體內應力（SM-U1-4）**
```
核心：有效應力原理 σ' = σ - u（控制土壤強度與變形的是有效應力，不是總應力）
自重應力：
  地下水位以上：σv = Σγ·z
  地下水位以下：σv = Σγ·z（含水位以上部分）+ Σγsat·z（水位以下部分）；u = γw·zw；σv' = σv - u
  毛細上升區：需視是否飽和決定是否貢獻有效應力
外加應力（Boussinesq 彈性理論）：
  點載重：Δσz = 3Q/(2πz²)·[1/(1+(r/z)²)]^(5/2)
  條形載重、矩形載重：查影響係數圖（Newmark chart / Fadum chart）Δσz = q·Iσ
  近似法（2:1 應力分散法）：Δσz = Q/[(B+z)(L+z)]
```

**土壤強度特性與變形性（SM-U1-5）**
```
核心：Mohr-Coulomb 破壞準則 τf = c' + σ'·tanφ'（有效應力）或 τf = c + σ·tanφ（總應力，短期）
試驗方法對應分析情境：
  直接剪力試驗（DS）：排水剪力強度，適用長期穩定分析
  三軸壓縮試驗：
    UU（不壓密不排水）→ 總應力法，φ=0，Su = qu/2（無圍壓縮試驗）→ 短期施工穩定分析
    CU（壓密不排水，量測孔隙水壓）→ 可得有效應力強度參數 c'、φ'
    CD（壓密排水）→ 直接得有效應力強度參數，但費時
破壞面判斷：破壞面與大主應力面夾角 = 45° + φ/2
莫爾圓與強度包絡線相切處即為破壞面應力狀態
```

**淺基礎之支承力與沉陷量（SM-U2-1）**
```
核心：qu,net = qu - γ·Df（極限承載力）；qa = qu/FS（容許承載力，FS通常取3）
Terzaghi 承載力公式（一般剪力破壞，條形基礎）：
  qu = c·Nc + q·Nq + 0.5·γ·B·Nγ（q = γ·Df，上覆有效應力）
  Nc、Nq、Nγ 為 φ 之函數（查表或代公式）
  方形/圓形基礎需乘形狀係數（Terzaghi：qu=1.3cNc+qNq+0.4γBNγ 方形）
Meyerhof/Hansen/Vesic 一般式：
  qu = c'Nc·Fcs·Fcd·Fci + q'Nq·Fqs·Fqd·Fqi + 0.5γBNγ·Fγs·Fγd·Fγi
  （形狀 Fs、深度 Fd、傾斜載重 Fi 修正係數）
地下水位修正：水位在基礎面以下 → 有效應力項用 γ'；水位在基礎面以上 → q 項與 Nγ 項均需扣水浮力
局部剪力破壞（鬆砂/軟弱土）：修正 c* = (2/3)c；φ* = tan⁻¹[(2/3)tanφ]
沉陷量：瞬時沉陷（彈性理論，砂土為主）+ 壓密沉陷（黏土為主，見 SM-U1-3）
容許沉陷準則：總沉陷量與差異沉陷量需同時檢核（差異沉陷常為控制項）
```

**深基礎之支承力與沉陷量（SM-U2-2）**
```
核心：Qu = Qp + Qs（樁端承載力 + 樁身摩擦力）；Qa = Qu/FS 或依 α法/β法個別安全係數
樁端承載力：Qp = Ap·qp（qp 依 Meyerhof 承載力理論，深基礎 Nq*、Nc* 隨 L/D 增大而趨於定值）
樁身摩擦力：
  黏土（α法）：fs = α·Su（α 為經驗係數，隨 Su 增大而減小）
  砂土（β法）：fs = K·σv'·tanδ = β·σv'（K 依樁施工方式，δ 為樁-土界面摩擦角）
  Qs = Σ(fs,i·As,i)（分層加總）
動力打樁公式（僅供概估）：Engineering News Formula 等，Qu = Wr·h/(s+c)
群樁效應：
  群樁效率 Eg = Qg(group)/(n·Qu(single))
  黏土常需檢核「塊體破壞」（block failure）承載力
  沉陷：黏土群樁沉陷遠大於單樁沉陷（應力重疊，需以等值基礎法估算）
負摩擦力（下曳力）：填土或地下水位下降造成土層相對樁下沉時，摩擦力方向反轉、增加樁身荷重
```

**開挖之穩定性分析（SM-U2-3）**
```
核心：開挖伴隨側向土壓力釋放與地下水滲流，須同時檢核支撐結構強度與整體穩定
開挖面板樁/連續壁：主動側土壓力（開挖側）vs 被動側土壓力（嵌固側），依插入深度求彎矩、剪力
基盤隆起（basal heave）：
  FS = (Nc·Su)/(γ·H)（Terzaghi/Bjerrum-Eide 法，軟弱黏土開挖常見破壞模式）
砂湧（boiling）與管湧（piping）：
  FS = icr/i（見 SM-U1-2 臨界水力坡降）
  可用地下連續壁增加滲流路徑長度、或降水井洩壓來提高安全係數
支撐系統：內支撐（水平樑柱）／背拉錨（tieback anchor），依開挖深度分階段設置
```

**基礎型式之選擇與評估（SM-U2-4）**
```
核心：依承載力需求、沉陷容許值、地層條件、施工限制綜合評估
淺基礎（獨立/聯合/筏式基礎）：適用地表附近有足夠承載力土層，經濟性優
深基礎（樁基/沉箱/壁樁）：適用表層軟弱、需穿過軟弱層達堅實層，或需抵抗大側向力/上舉力
評估準則：承載力是否滿足、沉陷（含差異沉陷）是否在容許範圍、液化potential、施工可行性與經濟性
```

**地層改良方法（SM-U2-5）**
```
核心：改善原地層強度、壓縮性或滲透性以滿足工程需求
夯實類：動力夯實、震動夯實（適用砂性土）
排水固結類：預壓法 + 垂直排水井（砂井/塑膠排水板），加速壓密、預先消除沉陷
灌漿類：滲透灌漿、擠壓灌漿、高壓噴射灌漿（改善強度、降低滲透性）
置換類：開挖置換、擠淤
化學/物理改良：石灰/水泥攪拌樁（深層攪拌法）、凍結法（臨時性）
```

**側向土壓力理論（SM-U3-1）**
```
核心：牆體位移方向決定土壓力狀態（靜止/主動/被動）
靜止土壓力：K0 = 1 - sinφ'（正常壓密）；K0,OC = K0,NC·√OCR（過壓密修正）
Rankine 理論（假設牆背垂直、光滑、填土水平）：
  Ka = tan²(45° - φ/2)；Kp = tan²(45° + φ/2)
  無凝聚力：σa' = Ka·σv'；Pa = 0.5·Ka·γ·H²（作用點在 H/3）
  有凝聚力：σa' = Ka·σv' - 2c'√Ka；張力裂縫深度 zc = 2c'/(γ√Ka)（裂縫以上不計主動壓力）
  被動側：σp' = Kp·σv' + 2c'√Kp
Coulomb 理論（可考慮牆背傾角、填土坡度、牆土摩擦角 δ）：
  Ka、Kp 依完整三角函數式計算（δ 增大使 Ka 略減、Kp 明顯增大，但需注意破壞面非平面的修正）
水位以下：以有效應力 σv' 計算土壓力，另加水壓力 u（水壓力沿深度線性增加，作用於牆身）
```

**擋土結構物穩定分析（SM-U3-2）**
```
核心：四項獨立穩定檢核，缺一不可
① 抗滑動：FS = ΣFR/ΣFD = (W·tanδ + Ca·B)/Pa,h ≥ 1.5（δ=基礎底面摩擦角）
② 抗傾覆：FS = ΣMR/ΣMO（對牆趾取矩，抵抗力矩/傾覆力矩）≥ 2.0
③ 承載力：合力作用點偏心距 e = B/2 - x̄，需 e ≤ B/6（避免底面出現拉應力）
   梯形/三角形應力分布：qmax,min = (ΣV/B)·(1 ± 6e/B)；需 qmax ≤ qa（地基承載力）
④ 整體穩定：以圓弧滑動法檢核含牆體在內的整體邊坡穩定性（見 SM-U3-3）
加勁擋土結構（加勁土、地錨）：另需檢核加勁材抗拉強度、抗拔出摩擦力
```

**坡地工程（SM-U3-3）**
```
核心：安全係數 FS = 抗滑力（矩）/驅動力（矩），沿最危險（臨界）滑動面計算
無限邊坡分析（適用淺層、平行邊坡表面之滑動面）：
  乾坡：FS = tanφ'/tanβ（無凝聚力）
  含滲流（滲流方向平行坡面）：FS = c'/(γ·z·cosβ·sinβ) + [γ' /γ]·(tanφ'/tanβ)
有限邊坡 — 瑞典圓弧法（Fellenius 法，適用 φ=0 分析或簡化計算）：
  FS = ΣτfL/ΣτdL；φ=0 時 FS = Su·Larc/(W·d)（d=力臂）
條分法通用式（含 Bishop 簡化法）：
  FS = Σ[c'·b + (W - u·b)·tanφ']/[m_α] / Σ(W·sinα)
  m_α = cosα·(1 + tanα·tanφ'/FS)（需迭代求解，因 FS 出現在等號兩側）
臨界滑動面：需嘗試多組圓心與半徑，找出 FS 最小之滑動面
常見破壞模式：坡面滑動、坡趾滑動、坡底滑動（視土層與坡度而定）
```

**生態工法在邊坡工程之應用（SM-U3-4）**
```
核心：以植生或自然材料強化邊坡表層穩定與排水，兼顧環境與坡面保護
植生護坡：根系增加表層抗剪強度（附加凝聚力 Δc）、降低表層滲透造成的沖蝕
排水設計：地表排水溝、暗管排水降低坡體內地下水位（提高有效應力、增加 FS）
搭配工法：格框植生、蜂巢式擋土、多孔隙生態工法（兼具透水性與結構強度）
```
