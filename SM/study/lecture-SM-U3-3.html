§0　全景：一個定義，三種滑動面，四種水

一句話：擋土牆的安全係數比的是「剛體的力」，邊坡的安全係數比的是「同一條滑動面上的應力」： $$FS=\frac{\tau_f}{\tau_d}=\frac{c'+\sigma_n'\tan\phi'}{\tau_{\text{需要}}}$$ 意思是「土的強度要打幾折，這條滑動面才剛好處於極限平衡」。所有題目只在變兩件事：滑動面的幾何（決定 \(\tau_d\) 與 \(\sigma_n\) 怎麼算），以及水（決定 \(\sigma_n'\) 與驅動力被改了多少）。
圖 0-1　三種滑動面（楔體依 SM-2023-2 的 60°／45° 按比例；其餘為示意）。這張圖攔的錯：用錯分析單元 —— 無限邊坡只取一個切片、不管邊界；楔體要整塊算重量；圓弧要切片、對圓心取矩。
水扮演的角色作用題目
浮力\(\sigma_n'\) 與下滑力同比例減少2024-2 ㈡：完全浸水，\(FS\) 不變
滲流力（孔隙水壓）\(\sigma_n'\) 減少、下滑力不減 → \(FS\) 下降2014-1（平行滲流）、2021-4（切片 \(u\Delta L\)）
降低強度入滲使 \(c\) 下降（吸力消失、軟化）2023-2 ㈡：\(c\) 50 → 5，\(FS\) 3.68 → 1.02
側向靜水壓張力裂縫或塊體背面積水，直接推2006-3 ㈡：水壓佔驅動 85%，\(FS\) 1.22 → 0.47

6 題主考點的計算題全部都有水，或明講「雨水」（2008-4 例外，改考地震）。水是本單元的主角，地震是配角。

§1　無限邊坡（c = 0）：FS 只看兩個角度

這一節在怕什麼：算出 \(FS\lt1\) 就以為自己算錯，或把浸水和滲流當成同一件事。

取深度 \(z\)、平行坡面的滑動面上一小段：重量 \(\gamma z\)（每單位水平寬），分解到滑動面：

$$\sigma_n=\gamma z\cos^2\beta,\qquad \tau_d=\gamma z\sin\beta\cos\beta\quad\Rightarrow\quad FS=\frac{\gamma z\cos^2\beta\tan\phi}{\gamma z\sin\beta\cos\beta}=\frac{\tan\phi}{\tan\beta}$$
圖 1-1　由公式取 140 點繪出。SM-2024-2 刻意給 \(\beta=42^\circ\gt\phi=35^\circ\)，乾與浸水都是 0.78。這張圖攔的錯：「浸水比較危險所以 FS 要變小」—— 靜水只有浮力，兩邊等比例縮小；只有流動的水才把 \(FS\) 打到大約一半。
極限檢查：\(\beta=\phi\) → \(FS=1\)，這就是乾砂的休止角；\(z\) 完全約掉 → c = 0 的無限邊坡沒有「臨界深度」，淺處和深處一樣危險（所以砂坡的破壞多是表層剝落）。
浸水 vs 滲流：完全浸水時，\(\sigma_n'\) 和下滑力都用 \(\gamma'\)，比例不變。水平行坡面流到地表時，滲流力 \(i\gamma_w=\gamma_w\sin\beta\) 順坡往下，只加在驅動側 —— 驅動用 \(\gamma_{sat}\)、抗力用 \(\gamma'\)： $$FS_{\text{滲流}}=\frac{\gamma'}{\gamma_{sat}}\cdot\frac{\tan\phi}{\tan\beta}\approx\tfrac12\cdot\frac{\tan\phi}{\tan\beta}$$

1.1　自由水層的水力坡降：\(i=\sin\theta\)

自由水面上壓力水頭為 0，總水頭＝高程水頭。沿流線走 \(\Delta s\)，高程降 \(\Delta s\sin\theta\)，所以 \(i=\Delta h/\Delta s=\sin\theta\)。SM-2024-2 ㈢：\(\theta=30^\circ\) → \(i=0.50\)。寫成 \(\tan\theta=0.577\) 是把分母取成水平距離（Dupuit 近似）；用坡角 \(\beta=42^\circ\) 則是看錯線 —— 題目問的是水面的傾角，不是地表。

因果鏈 ①（c = 0 無限邊坡）：取平行坡面切片 → \(\sigma_n=\gamma z\cos^2\beta\)、\(\tau=\gamma z\sin\beta\cos\beta\) → \(z\) 約掉 → \(FS=\tan\phi/\tan\beta\) → 靜水：兩邊都換 \(\gamma'\)，不變 → 滲流：驅動 \(\gamma_{sat}\)、抗力 \(\gamma'\)，約減半。

§2　c′-φ′ 無限邊坡＋平行滲流：孔隙水壓為什麼是 \(\gamma_wh_w\cos^2\beta\)

這一節在怕什麼：孔隙水壓直接寫 \(\gamma_wh_w\)，以及把題目的「深度」讀成垂直坡面的厚度。SM-2014-1 的 6 m、1.5 m 都是鉛直量的。
圖 2-1　左：平行坡面滲流時流線平行坡面，等勢線垂直坡面（按 \(\beta=15^\circ\)、水下 4.5 m 比例繪；A 到 B 的線與坡面垂直）。A 與 B 在同一條等勢線上，總水頭相同；B 在水面上 \(u=0\)，所以 A 的壓力水頭等於兩點高程差 \(h_w\cos^2\beta\)。右：SM-2014-1 改變水位深度重算（同一組題解式子取 120 點）。這張圖攔的錯：用 A 正上方的水深 \(h_w\) 當壓力水頭 —— 那是靜水的做法。

2.1　分項通式（水位上下單位重不同時一定要用）

$$\sigma_v=\gamma_tH_1+\gamma_{sat}H_2,\qquad \tau_d=\sigma_v\sin\beta\cos\beta,\qquad \sigma_n'=\sigma_v\cos^2\beta-\gamma_wH_2\cos^2\beta$$ $$FS=\frac{c'+\sigma_n'\tan\phi'}{\tau_d}$$
手算範例：SM-2014-1（題目只給含水量與 \(G_s\)，單位重要自己推）
① 水位下飽和：\(e=wG_s=0.35\times2.64=0.924\)，水位上下 \(e\) 相同。
② \(\gamma_t=\dfrac{G_s(1+w_1)}{1+e}\gamma_w=16.69\)、\(\gamma_{sat}=\dfrac{G_s(1+w_2)}{1+e}\gamma_w=18.17\) kN/m³。
③ \(\sigma_v=16.69(1.5)+18.17(4.5)=106.80\) kPa；\(u=9.81(4.5)\cos^215^\circ=41.19\) kPa。
④ \(\sigma_n'=106.80(0.9330)-41.19=58.45\)；\(\tau_d=106.80\sin15^\circ\cos15^\circ=26.70\) kPa。
⑤ \(FS=(15+58.45\tan20^\circ)/26.70=1.36\)。
自我檢查：另一條路 \(\sigma_n'=(\gamma_tH_1+\gamma'H_2)\cos^2\beta=58.46\) ✓；水位降到岩層介面（無水）\(FS=1.96\)，升到地表 \(1.18\)，題目落在中間 ✓。
c 項讓深度重新有意義：\(FS=\dfrac{c'}{\gamma z\sin\beta\cos\beta}+\dfrac{\tan\phi'}{\tan\beta}(\cdots)\)。第一項隨深度變小 —— 淺層 c 很管用，深層靠摩擦。這解釋了為什麼 §3 的淺層楔體只要 c 一降，\(FS\) 就崩。
因果鏈 ②（c′-φ′＋滲流）：讀清深度是鉛直 → 三相換算求 \(\gamma_t\)、\(\gamma_{sat}\) → \(\sigma_v\) 分層加 → \(\tau_d=\sigma_v\sin\beta\cos\beta\) → \(u=\gamma_wh_w\cos^2\beta\)（等勢線垂直坡面）→ \(\sigma_n'\) → \(FS\)。

§3　平面楔體：先把幾何算對，再看 c 佔多少

這一節在怕什麼：楔體幾何算錯（重量、滑動面長），以及沒看出「淺層破壞面上 c 佔了大半抗力」。
$$FS=\frac{cL+W\cos\theta\tan\phi}{W\sin\theta}$$
圖 3-1　SM-2023-2：\(H=8\) m、坡面 60°、破壞面 45°，\(W=270.50\) kN/m、\(L=11.31\) m。左：抗力組成按比例；右：FS 對 c 是一條直線。這張圖攔的錯：以為「φ 沒變，強度差不多」—— c 從 50 降到 5，抗力少了 509 kN/m，而摩擦那 139 kN/m 一點都沒動。

楔體幾何：楔體 ABC 的面積 \(=\tfrac12\times(H\cot\theta-H\cot\alpha)\times H\)；2023-2 為 \(\tfrac12(8-4.619)(8)=13.53\) m²。題目只給高度與角度時（2008-4），三邊用正弦定理推，見 §4。

3.1　順向坡：滑動面是現成的

為什麼順向坡要用平面滑動？層面（弱面）傾向與坡面同向，傾角小於坡角（層面在坡面上「露出」）、又大於層面摩擦角時，塊體可以直接沿層面滑出 —— 不需要剪斷完整岩體。SM-2013-1 ㈠問需要哪些試驗：重點是層面的參數 —— 鑽探與地表調查求層面位態與地下水位；弱面（層泥）直接剪力試驗求 \(c'\)、\(\phi'\)；已滑動或有潛變者做反覆直剪求殘餘強度 \(\phi_r'\)。只答「三軸試驗求 c、φ」是答錯方向。
因果鏈 ③（平面楔體）：角度標在哪（坡面／破壞面）→ 面積與 \(L\) → \(W\) → 分解 \(W\sin\theta\)、\(W\cos\theta\) → 抗力 \(cL+N\tan\phi\) → 雨水只改 c 時，FS 隨 c 線性下降。

§4　地震與地錨：擬靜態力要兩個方向都分解

這一節在怕什麼：\(k_hW\) 只加在下滑力。水平力對傾斜的滑動面同時有平行分量（增加驅動）與垂直分量（把塊體拉離滑動面、減少正向力）。
$$T_d=W\sin\theta+k_hW\cos\theta,\qquad N=W\cos\theta-k_hW\sin\theta\ (+P_{\text{地錨}})$$
圖 4-1　SM-2008-4：AC 40°、\(\angle A=30^\circ\)、\(\angle C=35^\circ\)、B 高 7.5 m，按標註角度繪（考卷附圖未按比例，量圖會得到錯的角度）。右圖由同一組式子取 120 點：只把 \(k_hW\) 加在驅動側會高估 FS。這張圖攔的錯：量圖取角度、地震力取向坡內（偏不安全）、以及把每公尺需求當成每支地錨荷重。
手算範例：SM-2008-4
① 幾何：\(L_{AB}=7.5/\sin70^\circ=7.981\)；\(\angle B=115^\circ\)，正弦定理 \(L_{AC}=7.981\sin115^\circ/\sin35^\circ=12.61\) m；面積 \(\tfrac12(7.981)(12.61)\sin30^\circ=25.16\) m²，\(W=503.24\) kN/m。
② \(T_d=503.24\sin40^\circ+100.65\cos40^\circ=400.58\)；\(N=503.24\cos40^\circ-100.65\sin40^\circ=320.81\) kN/m。
③ \(FS=(10\times12.61+320.81\tan28^\circ)/400.58=0.74\)（無地震時 1.02）。
④ 地錨只增加正向力 \(P\)：\(126.10+(320.81+P)\tan28^\circ=1.2\times400.58\) → \(P=346.09\) kN/m → 間距 2 m，每支 \(T\ge692.2\) kN。
為什麼垂直滑動面的地錨效率不高？它只能透過 \(\tan\phi\)（這裡 0.53）把拉力轉成抗力，每 1 kN 只換到 0.53 kN。若地錨往上坡方向傾斜，拉力同時抵銷一部分下滑力。本講義以同一組數字試算：地錨偏離法線約 23° 時，所需力降到約 192 kN/m（約為垂直時的 55%）。題目指定「垂直滑動面、只增加正向力」時照題目算；說明題可以拿這點談地錨傾角的選擇。
因果鏈 ④（地震與地錨）：正弦定理求邊長與面積 → \(W\) → \(k_hW\) 朝坡外 → 兩個方向分解（驅動 +、正向 −）→ FS → 目標 FS 反算 \(P\)（只進 \(N\tan\phi\)）→ 乘間距得每支荷重。

§5　滑動塊體法：軟弱夾層上的側向滑動

這一節在怕什麼：題目只說「以合理方法」，就不知道從哪裡下手。軟弱薄層就是現成的滑動面；它上面的土分成三塊：後方主動楔推、中間塊沿夾層滑、前方被動楔擋。
$$FS=\frac{s_uL+P_P\ (+P_{wP})}{P_A\ (+P_{wA})}$$
圖 5-1　SM-2006-3（剖面按 1:2 邊坡、開挖 10 m 繪；力的長條依題解數值按比例）。主動側高 12 m、被動側高 2 m、夾層長 20 m。這張圖攔的錯：豪雨時只把土壓換成 \(\gamma'\)（有效土壓反而變小），卻忘了加靜水壓 —— 那才是驅動力的大頭。
  • 主動側：\(c'=10\) kPa 的砂質土，先求張力裂縫 \(z_c=2c'/(\gamma\sqrt{K_A})\)：常時 1.73 m、豪雨（\(\gamma'\)）3.40 m；裂縫以上不計，常時 \(P_A=351.4\)、豪雨有效土壓只剩 125.6 kN/m。
  • 中間塊：沿夾層用不排水強度 \(s_uL=12\times20=240\) kN/m，與正向力無關（\(\phi=0\)，和 U3-2 的 2025-3 同一個道理）。
  • 被動側：\(K_P=3\)，含 \(2c'\sqrt{K_P}\) 項，常時 189.3 kN/m。
  • 豪雨：題目正本判讀為水位沿地表輪廓（一個情況），兩側加靜水壓：主動側 706.3、被動側 19.6 kN/m → \(FS=0.47\)。
陷阱：把「水位沿原地表面、邊坡面、開挖面」拆成三個水位各算一次。觸發信號：㈡的長句。正確認知：三段地表連起來就是豪雨後的水面輪廓，只有一個情況（出自 2006-3 題目正本 #1，已確認）。
因果鏈 ⑤（三塊法）：找軟弱層當滑動面 → 切三塊 → 主動側 \(K_A\)、裂縫 → 被動側 \(K_P\)＋\(2c\sqrt{K_P}\) → 中間 \(s_uL\) → 有水：土壓改 \(\gamma'\)、兩側加靜水壓 → FS。

§6　圓弧切片法：考的是量圖與列表，不是公式

這一節在怕什麼：以為切片法的難點是公式。SM-2021-4 考卷把普通切片法公式整式印出，卻沒有給任何切片尺寸 —— 寬、高、底長、重量、孔隙水壓全部要依比例尺量。題解 2026-11-15 勘誤前用了一張自編的切片表，FS 寫成 0.867；依量測幾何改為 0.98。
$$FS_{\text{Fellenius}}=\frac{\sum\bigl[c'\Delta L_n+(W_n\cos\alpha_n-u_n\Delta L_n)\tan\phi'\bigr]}{\sum W_n\sin\alpha_n}$$
圖 6-1　SM-2021-4 題解切片表（依 5 m 比例尺量測，精度約 ±0.2 m）逐片拆開。陡的切片負責「推」、平的切片負責「擋」。右框的 Bishop 值是本講義用同一張表試算，僅供對照，不是題目所求。這張圖攔的錯：以為每一片都要「自己穩定」—— FS 是整條滑動面加總的比值。

6.1　\(\alpha\) 怎麼取

\(\alpha_n\) 是切片底面的傾角，等於「圓心 O 到切片底中點的半徑」與鉛直線的夾角。2021-4 的考卷在 O 到每個 \(W_n\) 作用點畫了虛線半徑並標 60°、42°、30°、13°，第 5 片未標，判讀為 0°（\(W_5\) 與鉛直半徑重合）。題解指出考卷所畫圓弧不是以 O 為圓心的正圓，改量弦角會得 FS ≈ 1.37 —— 照考卷標註用。

6.2　Fellenius vs Bishop：差在切片之間的力

普通切片法（Fellenius）Bishop 簡化法
切片間力全部忽略計入水平力、忽略垂直剪力
正向力\(N'=W\cos\alpha-u\Delta L\)由每片鉛直力平衡求得
式子直接算\(FS=\dfrac{\sum[c'b+(W-ub)\tan\phi']/m_\alpha}{\sum W\sin\alpha}\)，\(m_\alpha=\cos\alpha+\dfrac{\sin\alpha\tan\phi'}{FS}\)，FS 在兩邊 → 迭代
結果偏保守，常比 Bishop 低 5%–20%（題解 2021-4 §5）同表試算 ≈ 1.09（比 0.975 高約 12%）
為什麼 Fellenius 會偏低？它把切片當成彼此不相干的小塊，每一片只用自己的重量去壓滑動面。實際上相鄰切片互相推擠，這股力會增加下段切片底面的正向力 → 摩擦更大。忽略它，等於少算了一部分抗力。另一個症狀是 \(W\cos\alpha-u\Delta L\) 在陡片、高水壓時可能變成負的（有效正向力為負，物理上不可能），這時就是 Fellenius 失真的訊號。
因果鏈 ⑥（切片法）：依比例尺量切片邊界 → 每片 \(b\)、面積（水位上下分開）→ \(W_n\) → \(\alpha_n\)（半徑與鉛直夾角）→ \(\Delta L=b/\cos\alpha\)、\(u\) 取底中點 → 列表求和 → FS；寫出量測表與不確定度。

§7　門檻與穩定對策

本單元考卷只有一次印出門檻：SM-2008-4 的「地震力作用下 \(FS\ge1.2\)」。其他題只要求算 FS，題解也多半只報數值。作答時補一句與規範門檻比較，並寫明依據（水土保持技術規範、公路邊坡穩定設計規範、建築物基礎構造設計規範各有常時／地震／豪雨的規定值，條文以原文為準）。例如建築物基礎構造設計規範（112 年修正）7.4.4 擋土牆整體穩定：長期 1.5、地震 1.1、考慮最高水位 1.2（最高水位時可不同時考慮地震）。

§11　自我檢測：能回答才算讀懂

1. c = 0 無限邊坡的 FS 為什麼和深度無關？

正向力與下滑力都與 \(\gamma z\) 成正比，相除後 \(z\) 約掉，只剩 \(\tan\phi/\tan\beta\)。

2. 為什麼完全浸水的砂坡 FS 不變，平行滲流卻約減半？

靜水浮力讓正向力與下滑力都改用 \(\gamma'\)，比例不變；滲流力順坡向下只加在驅動側，驅動用 \(\gamma_{sat}\)、抗力用 \(\gamma'\)，FS 乘 \(\gamma'/\gamma_{sat}\approx0.5\)。

3. 平行坡面滲流時，孔隙水壓為什麼要乘 \(\cos^2\beta\)？

流線平行坡面，等勢線垂直坡面。滑動面上一點與等勢線在水面上的交點總水頭相同；後者壓力為 0，所以壓力水頭等於兩點高程差 \(h_w\cos^2\beta\)。

4. 自由水層的水力坡降為什麼是 \(\sin\theta\) 不是 \(\tan\theta\)？

水面上壓力水頭為 0，水頭損失等於高程降；坡降的分母是沿流線的長度，所以是 \(\sin\theta\)。\(\tan\theta\) 是以水平距離為分母的 Dupuit 近似。

5. 2023-2 的 φ 沒變，c 從 50 降到 5，為什麼 FS 掉了七成多？

楔體淺、正向力小，\(N\tan\phi\) 只有 139 kN/m，\(cL\) 有 566 kN/m；c 降低直接拿走大部分抗力。

6. 水平地震力為什麼會「兩邊夾擊」？

它在傾斜滑動面上有平行分量（增加下滑）與垂直分量（把塊體拉離滑動面，減少正向力與摩擦）。2008-4 從 1.02 降到 0.74。

7. 垂直滑動面的地錨，為什麼每 1 kN 只換到 \(\tan\phi\) kN 抗力？

它只增加正向力，抗力增量 \(=P\tan\phi\)。往上坡傾斜的地錨同時抵銷下滑力，效率較高。

8. 三塊法中，夾層的抗力為什麼不用正向力乘摩擦係數？

夾層是軟弱黏土，用不排水強度 \(s_u\)（\(\phi=0\)），抗力 \(=s_uL\)，與正向力無關。

9. 2006-3 豪雨時有效主動土壓變小，FS 為什麼反而從 1.22 降到 0.47？

有效土壓由 351 降到 126，但主動側多了 706 kN/m 的靜水壓；水的 \(K=1\)，遠大於土的 \(K_A=1/3\)。

10. 切片法的 \(\alpha_n\) 是什麼角？

切片底面的傾角，等於圓心到切片底中點的半徑與鉛直線的夾角；圓心正下方的切片 \(\alpha=0\)，只提供抗力。

11. 普通切片法為什麼通常比 Bishop 保守？

它忽略切片間力，少算了相鄰切片推擠所增加的正向力與摩擦；Bishop 計入切片間水平力，以每片鉛直力平衡求正向力。

12. 邊坡穩定對策裡，為什麼「排水」通常排第一？

水同時降低有效正向應力、產生滲流力或靜水推力、軟化強度；排水一次處理多個機制，且成本最低。

§11.5　因果鏈重列

  1. c = 0 無限邊坡：平行切片 → \(z\) 約掉 → \(\tan\phi/\tan\beta\) → 浸水不變、滲流乘 \(\gamma'/\gamma_{sat}\)。
  2. c′-φ′＋滲流：鉛直深度 → 三相換算 → \(\sigma_v\) 分層 → \(\tau=\sigma_v\sin\beta\cos\beta\) → \(u=\gamma_wh_w\cos^2\beta\) → \(\sigma_n'\) → FS。
  3. 平面楔體：角度 → 面積、\(L\) → \(W\) → 分解 → \(cL+N\tan\phi\) → c 主導淺層。
  4. 地震與地錨：正弦定理 → \(W\) → \(k_hW\) 兩方向分解 → FS → 反算 \(P\) → 乘間距。
  5. 三塊法：軟弱層 → 主動楔（裂縫）＋中間 \(s_uL\)＋被動楔 → 有水加靜水壓 → FS。
  6. 切片法：量圖列表 → \(W\)、\(\alpha\)、\(\Delta L\)、\(u\) → Fellenius 直接算（Bishop 迭代）→ 寫量測不確定度。
