## SM-2004-3 重力式擋土牆滑移時之地下水位高度

**(a)** 牆高 6 m，可抗水平推力 146 kN/m；回填 $c$ = 0、$\gamma_t=\gamma_{sat}$ = 19.2、φ = 35°；δ = 0、無毛細；求水位高度 x（由牆底起算）使牆滑移。

**(c) 盲分類**：主 SM-U3-1；副 SM-U3-2。

**(d) 計算**
- $K_a=\tan^2(27.5°)$ = **0.2710**。
- $P_h(x)=\tfrac12K_a\gamma(H-x)^2+K_a\gamma(H-x)x+\tfrac12K_a\gamma'x^2+\tfrac12\gamma_wx^2$，$\gamma'$ = 9.39。
- $P_h(0)$ = 93.65 kN/m（< 146）；$P_h(6)$ = 222.4 kN/m（> 146）。
- 解 $P_h(x)$ = 146：**x = 3.83 m**（數值積分複核 146.000）。$\gamma_w$ = 10：x = 3.79 m。

**答案**：水位升至牆底以上約 **3.8 m**（地表下約 2.2 m）時，總水平推力達 146 kN/m，開始滑移。

**(f)**：無重大疑義（δ = 0、Rankine、水壓全計）。

## SM-2010-2 砂土＋黏土層 Rankine 主動土壓分布

**(a)** 8 m 垂直牆背；0～4 m 砂（$\gamma_{dry}$ = 17、$\gamma_{sat}$ = 18、φ = 30°），4 m 以下黏土（$\gamma_{sat}$ = 17.5、$c$ = 30）；水位地表下 2 m。

**(b)** 黏土 φ = 0（判讀 #1 定案，總應力法，$K_a$ = 1）；0～2 乾砂、2～4 水下砂、4～8 黏土。

**(c) 盲分類**：主 SM-U3-1。

**(d) 壓力分布**（z 由地表向下）
- 砂 $K_a$ = 1/3：z = 2：$\sigma'_v$ = 34 → $\sigma'_a$ = **11.33 kPa**；z = 4⁻：$\sigma'_v$ = 34 + 2(18−9.81) = 50.38 → **16.79 kPa**；水壓 z = 4：**19.62 kPa**。砂底總側壓 36.41 kPa。
- 黏土（φ = 0，總應力）：$\sigma_h=\sigma_v-2c_u$；z = 4⁺：$\sigma_v$ = 70 → **10.0 kPa**；z = 8：$\sigma_v$ = 140 → **80.0 kPa**（黏土頂未出現負值，無張力區）。介面處側壓由 36.41 跳降至 10.0。
- 若黏土段也把水壓分開畫：有效部分 $\sigma'_v-2c$ = −9.62 → 21.14 kPa（z = 5.25 m 處為 0），加水壓 19.62 → 58.86 kPa，總和與上式完全相同。

**合力**（作用位置量自牆底）

| 分項 | 合力 (kN/m) | 作用點 (m) |
|---|---|---|
| 砂 0～2 m 三角形土壓 | 11.33 | 6.667 |
| 砂 2～4 m 有效土壓（梯形 11.33→16.79） | 28.13 | 4.935 |
| 砂 2～4 m 水壓（0→19.62） | 19.62 | 4.667 |
| 黏土 4～8 m 總側壓（10→80） | 180.00 | 1.481 |
| **合計** | **239.1** | **2.40** |

- 交叉驗算：全高總側壓數值積分 239.08 kN/m、作用點 2.395 m（與分項相同）。另一分法（水壓 2～8 m 全段 176.58 @ 2.00；黏土有效 23.04 @ 0.22）合計亦 239.08。
- $\gamma_w$ = 10：239.3 kN/m @ 2.40 m。

**答案**：總主動推力 ≈ **239 kN/m**，作用於牆底以上 ≈ **2.40 m**。

**(f) 不確定處 ❓**
- 若黏土段採「有效應力＋水壓分開」並把負的 $\sigma'_v-2c$（4～5.25 m）設為 0：合計 245.1 kN/m @ 2.42 m。
- 若黏土另有 φ' > 0（題未給）則數值不同；主線依判讀 #1。

## SM-2015-2 黏土＋砂層 Rankine 土壓與重力牆抗滑

**(a)** 0～4 m NC 黏土（$\gamma_{dry}$ = 17.5、φ = 20°、c = 20），4～8 m 砂（$\gamma_{sat}$ = 18.5、φ = 30°），水位 4 m；牆高 8 m、頂寬 1.0、底寬 3.0、牆前埋 1.0 m、$\gamma_c$ = 23。

**(b)** 定案：牆底 δ = 2φ/3 = 20°；計入牆前 1.0 m 被動土壓並列不計對照；FS 要求 1.5；黏土張力區需自行說明（判讀 #8）。

**(c) 盲分類**：主 SM-U3-1；副 SM-U3-2。

**㈠ 土壓分布**
- 黏土 $K_a=\tan^2 35°$ = 0.4903，$\sqrt{K_a}$ = 0.7002：頂 $\sigma_a$ = −2c√Ka = **−28.0 kPa**；z = 4⁻：70×0.4903 − 28.0 = **6.31 kPa**；張力裂縫深 $z_c=2c/(\gamma\sqrt{K_a})$ = **3.26 m**。
- 砂 $K_a$ = 1/3：z = 4⁺：70/3 = **23.33 kPa**；z = 8：(70 + 4×8.69)/3 = **34.92 kPa**；水壓 z = 8：**39.24 kPa**。
- 合力（張力區不計，視為開裂；作用點量自牆底）：

| 分項 | 合力 (kN/m) | 作用點 (m) |
|---|---|---|
| 黏土 3.26～4 m 三角形 | 2.32 | 4.245 |
| 砂 矩形 23.33×4 | 93.33 | 2.000 |
| 砂 三角形 | 23.17 | 1.333 |
| 水壓 | 78.48 | 1.333 |
| **合計** | **197.3**（土壓 118.8） | **1.68** |

- 若計入張力區（−45.7）：151.6 kN/m（不保守，不採）。$\gamma_w$ = 10：198.3 kN/m @ 1.68 m。

**㈡ 抗滑**
- 牆重：斷面 = 3×1（埋入段）+ (3+1)/2×7 = 17 m² → $W$ = **391 kN/m**（牆背 δ = 0，土壓無鉛直分量）。
- 主線：$F_r=W\tan20°$ = 142.3；被動（牆前 1 m，水位取牆前地面，$\gamma'$ = 8.69，$K_p$ = 3）$P_p$ = 13.0 + 前側水壓 4.9 → $FS$ = (142.3+13.0+4.9)/197.3 = **0.81**。
- 不計被動：0.72；被動用 $\gamma_{sat}$ 不分水：0.86；δ = φ = 30°：1.14～1.29；再計牆底揚壓力（踵 4 m 水頭、趾 1 m 水頭線性，U = 73.6 kN/m）：δ = 20° 時 0.59。

**答案**：㈠ 主動合力 ≈ **197 kN/m**（含水壓 78.5），作用於牆底以上 ≈ **1.68 m**；張力裂縫深 3.26 m。㈡ $FS_{滑}$ ≈ **0.8** < 1.5（所有假設組合皆 < 1.5）→ **不恰當**，需加寬牆底、設止滑榫、排水降低水壓等。

**(f) 不確定處 ❓**：牆底摩擦、被動土壓、揚壓力與水位在牆前的假設皆題未給，數值 0.59～1.29 但結論一致。

## SM-2019-4 有張力裂縫之 Coulomb 主動土楔力多邊形（符號題）

**(a)** 牆背與鉛直夾 θ（牆背向填土側傾）、填土坡 α、土 γ、c、φ；牆土介面 $c_a$、δ；裂縫 DE（沿牆背）、BF（鉛直），縫內無水；破壞面 AB 與水平夾 β。

**(c) 盲分類**：主 SM-U3-1。

**㈠ 張力裂縫最大深度**
- 主動側壓為零的深度：$Z_t=\dfrac{2c}{\gamma\sqrt{K_a}}=\dfrac{2c}{\gamma}\tan\!\left(45°+\dfrac{\phi}{2}\right)$，$K_a=\tan^2(45°-\phi/2)$。
- 補充：考慮牆土黏著時常用 $Z_t=\dfrac{2c\sqrt{1+c_a/c}}{\gamma\sqrt{K_a}}$（Craig／BS 8002 形式）；坡面 α ≠ 0 時嚴格解（Mazindrani–Ganjali）較複雜，考試一般用上式近似。❓

**㈡ 力多邊形（作用於土楔 ABFED）**
座標：x 向填土側（右）、y 向上。各力：
1. $W=\gamma\times$ 面積(ABFED)，**鉛直向下**（含兩裂縫之間的土體）。
2. $C=c\cdot\overline{AB}$，沿破壞面向上（指向 B），與**水平夾 β**（BF 段無黏聚力）。
3. $C_a=c_a\cdot\overline{AD}$，$\overline{AD}$ 為裂縫底以下牆背長；沿牆背向上作用於土楔，與**鉛直夾 θ**（DE 段無黏著、無土壓）。
4. $R$：AB 面上的反力，與 AB 法線夾 φ，與**鉛直夾 (β−φ)**，偏向牆側。
5. $P_a$：牆對土楔的反力，與牆背法線夾 δ，與**水平夾 (θ+δ)**、斜向上指向填土；作用於牆的主動推力方向相反（斜向下、與水平夾 θ+δ）。
- 已知 $W$、$C$、$C_a$（大小方向），$R$、$P_a$ 只知方向。作圖：依序首尾相接畫 $W$（向下）→ $C_a$ → $C$，再由起點與終點分別畫 $P_a$、$R$ 的方向線，交點閉合。
- 閉合式（sympy 解）：
$$P_a=\frac{W\sin(\beta-\phi)-C\cos\phi-C_a\sin(\beta-\phi-\theta)}{\cos(\beta-\phi-\theta-\delta)}$$
  驗證：θ = α = δ = $c_a$ = 0 時退化為 Rankine 三種情形（見方法）。

**㈢ 主動推力**
- 改變 β（試楔法／Culmann 圖解），對每個 β 畫力多邊形求 $P_a(\beta)$，取 **最大值** 即為主動推力（$dP_a/d\beta$ = 0）；作用於牆背 AD 段，方向與牆背法線夾 δ（與水平夾 θ+δ 斜向下）。
- 數值示例（自設 H = 6、γ = 18、c = 10、φ = 25°、α = θ = 10°、δ = 15°、$c_a$ = 5）：$Z_t$ = 1.74 m，β 掃描得 $P_{a,max}$ = 92.9 kN/m @ β = 55.6°（力多邊形閉合殘差 ~0）。
- 作用點：近似取牆背有壓力段（AD）的 1/3 高處，或由試楔分段求導。

**(f) 不確定處 ❓**：㈠ 是否計入 $c_a$ 及坡面對 $Z_t$ 的修正，教材寫法不一。
