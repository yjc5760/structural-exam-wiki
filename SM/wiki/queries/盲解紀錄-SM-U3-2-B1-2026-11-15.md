## SM-2009-4 重力式擋土牆：合力在 B/3 求底寬，檢核滑動與傾倒

**(a) 題意摘要**：梯形重力牆，牆背鉛直、牆面傾斜，$H$ = 6 m、頂寬 0.6 m；背填砂 $\gamma$ = 18、$\phi$ = 30°、地表 20° 上傾；混凝土 24；基礎土 $\gamma$ = 16、$\phi$ = 33°。㈠合力過牆底距趾 $B/3$ 求 $B$；㈡滑動、傾倒 FS 與改善方式。

**(b) 判讀要點（照題目正本）**：Rankine 傾斜地表（#1），$P_a$ 平行地表（20°）作用於牆背鉛直面、高 6 m、作用點 $H/3$；牆底介面摩擦角取 33°、黏著 0（#2），另附 $\tfrac23\phi$ = 22°；牆前無埋入、無被動。

**(c) 盲分類**：主 SM-U3-2；副 SM-U3-1（側向土壓力）。

**(d) 計算**
- $K_a=\cos20^\circ\dfrac{\cos20^\circ-\sqrt{\cos^2 20^\circ-\cos^2 30^\circ}}{\cos20^\circ+\sqrt{\cdots}}$ = **0.4142**
- $P_a=\tfrac12(18)(6^2)(0.4142)$ = 134.20 kN/m；$P_h$ = 126.11、$P_v$ = 45.90 kN/m（$P_v$ 作用於牆背，力臂 $B$）
- 牆重：矩形 $0.6\times6\times24$ = 86.4 kN（力臂 $B-0.3$）；三角形 $\tfrac12(B-0.6)(6)(24)$（力臂 $\tfrac23(B-0.6)$）
- 條件 $(\Sigma M_R-\Sigma M_O)/\Sigma V = B/3$ → **$B$ = 2.49 m**
  - $W$ = 222.48、$\Sigma V$ = 268.38 kN/m；$\Sigma M_R$ = 474.98、$M_O=P_h\cdot2$ = 252.22 kN·m/m；$\bar x$ = 0.830 = $B/3$ ✓，$e=B/6$ = 0.415 m
- ㈡ 抗滑：$FS_s=\Sigma V\tan\delta/P_h$
  - $\delta$ = 33°：**1.38**（< 1.5，不足）
  - 對照 $\delta=\tfrac23\phi$ = 22°：0.86
- ㈡ 抗傾倒（對趾）：$FS_o=\Sigma M_R/\Sigma M_O$ = **1.88**（< 2.0，不足；合力恰在中央三分之一邊緣，以「合力在中央 1/3」準則則恰好合格）
  - 對照（$P_v$ 力矩改為抵減 $M_O$）：$360.7/(252.2-114.3)$ = 2.62

**(e) 雙路徑**：① 對 $B/3$ 點取矩，殘差 ≈ 0（−3×10⁻¹⁴）✓。② 以 Coulomb、牆背鉛直、$\delta=\alpha$ = 20° 計算 $K_a$ = 0.4142，與 Rankine 傾斜地表解完全相同（已知恆等），$B$、FS 全同 ✓。

**改善方式（不改底寬）**：牆底設剪力鍵（shear key）引入被動抗力；牆前回填／加深埋入增加被動土壓；牆背改為向背填側傾斜（battered back）或加高牆身頂寬以增加自重（含牆背上方土重）；背填改用輕質材料或降低背填坡度、牆頂削坡；背填排水（排水層、洩水孔）防止水壓；地錨／拉桿；牆底置換級配料或粗糙化提高介面摩擦；必要時改懸臂／扶壁式。

**(f) 不確定處 ❓**：土壓理論（Rankine vs Coulomb 含 $\delta$）、牆底 $\delta$（33° vs 22°）、$P_v$ 是否計入抵抗力矩——主線如上，替代值已列。滑動 FS 1.38 與 0.86 均 < 1.5，結論（不足）不受影響；傾倒依準則不同可能判「恰好合格」。

## SM-2013-1 綜合問答（順向坡試驗、波動方程式、Rankine vs Coulomb、加勁土壤檢核）

**(c) 盲分類**：主 SM-U3-2（㈣）；副 SM-U3-1（㈢）、SM-U4（㈡樁）、SM-U5 邊坡（㈠）——副分類代號以 `syllabus_taxonomy.json` 實際子項為準（本盲解未開大綱，比對時再對）。

**得分要點**
- ㈠ 順向坡試驗：
  1. 現地調查：鑽探取樣、岩心（RQD）、層面／弱面位態量測（走向、傾角、與坡面夾角）、地表地質測繪、地下水位觀測（水壓計）、傾度管。
  2. 弱面（層面、泥質夾層）剪力強度：**直接剪力試驗**（沿層面，含尖峰與殘餘強度；必要時現地大型直剪）、傾斜試驗（tilt test）求基本摩擦角、JRC／JCS（Barton）。
  3. 完整岩石：單軸壓縮、點荷重、三軸試驗；單位重、含水量、比重；泥岩／頁岩之消散耐久（slake durability）試驗。
  4. 夾層土：阿太堡限度、粒徑、三軸 CU／CD（有效參數 $c'$、$\phi'$）、殘餘強度（環剪）。
  5. 透水性（現地透水試驗）供孔隙水壓估計；地震分析需動態參數。
- ㈡ 波動方程式原理：
  1. 打樁為應力波傳遞問題，以一維波動方程 $\partial^2u/\partial t^2=c^2\partial^2u/\partial x^2$（$c=\sqrt{E/\rho}$）描述。
  2. Smith 模式：錘、墊、樁離散為質量–彈簧，土壤阻抗以彈塑性彈簧（quake）＋阻尼（Smith damping）表示，分樁身摩擦與樁尖。
  3. 假設極限阻抗 $R_u$ 與分佈，數值模擬每擊貫入量（set）→ 繪「$R_u$–每擊貫入量（或每 m 擊數）」承載力曲線（bearing graph），以實測貫入量反求 $R_u$；同時求打樁應力檢核。
  4. 實測應用：PDA 動態量測（應變計＋加速度計）得力與速度，以 CASE 法或 CAPWAP 訊號擬合求承載力；需考慮土壤凍結／鬆弛（setup/relaxation），以再打（restrike）確認。
- ㈢ Rankine vs Coulomb：
  1. Rankine：土體達塑性平衡應力狀態（應力法），假設牆背光滑（$\delta$ = 0）、牆背鉛直、半無限土體；傾斜地表時土壓平行地表。
  2. Coulomb：楔體極限平衡（力法），假設平面滑動面，可考慮牆背摩擦 $\delta$、牆背傾角 $\beta$、地表傾角 $\alpha$；土壓與牆背法線夾 $\delta$。
  3. 主動時兩者接近（Coulomb 略小）；被動時 Coulomb 平面滑動面在 $\delta$ 大時高估 $K_p$（不保守），宜用對數螺旋法。
  4. Rankine 可求土壓分佈；Coulomb 只求合力（作用點另假設 H/3）。$\delta=\alpha$、牆背鉛直時兩者相同。
  5. 適用：懸臂式牆用虛擬背（通過踵端鉛直面）配 Rankine；重力式牆背有摩擦用 Coulomb。
- ㈣ 加勁土壤結構物檢核：
  1. 外部穩定：滑動、傾倒（偏心 $e\le B/6$ 或 FS）、基礎承載力、整體穩定（深層滑動，含通過加勁區外的圓弧）、沉陷（含差異沉陷）。
  2. 內部穩定：加勁材拉斷（抗拉強度，考慮施工損傷、潛變、耐久折減）、拉出（錨定段在主動破壞區外之抗拉出長度）、面板與加勁材連接強度、面版／牆面局部穩定（凸出 bulging、單元滑移）、複合破壞（通過加勁區內部與外部）。
  3. 地震條件（M–O 動態土壓、加勁區慣性力）、排水與孔隙水壓、長期耐久（金屬腐蝕、地工合成材料老化）。

## SM-2016-4 混凝土重力式擋土牆（Coulomb、承載、M–O）

**(a) 題意摘要**：$H$ = 8 m、頂寬 3、底寬 5（牆面鉛直、牆背斜），$\gamma_c$ = 23.5；背填 $\gamma$ = 18、$\phi'$ = 30°、$\delta_B$ = 15°、$\alpha$ = 0；牆底 $c_a$ = 15、$\delta_F$ = 18°；基礎 $c'$ = 20、$\phi'$ = 30°、$\gamma$ = 18、$N_c$ = 30.14、$N_\gamma$ = 22.4；$K_h$ = 0.15、$K_v$ = 0.05。

**(c) 盲分類**：主 SM-U3-2；副 SM-U3-1、淺基礎承載力子項、耐震土壓力（代號以大綱為準）。

**(d) 計算**
- ㈠ 庫倫 $K_a$（考卷註式）= **0.4148**（核對：$\beta$ = 90° 時 0.301，牆背外斜使楔體變大 → $K_a$ 增大，合理）

- **$FS_{滑動}=(\Sigma V\tan18^\circ+15\times5)/P_h$ = 1.71**（≥ 1.5 OK；不計 $c_a$ 時 1.35）

## SM-2022-2 加勁擋土結構概述與內穩定 5 種破壞模式（說明題）

**(c) 盲分類**：主 SM-U3-2。

**得分要點（前段 10 分）**
1. 定義：在填土中分層鋪設抗拉加勁材，與土壤形成複合材料，以面板＋加勁土體構成重力式擋土結構（MSE wall／RSS）。
2. 原理：土壤抗壓不抗拉；加勁材藉與土的界面摩擦（及被動承壓）提供張力，限制土體側向變形——(a) 視為增加圍壓（擬似凝聚力 $\Delta c=\frac{T}{2S_v}\sqrt{K_p}$ 概念）；(b) 錨定作用：主動區土壓由加勁材傳至穩定區（抗拉出）。
3. 加勁材料種類：金屬（鍍鋅鋼帶、鋼格網／焊接鋼網）；地工合成材料（地工格網 geogrid——HDPE 單軸、PP 雙軸、PET 編織格網；地工織物 geotextile；地工帶 geostrip）；其他（纖維、輪胎、竹材等）。可伸展（extensible）與不可伸展（inextensible）之分影響主動區形狀（雙線性 vs Rankine 線）。
4. 依使用目的之結構種類：加勁擋土牆（陡於 70°，有面板：混凝土面板、模塊磚 segmental block、包覆式、鋼網籠／蛇籠面）；加勁邊坡（緩於 70°，植生面）；橋台（承重式加勁橋台、GRS-IBS）；堤防／護岸、道路拓寬、崩塌復建、隔音堤、防落石堤等。

**後段 15 分：內穩定 5 種破壞模式（各附示意圖：牆剖面＋潛在破壞面＋加勁材）**
1. **加勁材拉斷（tensile rupture）**：加勁材承受之最大張力 $T_{max}=\sigma_hS_v$ 超過長期設計強度（考慮施工損傷、潛變、耐久折減）→ 斷裂，常發生於下層（側壓大）。原因：強度不足、間距過大、潛變／腐蝕。
2. **加勁材拉出（pull-out）**：主動區外（錨定段）長度 $L_e$ 之界面摩擦抵抗 $2L_e\sigma'_vF^*\alpha$ 不足 → 拔出，常發生於上層（覆土壓小）。原因：加勁長度不足、回填土摩擦差、含水量高。
3. **面板與加勁材連接破壞（connection failure）**：連接強度不足或面板處張力集中 → 連接處斷裂、面板外傾或脫落。原因：連接設計不當、面板處壓實不足沉陷產生下拉力。
4. **面板局部破壞／凸出（facing bulging／局部滑移）**：加勁材間距過大，面板間土體局部擠出、模塊磚間剪力不足而錯動，或面板本身彎曲破壞。原因：垂直間距過大、面板剛度不足、排水不良水壓。
5. **內部滑動（internal sliding）／複合破壞**：沿加勁材層面（土—加勁材界面，尤其地工織物）的直線滑動，或滑動面部分穿過加勁區、部分在加勁區外的複合破壞。原因：界面摩擦係數低、加勁材長度不足或上下層長度不一、背填排水不良。
（可另提：加勁材潛變過大變位、施工損傷、腐蝕等劣化屬長期內穩定問題。）
