## SM-2009-2 部分代償式筏基埋深與開挖隆起

**(a)** 筏基 $B$ = 8 m、$L$ = 12 m、$Q$ = 18 MN；NC 黏土 $\gamma_{sat}$ = 17、$c_u$ = 35 kPa，地表下 12 m 為砂土；水位地表下 3 m。㈠部分代償、FS = 3 求 $D_f$；㈡坑內水位抽至坑底，求抗隆起 FS。

**(b)** 全層 $\gamma$ = 17（判讀 #5）；φ = 0 總應力分析，覆土壓力 $\gamma D_f$ 為總應力；㈡主線為剪力型底面隆起（判讀 #1 定案），上舉另列。

**(c) 盲分類**：主 SM-U2-1；副 SM-U2-3。

**(d) 計算**
- $Q/A$ = 18000/96 = **187.5 kPa**。FS 定義（部分代償）：$FS=\dfrac{q_{net,u}}{Q/A-\gamma D_f}$。
- 主線（Das 補償式基礎式）：$q_{net,u}=5.14c_u(1+0.195B/L)(1+0.4D_f/B)$ → 解 $FS$ = 3：**$D_f$ = 5.87 m**（$q_{net,u}$ = 263.0、$q_{net}$ = 87.7 kPa）。
- 對照（Skempton $N_c=5(1+0.2D_f/B)(1+0.2B/L)$）：$D_f$ = 6.51 m。完全代償 $D_f$ = 187.5/17 = 11.03 m（參考）。
- ㈡（$H=D_f$ = 5.87 m，坑底至砂土 6.13 m）：
  - Bjerrum–Eide（以 Skempton 式近似 $N_c=5(1+0.2H/B)(1+0.2B/L)$ = 6.50）：$FS=c_uN_c/(\gamma H)$ = 227.4/99.8 = **2.28**。
  - 交叉：Terzaghi 法（硬層深 6.13 m > 0.7B = 5.6 m，用 0.7B）：$FS=\dfrac{5.7c_u}{H(\gamma-c_u/0.7B)}$ = **3.16**。
  - 補充（上舉）：若砂土水頭為外側靜水（水位 3 m）：$u$ = 9×9.81 = 88.3 kPa、坑底下黏土重 17×6.13 = 104.2 → FS = 1.18（偏低，宜降壓）。
- 若㈠採 Skempton（$D_f$ = 6.51）：㈡ Bjerrum–Eide 2.08、Terzaghi 2.88、上舉 1.06。

**答案**：㈠ $D_f\approx$ **5.9 m**（Skempton 6.5 m）；㈡ 抗隆起 FS ≈ **2.3**（Bjerrum–Eide；Terzaghi 3.2），> 一般要求 1.5～2.0 → 可；砂土上舉 FS ≈ 1.2 偏低（補充）。

**(f) 不確定處 ❓**：承載力式（Das／Skempton／Meyerhof 深度因數）不同，$D_f$ 在 5.9～6.5 m；㈡隆起公式選擇使 FS 在 2.1～3.2。題目未給隆起法，答案對方法敏感。

## SM-2010-4 方型基腳短期承載力與水位下降影響

**(a)** $B$ = 4 m 方形，$D_f$ = 2 m（砂 $\gamma_t$ = 16），下為 OC 黏土 $\gamma_{sat}$ = 17.5、$c_u$ = 60；水位在基底；FS = 3；提示 $F_{sc}=1+0.2B/L$、$F_{dc}=1+0.2D_f/B$。

**(b)** 短期 φ = 0（判讀 #1）；容許承載以淨承載加回覆土為主、總承載/FS 對照（判讀 #2）。

**(c) 盲分類**：主 SM-U2-1；副 SM-U1-5。

**(d) 計算**
- $q=\gamma_tD_f$ = 32 kPa；$F_{sc}$ = 1.2、$F_{dc}$ = 1.1；$N_c$ = 5.14、$N_q$ = 1、$N_\gamma$ = 0。
- $q_{net,u}=c_uN_cF_{sc}F_{dc}$ = 60×5.14×1.2×1.1 = **407.1 kPa**；$q_u$ = 439.1 kPa。
- 主線：$q_a=q_{net,u}/3+q$ = 135.7 + 32 = **167.7 kPa**，$Q_a$ = 167.7×16 = **2683 kN**（淨容許 135.7 kPa、淨載重 2171 kN）。
- 對照：$q_a=q_u/3$ = 146.4 kPa → 2342 kN。
- 水位下降 4 m（至基底下 4 m = B）：
  - **短期**：φ = 0 時 $q_u=c_uN_cF_{sc}F_{dc}+q$，與基底下單位重無關（$N_\gamma$ = 0），基底以上覆土在水位以上不受影響 → 短期承載力與 FS **不變**（3.0）。長期而言，基底下有效應力增加最多 $4\gamma_w$ ≈ 39 kPa，黏土再壓密後 $c_u$ 可能略增（OC 土若仍在 $\sigma'_p$ 以下則增量小）→ FS 略增。
  - **長期（排水，$c'$、$\phi'$）**：基底下 B 範圍內單位重由 $\gamma'$ ≈ 7.7 變為 ≈ 17.5，$N_\gamma$ 項約加倍、$q$ 項不變 → 長期承載力與 FS **增加**。示例（自設 $c'$ = 0，$\phi'$ = 25°，Meyerhof 因數）：$q_u$ 678 → 806 kPa，FS 4.05 → 4.81；$\phi'$ = 28°：5.87 → 7.04。
  - 負面：有效應力增加造成額外壓密沉陷（OC 黏土量小）、鄰房與管線沉陷；水位回升時恢復原狀況，設計應以高水位控制。

**答案**：$q_a$ ≈ **168 kPa**（$Q_a$ ≈ 2680 kN；總/FS 對照 146 kPa）；水位下降：短期承載力與 FS 不變（長時間可能因壓密略增），長期承載力與 FS 增加，但伴隨額外沉陷。

**(f) 不確定處**：容許承載定義（淨／總）；長期參數考卷未給，只能定性或自設示例。

## SM-2017-3 平鈑載重試驗設計 2 m×2 m 基腳（砂土）

**(a)** 0.3 m 平鈑試驗於坑底（$D_f$ = 1.0 m，回填 $\gamma_m$ = 18 → $q_0$ = 18 kPa）；㈠ 承載力控制 FS = 2 求 $Q_a$ 與沉陷；㈡ 沉陷 1 cm 求 $Q_a$；㈢ 比較表。

**(b)** 定案讀法：砂土沉陷換算主線用 Terzaghi–Peck $(2B/(B+P))^2$ = 3.025，考卷式 $(B/(B+P))^2$ = 0.756 列對照（判讀 #1）；$Q_a=(q_a-q_0)A$（判讀 #2）；$q_{ult}$ 取 ΔH = 2.54 cm（判讀 #3）。

**(c) 盲分類**：主 SM-U2-1。

**(d) 自行讀值**（見方法）：

| ΔH (cm) | 0.331 | 0.5 | 0.864 | 1.0 | 1.322 | 2.0 | 2.54 | 3.0 | 3.95 |
|---|---|---|---|---|---|---|---|---|---|
| q (kN/m²) | 61.8 | 83.4 | 119.3 | 130.4 | 153.8 | 195.0 | 219.8 | 234.4 | 247.6 |

格線交點核對：曲線過 q = 100 於 ΔH ≈ 0.65 cm、過 q = 200 於 ≈ 2.1 cm、終點 ≈ (250, 3.96)。曲線至 4 cm 無陡降，不需外插；$q_{ult}$ 直接讀於 2.54 cm（無外插假設）。

**㈠ 承載力控制**
- $q_{ult}$（平鈑）≈ **220 kN/m²**；$q_{a,平鈑}=q_0+(q_{ult}-q_0)/2$ = 18 + 100.9 = **118.9 kN/m²**。
- $q_{a,基腳}=q_{a,平鈑}\cdot B/P$ = 118.9×2/0.3 = **792 kN/m²**；$Q_a=(q_a-q_0)A$ = (792−18)×4 = **≈ 3100 kN**（毛值 $q_aA$ = 3170 kN）。讀值 ±5 → $Q_a$ 3030～3160 kN。
- 沉陷：平鈑在 $q$ = 118.9 時 ΔH = 0.86 cm → 基腳（T&P ×3.025）= **2.6 cm**；照考卷式（×0.756）= 0.65 cm。
- 對照（先把 $q_{ult}$ 放大 B/P 再除 FS）：$q_a$ = 18 + (1465−18)/2 = 740 → $Q_a$ ≈ 2890 kN。

**㈡ 沉陷控制（基腳 1 cm）**
- T&P：平鈑 ΔH = 1/3.025 = 0.331 cm → $q$ ≈ **62 kN/m²**（±5）；同一接觸壓力下換算，$q_a$ = 62 → $Q_a=(62-18)\times4$ ≈ **176 kN**（毛值 247 kN；讀值 ±5 → 156～196 kN）。
- 照考卷式：平鈑 ΔH = 1/0.756 = 1.32 cm → $q$ ≈ 154 → $Q_a$ ≈ 543 kN（毛值 615）。

**㈢ 表 3-1**

| 砂土地盤 | 2m×2m 基腳 | $Q_a$ (kN) | ΔH (cm) |
|---|---|---|---|
| | 承載力控制（FS = 2） | ≈ 3100 | ≈ 2.6（考卷式 0.65） |
| | 沉陷量控制（ΔH = 1 cm） | ≈ 176（考卷式 ≈ 543） | 1.0 |

結論：沉陷控制遠為嚴格；精密廠房對沉陷敏感，應採沉陷量控制設計（或改良地盤／改筏基）。

**(f) 不確定處 ❓**
- ㈠「對應之沉陷」：主線取平鈑在 $q_{a,平鈑}$ 下的沉陷再換算（考卷框架）；嚴格的同壓力換算要求平鈑在 792 kPa 下的沉陷，已超出曲線範圍，無法讀取。
- ㈡ 若錯把 $q$ 也乘 B/P：T&P 1581 kN、考卷式 4074 kN（不合理，不採）。
- $Q_a$ 是否扣 $q_0$：毛值與淨值差 72 kN。

## SM-2020-4 條形基礎短期承載安全檢核

**(a)** $B$ = 1.25 m、$D_f$ = 0.5 m、基礎厚 0.5 m；粉土質黏土 $q_u$ = 100 kPa（$c_u$ = 50）、$\gamma$ = 18.8，水位地表；牆載 120 kN/m。

**(b)** 定案：FS = 3（現行規範常時）；120 kN/m 為牆傳來荷重，基礎超重 $(\gamma_c-\gamma)D_fB$（$\gamma_c$ = 24）另計。

**(c) 盲分類**：主 SM-U2-1。

**(d) 計算**
- $q=\gamma D_f$ = 9.4 kPa；條形 $s_c$ = 1；φ = 0：$N_c$ = 5.14、$N_q$ = 1。
- 主線（$d_c=1+0.4D_f/B$ = 1.16）：$q_{net,u}$ = 5.14×50×1.16 = **298.1 kPa**。
- 淨施加壓力 $q_{net}=[120+(24-18.8)(0.5)(1.25)]/1.25$ = **98.6 kPa**（總壓力 108.0 kPa）。
- $FS_{net}$ = 298.1/98.6 = **3.02** ≥ 3 → 可（勉強）；以總壓力定義 $FS$ = (298.1+9.4)/108 = 2.85。
- FS = 3 時容許牆載 ≈ 121 kN/m（略大於 120）。
- 方法敏感度：Skempton $N_c$ = 5(1+0.2×0.4) = 5.4 → FS 2.74；Terzaghi 5.7 → 2.89；不計深度因數 5.14 → 2.61。若 120 kN/m 已含基礎重：主線 FS 3.44。

**答案**：$FS\approx$ **3.0**（淨承載、含深度因數）→ 剛好滿足 FS = 3，可安全承載但無餘裕；改用其他承載力式 FS 2.6～2.9 則不足。❓結論對方法與自重假設敏感。

**(f) 不確定處 ❓**：結論處於臨界；長期（排水）承載力因未給 $c'$、$\phi'$ 未檢核（φ = 0 短期通常控制）。
