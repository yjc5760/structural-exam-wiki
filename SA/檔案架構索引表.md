## 二、資料夾結構

```
SA/
├── SUBJECT.md               ← 科目層設定（子項表、分析法、解題邏輯、CHANGELOG）
├── README.md                ← 冷啟動導覽
├── 知識庫使用說明書.md
├── index.html               ← 離線儀表板（暫用原 repo 版）
├── dashboard-data.js        ← 儀表板資料快照
├── scripts/                 ← SA 專屬腳本：gen_lecture_SA-*_figs.py（講義附圖）、fixes/（一次性修正）
├── 影片講義/                 ← 影片圖文講義（img/、video/）
│
├── study/                   ← 單元總覽、觀念講義、頻率熱圖、problems-view/、data/、assets/katex/
│
├── raw/
│   ├── exams/               ← SA-YYYY_結構學.pdf（24份）
│   ├── json/
│   │   ├── question_index.json   ← 題目總索引 ✏️
│   │   ├── concepts.json         ← 概念定義（備查）
│   │   └── syllabus_taxonomy.json ← 命題大綱分類樹（副本，正本在根目錄）
│   └── solutions/
│       ├── SA-YYYY-N/       ← 題目正本、解析、考卷附圖、gen_*.py、figs/
│       └── methods/         ← 解題方法論文件 ✏️
│
├── wiki/
│   └── queries/             ← 查詢結果、稽核／盲解報告、audit-ledger-SA.json、log.md（變更紀錄）
│
└── archive/
    ├── wiki/                ← 2026-11-01 封存的舊 wiki 各層（唯讀）
    └── exam-wiki-SA-root/   ← 搬入前原 repo 根目錄的 CLAUDE*.md、xcheck.py（唯讀參考）
```

> 共用腳本（render_problem_view、build_unit_page、build_frequency、xcheck、audit_classification…）在知識庫根目錄 `scripts/`。
