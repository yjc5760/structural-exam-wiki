§0　全景：這個單元只有一句話

建築結構系統分析，永遠是兩件事的對立：力想照「勁度」分配，但變形必須「相容」。
當被綁在一起的元件變形形狀相同，相容條件不惹事，力就照勁度比分；當變形形狀不同（剪力型 vs 彎曲型、近剛心 vs 遠剛心、剛性區 vs 連梁），相容條件會把力重新分配——分配比偏離勁度比、甚至反向。

所以每一題的第一步都不是算，而是回答：這幾個元件被什麼綁在一起、被迫哪幾個位移相同？五題考古題恰好是四種綁法：

剛性樓板整片樓板只剩 \(u_x, u_y, \theta\) 三個自由度SA-2021-4§4

為什麼值得先背這一句？本單元考題的數字都很小（2 × 2 矩陣、四根柱、反曲點在中點），難的從來不是計算，而是「該用哪個模型」。§7 的決策流程就是把這句話拆成三個問題。

§1　側向勁度的積木：\(12EI/h^3\) 從哪裡來

系統分析裡的每個「彈簧」，都是一根柱子在某種端部條件下的側推勁度。先把這塊積木的來源弄清楚，後面所有題目只是在組積木。

1.1　這條公式在怕什麼

怕的是你不看端部條件就套 \(12EI/h^3\)。柱的側推勁度完全取決於柱頂能不能轉：

  • 柱頂接剛性梁（\(I_{梁}=\infty\)，SA-2020-4、SA-2021-4 都明講）＋柱底固定：兩端都不轉。由傾角變位法，側移 \(\Delta\) 使兩端各產生 \(M = 6EI\Delta/h^2\)，剪力 \(V = 2M/h\)： $$k = \frac{V}{\Delta} = \frac{12EI}{h^3}$$
  • 柱頂自由轉動（懸臂）：\(k = 3EI/h^3\)，只有前者的 1/4。
圖 1-1　(a) 兩端不轉：變形曲線 \(v = \Delta(3\xi^2 - 2\xi^3)\)，反曲點恰在中點，彎矩反對稱；(b) 懸臂：\(v = \Delta(3\xi^2-\xi^3)/2\)，彎矩全在底部；(c) 彈簧的並聯與串聯。曲線由公式取 100 點繪製。
這張圖攔的錯：以為「柱頂有梁」就一定是 12；梁若不是剛性，柱頂會轉，勁度落在 3 與 12 之間。
數值核對（SA-2020-4）　\(EI = 81920\ \text{kN}\cdot\text{m}^2\)、\(h = 3.2\ \text{m}\)： $$k_c = \frac{12 \times 81920}{3.2^3} = 30000\ \text{kN/m}$$ 每層兩柱並聯 → \(K_{層} = 60000\ \text{kN/m}\)。SA-2021-4：\(EI = 9720\)、\(48600\)，\(h = 3.6\) → \(k = 2500\)、\(12500\ \text{kN/m}\)（1 : 5）。
出題者把 EI 調成整數勁度是常態——算出來不是整數，先回頭檢查是否把「\(\text{kN-m}^2\)」的 2 讀成係數（SA-2021-4 舊解就讀成了一半，2026-11-07 勘誤）。

1.2　積木怎麼組：並聯、串聯

  • 同一層的柱 = 並聯：位移相同、力相加 → \(K_{層} = \sum k_{柱}\)。
  • 上下疊的樓層 = 串聯：剪力相同、位移相加。剪力建築（梁剛性）的勁度矩陣因此是三對角： $$[K_f] = \begin{bmatrix} K_2 & -K_2 \\ -K_2 & K_1+K_2 \end{bmatrix}\quad(\text{自由度 1 = 頂層、2 = 一樓})$$
  • 兩個系統用連桿或剛性樓板綁成同位移 = 並聯：\([K] = [K_f] + [K_w]\)，矩陣直接相加。這就是 SA-2020-4 的全部做法。
極限檢查（不用背表）　\(h\) 加倍 → 勁度變 1/8：長柱非常軟，所以高低不等的柱並排時，矮柱吃掉大部分剪力。\(I_{梁} \to 0\) → 柱頂可自由轉 → 退化成 \(3EI/h^3\)。忘了係數時，用「兩端不轉 = 兩根懸臂背對背、各長 \(h/2\)」也能重建：\(3EI/(h/2)^3 \div 2 = 12EI/h^3\)（兩段串聯，柔度相加）。

更完整的傾角變位推導見 SA-U2-3 觀念講義；勁度矩陣的「單位位移實驗」見 SA-U2-4 觀念講義。

§2　剪力型 vs 彎曲型：兩種「長相」

構架和剪力牆都能抵抗水平力，但它們變形的形狀相反。這是 §3 互制作用的唯一來源。

剪力型（抗彎構架、剪力建築）
每層的層間位移只由該層的層剪力決定：\(\Delta_i = V_i / K_i\)。
層剪力由上往下累加，底層最大 → 底部層間位移最大、往上遞減。
整條曲線「下部就跑出去，上部收斂」。
彎曲型（貫通全高的剪力牆、細長核心筒）
像一根直立懸臂梁：某層的位移由全部樓層力對整根牆造成的彎曲決定。
底部斜率為零（固定），曲率由下往上累積 → 層間位移往上遞增。
整條曲線「下部很挺，上部才甩開」。
圖 2-1　同樣每層受 F：構架單獨（剪力型）、牆單獨（彎曲型）與兩者綁在一起的變形（各自除以頂層位移）。右圖是每層層間位移，兩者沿高度的趨勢恰好相反。數值來自 §3 的 8 層模型。
這張圖攔的錯：把「牆比較硬」當成全部的資訊。牆在下部比構架硬得多，但在上部，它自己的層間位移反而比構架大——所以上部輪到構架去「拉住」牆。
為什麼「樓層勁度」對牆不是定值？剪力型的 \(K_i = V_i/\Delta_i\) 跟載重分布無關；彎曲型牆的層間位移受上方所有樓層力的彎矩影響，同一層的「勁度」換一組載重就變。所以題目說「剪力牆提供的樓層水平勁度為構架 5 倍」，只能理解成一個整體平均比，不能拿來每層 1 : 5 分力（除非兩者都是剪力型）。

§3　牆–構架互制：下部牆扛、上部構架扛

連桿（兩端鉸、只傳軸力、不計軸向變形）強迫牆與構架每層位移相同。兩條「長相相反」的曲線被迫合成一條，合成的代價就是互相推拉的內力——連桿軸力。

3.1　定性推理（SA-2018-1 第㈡小題要你寫的）

  1. 下部：牆單獨時下部幾乎不動，構架單獨時下部跑很多。綁在一起，牆把構架往回拉 → 構架受反向（與外力相反）的力，牆承擔大於 F 的力。
  2. 上部：牆單獨時頂部甩很多，構架頂部增量小。綁在一起，構架把牆往回拉 → 牆頂受反向力，構架頂層承擔大於 F 的力。
  3. 每一層：構架力 ＋ 牆力 = F（樓層平衡，連桿力是內力）。
圖 3-1　SA-2018-1 樓層水平力分布（以 F 為單位）。牆 = 8 層懸臂撓曲梁（柔度矩陣求逆）、構架 = 剪力型樓層彈簧 k、「5 倍」取 \(12EI/h^3 = 5k\)；與解析正本 §4 示意數值逐一 assert。
這張圖攔的錯：把構架的反向力畫到一半樓層（舊解寫 1–5 樓，需要牆的 EI 比題設大一個數量級才會如此；2026-11-08 勘誤）；以及把頂層構架畫成小於 F。
題意的兩種讀法（SA-2018-1）　題文「樓層水平勁度為構架的 5 倍」「依此比例標畫」也可照字面讀成兩個剪力型彈簧，每層構架 F/6、牆 5F/6（圖 0-1 左）。正本採互制讀法（使用者 2026-11-08 判定），理由：第㈡小題要「解釋理由」，若只是均勻 1 : 5，一句話就說完，與 25 分不符。作答建議：以互制形狀為主答，並附一句「若僅依樓層勁度比則為 F/6、5F/6，但牆為彎曲型，實際分配沿高度改變」。反向力延伸到幾樓取決於「5 倍」怎麼換算成牆的 EI（取 \(3EI/h^3=5k\) 時構架 1、2 樓都反向、8 樓達 1.88F），所以只畫形狀、不寫精確樓層數。

3.2　定量版本：SA-2020-4 用 2 × 2 矩陣把同一件事算出來

SA-2020-4 直接給剪力牆勁度矩陣 \(30000\begin{bmatrix}1&-2\\-2&6\end{bmatrix}\)（若牆是剪力型，頂層對角項應等於非對角項的絕對值；這裡 1 ≠ 2，表示它不是樓層彈簧串成的，而是彎曲型懸臂濃縮出來的勁度）。構架是 §1 的剪力建築：

$$[K] = [K_f]+[K_w] = 30000\left(\begin{bmatrix}2&-2\\-2&4\end{bmatrix}+\begin{bmatrix}1&-2\\-2&6\end{bmatrix}\right) = 30000\begin{bmatrix}3&-4\\-4&10\end{bmatrix}$$ $$\{\Delta\} = [K]^{-1}\begin{Bmatrix}60\\60\end{Bmatrix} = \begin{Bmatrix}2\\1\end{Bmatrix}\ \text{mm}$$

回代：牆接 \([K_w]\{\Delta\} = \{0,\ 60\}\) kN，構架接 \([K_f]\{\Delta\} = \{60,\ 0\}\) kN。

圖 3-2　SA-2020-4：頂層的 60 kN 全部由構架承擔（bc 連桿 0），一樓的 60 kN 全部經 ef 連桿（受壓）送給剪力牆。構架柱形狀為兩端不轉的三次曲線，層間位移各 1 mm。
這張圖攔的錯：以為牆比較硬就每層都分到大部分；也攔住把 eh 柱剪力寫成「一樓構架力 0 → 柱剪力 0」——柱剪力看的是層剪力（上方所有構架力之和 60 kN，兩柱各 30），不是該層的樓層力。
答案（與正本一致）　bc 軸力 0；ef 軸力 60 kN（壓）；一樓剪力牆基底剪力 \(0 + 60 = 60\) kN；eh 柱 \(V = k_c\,\Delta_2 = 30000 \times 0.001 = 30\) kN，兩端 \(M = Vh/2 = 48\ \text{kN}\cdot\text{m}\)。
自我檢查：一樓構架兩柱剪力 \(2\times30 = 60\)，加牆基底 60，等於總外力 120 ✓。
為什麼 bc 剛好是 0？構架單獨只推頂層 60 kN，變形是 (2, 1) mm；牆單獨只推一樓 60 kN，變形也是 (2, 1) mm。兩者在各自的載重下本來就長得一樣，綁在一起不需要互相拉——出題者刻意調出來的。它和 SA-2018-1 是同一個規律的數值版：上部力往構架跑、下部力往牆跑。

3.3　因果鏈

牆是彎曲型、構架是剪力型 → 單獨變形形狀相反 → 連桿強迫同位移 → 下部牆拉住構架、上部構架拉住牆 → 構架底層反向、頂層 > F；牆底層 > F、頂層反向 → 每層兩者相加仍為 F。

§4　剛性樓板：平移 ＋ 繞剛心扭轉

剛性樓板把所有柱頂綁成一塊剛體：整層只剩 \(u_x, u_y, \theta\) 三個自由度。力的合力若不通過「勁度的中心」，樓板除了平移還會轉。

4.1　剛心是什麼、為什麼是勁度加權平均

剛心 CR 的定義：水平力作用在這一點時，樓板只平移不轉動。只平移時每根柱位移相同，柱力 \(\propto k_i\)，這組柱力的合力作用線就是 $$x_r = \frac{\sum k_{y,i}\,x_i}{\sum k_{y,i}},\qquad y_r = \frac{\sum k_{x,i}\,y_i}{\sum k_{x,i}}$$ ——跟求形心一樣，只是把「面積」換成「勁度」。

4.2　扭轉勁度 \(K_\theta = \sum k\,d^2\) 的來源

樓板繞 CR 轉 \(\theta\)，離 CR 垂直距離 \(d\) 的柱在其抗力方向位移 \(d\theta\)，柱力 \(k\,d\theta\)，對 CR 的力矩 \(k\,d^2\theta\)。全部加起來： $$K_\theta = \sum k_{x,i}\,{y'_i}^2 + \sum k_{y,i}\,{x'_i}^2\quad(x', y' \text{ 從 CR 量})$$ \(d\) 是平方：放在外圍的構件抗扭效率最高；通過 CR 的牆（例如十字形牆，見 SA-2017-4，屬 SA-U3-1）對 \(K_\theta\) 幾乎沒貢獻。

圖 4-1　SA-2021-4。(a) C2、C4 的勁度是 C1、C3 的 5 倍，把剛心拉到 (2, 0)；合力 108 kN 作用在中心，偏心 2 m → 順時針扭矩 216 kN-m。(b) 樓板位移由 \(u = -\theta y'\)、\(v = \Delta_y + \theta x'\) 算出、放大繪製；藍箭頭是各柱柱頂位移。
這張圖攔的錯：以為剛心在幾何中心、只算平移（四柱都 3.6 mm）；或把扭轉方向弄反——弱柱 C1、C3 離 CR 最遠，位移反而最大。
SA-2021-4 手算（與正本一致，剛心法與 3 自由度勁度矩陣兩路徑對帳）
  1. \(\sum k = 2(2500+12500) = 30000\ \text{kN/m}\)；CR = (2, 0)。
  2. \(T = 108 \times (0 - 2) = -216\ \text{kN}\cdot\text{m}\)（順時針）。
  3. \(K_\theta = \underbrace{(k+5k+k+5k)\cdot 2^2}_{48k} + \underbrace{2(k\cdot5^2 + 5k\cdot1^2)}_{60k} = 108k = 270000\ \text{kN}\cdot\text{m/rad}\)。
  4. \(\Delta_y = 108/30000 = 3.6\ \text{mm}\)；\(\theta = -216/270000 = -0.0008\ \text{rad}\)。
  5. C3 \((x',y') = (-5, 2)\)：\(u = 1.6\)、\(v = 3.6 + 4.0 = 7.6\) mm → \(V = (4,\ 19)\) kN。
    C4 \((1, 2)\)：\(u = 1.6\)、\(v = 3.6 - 0.8 = 2.8\) mm → \(V = (20,\ 35)\) kN。
自我檢查：四柱 \(V_y\) 合計 \(19+35+19+35 = 108\) ✓；\(V_x\) 合計 \(-4-20+4+20 = 0\) ✓。
柱剪力與 EI 絕對值無關：只看勁度比（1 : 5）。EI 讀錯一倍，剪力仍然對，但位移錯一倍——這正是 SA-2021-4 舊解的錯法（2026-11-07 勘誤：柱頂位移全部減半，剪力不變）。所以剪力對了不代表 EI 讀對，位移要另外檢查。
x 向沒有外力，為什麼有 x 向剪力？扭轉讓樓板上緣往右、下緣往左（\(u = -\theta y'\)），每根柱都產生 x 向剪力，合力為零但個別不為零。題目問「兩個方向的剪力」就是要考這一點。

4.3　因果鏈

各柱 \(k = 12EI/h^3\) → 勁度加權求 CR → 合力對 CR 取扭矩 \(T = Ve\) → \(K_\theta = \sum k d^2\) → 平移 \(V/\sum k\)、轉角 \(T/K_\theta\) → 各柱位移 = 平移 ± 轉角 × 距離 → 柱剪力 = \(k\) × 位移。

§5　范倫迪爾桁架：沒有斜桿，剪力靠彎曲

一般桁架的剪力由斜桿軸力的垂直分量承擔；范倫迪爾桁架沒有斜桿，剪力只能靠剛接節點讓弦桿與腹桿彎曲來傳——它其實是一個「橫躺的多層剛架」。

5.1　為什麼「反曲點在中點」能讓題目變靜定

剛架是高次靜不定。每根桿都假設一個彎矩為零的點（反曲點），等於在每根桿中點放一個鉸，每個鉸釋放一個彎矩條件 → 結構退化為靜定，只用平衡就能解。這和多層剛架的門架法（portal method）是同一個思路，題目已直接給定假設，不必自己判斷。

圖 5-1　SA-2019-2 在第 2 格中點切開（上下弦的切點都是反曲點 = 鉸）。對下切點取力矩得上弦軸力 700/6 = 116.67 kN（壓），水平平衡得下弦等值拉力；切口剪力 50 kN 由上下弦各分 25。
這張圖攔的錯：上下弦拉壓對調（簡支「梁」受向下載重，上翼壓、下翼拉）；以及把整格剪力都給下弦（載重掛在下弦，不代表剪力只走下弦）。

5.2　四步解法（逐格套用）

  1. 弦桿軸力：切在格中點，整體彎矩 \(M\) 由上下弦力偶抵抗：\(N = \mp M/h\)。
  2. 弦桿剪力：整體剪力 \(V\) 由上下弦平分，各 \(V/2\)（由上弦節點力矩平衡逐節點推得，正本 Step 3）。
  3. 腹桿剪力：取上弦節點（切到相鄰桿中點），水平平衡 → 腹桿剪力 = 左右上弦軸力差。
  4. 腹桿軸力：同一節點垂直平衡 → 腹桿軸力 = 左右上弦剪力差。最後每根桿端彎矩 = 剪力 × 半桿長。

5.3　因果鏈

沒有斜桿 → 剪力只能靠弦桿彎曲 → 節點必須剛接 → 高次靜不定 → 假設每桿中點反曲（放鉸）→ 靜定：切面 \(N = M/h\)、上下弦各 \(V/2\) → 節點平衡得腹桿剪力、軸力 → 端彎矩 = 剪力 × 半桿長。

§6　偏心斜撐構架（EBF）：連梁轉角被幾何放大

EBF 的設計意圖：讓斜撐提供勁度，把非彈性變形集中在一小段「連梁」（link）上。梁、柱、斜撐圍成的三角形很硬，幾乎當剛體轉動；所有層間位移都得由那一小段連梁吸收——所以連梁轉角是層間位移角的 \(L/e\) 倍。

圖 6-1　SA-2023-4 一層的運動學：左、右剛性三角形各繞底角順時針轉 \(\theta\)（圖中放大到 0.045 rad）；連梁左端下沉 \(4\theta\)、右端上抬 \(4\theta\)，樓板頂兩端水平位移相同（\(h\theta\)）。座標由剛體旋轉公式算出，並 assert \(\gamma/\theta = L/e\)。
這張圖攔的錯：只算弦轉角 \(8\theta/e\) 而漏了端點隨三角形一起轉的 \(\theta\)（得 13.33θ 而非 14.33θ）；或把 \(L\) 用成單側剛性區寬 4 m。

6.1　\(\gamma = (L/e)\,\theta\) 的推導（三行）

$$\text{兩端相對垂直位移} = (L_1 + L_2)\theta,\qquad \text{弦轉角} = \frac{(L_1+L_2)\theta}{e},\qquad \gamma = \frac{(L_1+L_2)\theta}{e} + \theta = \frac{L}{e}\theta$$

SA-2023-4：\(L = 4 + 0.6 + 4 = 8.6\ \text{m}\)、\(e = 0.6\ \text{m}\)，放大倍率 \(8.6/0.6 = 14.33\)。

極限檢查　\(e \to L\)（連梁佔滿整跨、沒有斜撐）：\(\gamma \to \theta\)，就是普通抗彎構架的梁端轉角 ✓。\(e \to 0\)（斜撐交於一點 = 同心斜撐）：\(\gamma \to \infty\)，表示沒有連梁可以吸收變形，變形改由斜撐軸向承擔 ✓。連梁越短，勁度越像同心斜撐、轉角需求越大——這就是 EBF「勁度與韌性的取捨」。

6.2　層間位移怎麼分到各層

題目只給頂層總位移 6 cm、說「不需經過精確分析」。各層剛性區幾何相同、連梁 EI 相同 → 各層樓層勁度相同 → 層間位移與層剪力成正比（§1 的串聯彈簧）：

$$V_1 : V_2 : V_3 = 1350 : 1050 : 600 = 9 : 7 : 4 \ \Rightarrow\ \Delta = 2.7,\ 2.1,\ 1.2\ \text{cm}$$
圖 6-2　SA-2023-4 三層：層剪力比 → 層間位移 → \(\theta = \Delta/h\) → \(\gamma = 14.33\,\theta\)。
這張圖攔的錯：把 6 cm 平均分給三層（每層 2 cm），或照「樓層外力」而非「層剪力」分配；以及在意「每端 600 還是合計 600」——比例都是 9 : 7 : 4，答案不變。
答案（與正本一致）　\(\gamma_1 = 14.33 \times 0.00675 = 0.09675\ \text{rad}\)、\(\gamma_2 = 0.07525\ \text{rad}\)、\(\gamma_3 = 0.043\ \text{rad}\)（約 5.54°、4.31°、2.46°）。
版本提醒　鋼結構耐震規定（AISC 341-16 §F3.4a）用同一個幾何關係 \(\gamma_p = (L/e)\,\theta_p\)，但代入的是塑性層間位移角，並限制連梁轉角（剪力降伏型 0.08 rad、彎曲降伏型 0.02 rad、中間內插）。SA-2023-4 是結構學題，要的是以總位移「推估」，不做規範檢核；寫答案時不要自行套上限值。

6.3　因果鏈

三角形剛性 → 各層剛體轉 \(\theta = \Delta/h\) → 連梁兩端相對錯動 \((L-e)\theta\) → 弦轉角 \((L-e)\theta/e\) ＋ 端點自轉 \(\theta\) → \(\gamma = (L/e)\theta\)；各層勁度相同 → \(\Delta_i \propto V_i\)。

§11　自我檢測

1. 為什麼梁 \(I=\infty\) 時柱的側推勁度是 12 而不是 3？

剛性梁使柱頂不能轉，兩端都提供彎矩抵抗 \(6EI\Delta/h^2\)，剪力 \(2M/h = 12EI\Delta/h^3\)；柱頂可轉時只剩底端抵抗，\(3EI/h^3\)。

2. 剪力型構架的層間位移為什麼往上遞減？

層間位移 = 層剪力 / 樓層勁度；層剪力由上往下累加，底層最大，勁度相同時底層層間位移最大。

3. 牆–構架互制下，構架頂層為什麼承受大於 F 的力？

牆單獨時頂部甩得比構架多，連桿強迫同位移，構架必須把牆往回拉；這股拉力的反作用加在構架頂層上，使構架頂層的力超過外力 F，牆頂則受反向力。

4. 什麼情況下，牆與構架才能照樓層勁度比 1 : 5 分力？

兩者變形模態相同（同為剪力型或同為彎曲型）時，相容條件不額外產生內力，才會每層按勁度比分配。

5. SA-2020-4 頂層連桿軸力為什麼剛好是 0？

構架單獨受頂層 60 kN 的變形與牆單獨受一樓 60 kN 的變形都是 (2, 1) mm，兩者本來就同形，綁在一起不需互推。

6. eh 柱位在一樓，但一樓構架分到的樓層力是 0，為什麼柱剪力是 30 kN？

柱剪力是層剪力（該層以上構架力之和 = 60 + 0 = 60 kN）由兩柱平分，與該層的樓層力無關；也可直接用 \(k_c \times \Delta_2 = 30000 \times 0.001\)。

7. 剛心的定義是什麼？為什麼是勁度加權平均？

力作用在剛心時樓板只平移。只平移時各柱位移相同、柱力與勁度成正比，柱力合力的作用線位置就是勁度加權平均。

8. \(K_\theta\) 為什麼有距離平方？

轉角 \(\theta\) 讓距離 \(d\) 的構件位移 \(d\theta\)（一次），力 \(kd\theta\) 再乘力臂 \(d\)（第二次）得力矩 \(kd^2\theta\)。

9. SA-2021-4 只有 y 向外力，C3 卻有 4 kN 的 x 向剪力，從哪來？

樓板繞 CR 扭轉，\(u = -\theta y'\)：上緣（y > 0）往右、下緣往左，柱產生 x 向剪力，四柱合計為 0。

10. 范倫迪爾桁架為什麼節點一定要剛接？

沒有斜桿，剪力無法以軸力傳遞，只能靠弦桿與腹桿彎曲；鉸接時每格是可變形的四連桿機構，無法承受剪力。

11. 「反曲點在中點」這個假設把什麼變成已知？

每根桿中點彎矩為零（相當於放鉸），每個鉸提供一個條件，使高次靜不定結構退化為靜定，只用平衡就能解出全部桿力。

12. EBF 的 \(\gamma = (L/e)\theta\)，當 \(e \to L\) 時代表什麼？

連梁佔滿整跨、沒有剛性三角形，結構退化為抗彎構架，梁端轉角等於層間位移角，\(\gamma \to \theta\)。
