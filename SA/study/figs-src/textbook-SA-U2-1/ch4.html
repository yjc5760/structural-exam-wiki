第 4 章　分段彎矩與圖乘法：不積分也能算 \(\int Mm\,dx\)

讀完這一章，你應該能自己寫出： $$M(x)=Rx+M_0-P\langle x-a\rangle-\tfrac{w}{2}\langle x-a\rangle^2,\qquad \int Mm\,dx=A_M\cdot m(\bar x),\qquad \int Mm\,dx=\tfrac L6\big(M_\text{左}m_\text{左}+4M_\text{中}m_\text{中}+M_\text{右}m_\text{右}\big)$$ 並且從這三條，自己長出整張圖乘表（\(\tfrac L3\)、\(\tfrac L6\)、\(\tfrac L2\)、\(\tfrac23\)、\(\tfrac38\)）。
用到的種子：S1（切開取自由體，寫分段彎矩）和 S6（直線×任意＝面積×形心縱距）。

4.1　種子 S1：彎矩在哪裡換式子？　必背

彎矩函數 \(M(x)\) 就是「在 \(x\) 處切一刀，取一邊的自由體，對切口取力矩」（S1）。切口往前移的過程中，只要沒有越過新的力，式子就不會變；越過一個力，式子就多一項。

① 從一端（通常是自由端或多餘力所在的那端）起算 \(x\)，取「起點到切口」這一段為自由體。

② 每一個力只在切口「越過它之後」才出現在自由體上：集中力 \(P\) 在 \(x=a\) 的貢獻是 \(-P(x-a)\)，但只在 \(x\ge a\) 時存在。

③ 把「只在 \(x\ge a\) 時存在」寫成一個開關：\(\langle x-a\rangle=\begin{cases}x-a & x\ge a\\0 & x

{{FIG:fig4_1|圖 4-1｜SA-2013-2 的梁 BC（\(x\) 自 C 往左）。上：\(C_y\) 造成的 \(C_yx\)，從 C 開始一直都在。中：20 kN 造成的 \(-20\langle x-5\rangle\)，在 \(x<5\) 時開關關著、等於 0；過了載重點才打開。下：兩者相加就是 \(M_{BC}\)，\(x=5\) 處 \(+39.29\)、B 端 \(-21.43\) kN·m。分段點就是開關打開的地方。}}
分段點只有這幾種：集中力或力偶的作用點、均布載重的起訖點、支承、節點（桿件轉向）、內鉸、\(EI\) 改變處。沒有其他理由要分段。SA-2005-1 的 \(R_C\) 作用線「看起來」穿過 BA 的中點，但力並沒有作用在 BA 上，所以 BA 不分段（第 3 章 3.7 節）。
反過來，\(EI\) 改變處 \(M(x)\) 本身不變，但 \(\int M^2/2EI\) 要分兩段積分——這是唯一「式子不變卻要拆」的情況。

4.2　種子 S6：直線×任意＝面積×形心縱距

最小功法和單位力法裡，要積的永遠是 \(\int M\,m\,dx\)。而 \(m\)（單位力的彎矩圖）有一個好性質：集中力造成的彎矩圖在每一段都是直線。直線只有兩個參數，所以：

① 在一段之內 \(m=c_0+c_1x\)。

② \(\displaystyle\int Mm\,dx=c_0\int M\,dx+c_1\int xM\,dx\)。第一個積分是 \(M\) 圖的面積 \(A\)；第二個是 \(A\bar x\)（形心的定義）。

③ 合起來 \(A(c_0+c_1\bar x)\)，括號裡正是 \(m\) 在 \(\bar x\) 的高度： $$\boxed{\int M\,m\,dx=A_M\cdot m(\bar x)}$$　✔ 這就是種子 S6。\(M\) 可以是任何形狀，\(m\) 必須是直線（在這一段之內）。

{{FIG:fig4_2|圖 4-2｜種子 S6 的畫面：上面是任意形狀的 \(M\) 圖，先算面積 \(A\)、找形心；從形心往下拉一條線，碰到直線 \(m\) 圖的高度就是 \(m(\bar x)\)。兩者相乘就是 \(\int Mm\,dx\)。右框用本圖的數字驗證：\(A\cdot m(\bar x)\) 和直接積分都是 96.0。}}
S6 的前提：\(m\) 在這一段必須是一條直線。\(m\) 圖若有折點（例如單位力作用在段中間），要在折點把兩段分開各算一次。另外 \(M\) 與 \(m\) 的角色可以互換——誰是直線，誰就負責「被量高度」。

4.3　從 S6 長出整張圖乘表　必背

圖乘表不用背，用 S6 現場推，每一格兩秒鐘：

① 三角×三角（同側）：\(M\) 三角形面積 \(\tfrac12La\)，形心在離 0 端 \(\tfrac23L\)；\(m\) 三角形在那裡的高度是 \(\tfrac23c\)。所以 \(\tfrac12La\cdot\tfrac23c=\boxed{\tfrac13Lac}\)。

② 三角×三角（反側）：\(M\) 的形心仍在離它 0 端 \(\tfrac23L\) 處，反側時 \(M\) 的 0 端正好是 \(m\) 的高端，所以那裡離 \(m\) 的 0 端只剩 \(\tfrac13L\)，\(m=\tfrac13c\)。所以 \(\tfrac12La\cdot\tfrac13c=\boxed{\tfrac16Lac}\)。

③ 三角×常數：\(\tfrac12La\cdot c=\boxed{\tfrac12Lac}\)。常數×常數：\(Lac\)。

④ 梯形×梯形：梯形 \(=\) 兩個反向三角形相加（S5 疊加），把 ①② 各用一次： $$\boxed{\int Mm\,dx=\tfrac L6\big(2ac+ad+bc+2bd\big)}$$　（\(M\)：左 \(a\)、右 \(b\)；\(m\)：左 \(c\)、右 \(d\)）

{{FIG:fig4_3|圖 4-3｜圖乘表。紫色三格最常用：同側三角 \(\tfrac13\)、反側三角 \(\tfrac16\)、拋物線×常數 \(\tfrac23\)。表裡每一格都是底下那條梯形公式的特例（把某些端點設成 0 或設成相等）。檢查記憶的方法：同側一定比反側大（兩個大值相乘），所以 \(\tfrac13>\tfrac16\)。}}
極限檢查：梯形公式代 \(a=b\)、\(c=d\)（兩個常數）：\(\tfrac L6(2+1+1+2)ac=Lac\) ✔；代 \(a=0\)、\(c=0\)（兩個同側三角）：\(\tfrac L6\cdot2bd=\tfrac13Lbd\) ✔；代 \(a=0\)、\(d=0\)（反側）：\(\tfrac L6bc\) ✔

4.4　均布段：拋物線的 \(\tfrac23\) 與 \(\tfrac38\)　必背

均布載重段的 \(M\) 圖是二次拋物線。把簡支梁的拋物線從頂點切成兩半，每一半都是「頂點處水平切線」的拋物線：\(M=h\big(1-(s/b)^2\big)\)，\(s\) 自頂點量、\(0\le s\le b\)。

① 面積：\(\displaystyle\int_0^b h\Big(1-\frac{s^2}{b^2}\Big)ds=h\Big(b-\frac b3\Big)=\boxed{\tfrac23bh}\)。

② 形心：\(\displaystyle\bar s=\frac{\int_0^b s\,h(1-s^2/b^2)\,ds}{\tfrac23bh}=\frac{h(\tfrac{b^2}2-\tfrac{b^2}4)}{\tfrac23bh}=\boxed{\tfrac38b}\)（自頂點量）。

③ 全跨（\(b=L/2\)、\(h=wL^2/8\)）：面積 \(\tfrac23Lh=\dfrac{wL^3}{12}\)，形心在跨中。

{{FIG:fig4_4|圖 4-4｜(a) 拋物線的「肚子」佔外框（\(b\times h\) 長方形）的 \(\tfrac23\)，剩下的 \(\tfrac13\) 是灰色的「凹角」。肚子靠頂點那一側比較胖，所以形心離頂點 \(\tfrac38b\)（比中點 \(\tfrac12b\) 近）。數字取 \(w=2\)、\(L=12\)：\(h=36\)、半邊面積 144、形心離跨中 2.25 m。(b) 不想記任何形狀時，用 Simpson 公式：只要 \(M\cdot m\) 不超過三次式（拋物線×直線剛好三次），它就是精確的，連圖乘表都能用它驗算。}}
為什麼 Simpson 對三次式是精確的？拿 \([-1,1]\) 試：\(1\)、\(x\)、\(x^2\)、\(x^3\) 的真積分分別是 2、0、\(\tfrac23\)、0；Simpson 給 \(\tfrac26(1+4+1)=2\)、\(\tfrac26(-1+0+1)=0\)、\(\tfrac26(1+0+1)=\tfrac23\)、\(\tfrac26(-1+0+1)=0\)，四個全對。任何三次式都是這四個的組合（S5 疊加），所以都對。
考場用法：表記不清就用 Simpson，只要量三個點（兩端與中點）的 \(M\)、\(m\)。
常見錯配：\(\tfrac23\) 配 \(\tfrac38\)（頂點有水平切線的那一半）；\(\tfrac13\) 配 \(\tfrac34\)（凹角，形心離頂點 \(\tfrac34b\)）。懸臂梁受均布載重的 \(M\) 圖是「凹角」那一種（自由端斜率 0、固定端最大），面積 \(\tfrac13bh\)。拿不準就畫出來，看切線水平的地方在哪一端。

4.5　範例：SA-2016-3，給桿端彎矩反算變位

題目（SA-2016-3）：A、D 固定的剛架，題目直接給四個桿端彎矩（其中 \(M_{CD}=-25.3\)、\(M_{DC}=-17.0\) kN·m，順時針作用於桿端為正），求 C 點變位。CD 柱長 20 m，柱上沒有側向載重。

① 虛力系統可以自己選：虛設的單位力只要滿足平衡，不必和原結構同樣靜不定。在 C 切開，把 CD 看成固定於 D 的懸臂柱，C 加水平單位力 → 只有 CD 有 \(m=y\)（左側受拉為正）。

② 真實彎矩：桿端彎矩換成斷面彎矩（近端同號、遠端反號）：C 端 \(-25.3\)、D 端 \(+17.0\)，中間沒有載重，是直線。

③ 圖乘（梯形×三角形）： $$EI\,\Delta_{Cx}=\frac{20}{6}\big[2(-25.3)(0)+(-25.3)(20)+(17.0)(0)+2(17.0)(20)\big]=\frac{20}{6}\times174=580$$ \(\Delta_{Cx}=580/EI\)，正值 → 向右。

{{FIG:fig4_5|圖 4-5｜把柱 CD 放倒來看。上：真實彎矩 \(M\)，從 C 端 \(-25.3\) 直線變到 D 端 \(+17.0\)，在 11.96 m 處反曲（雙曲率，側移剛架的典型）。下：C 向右單位力的 \(m=y\)。用梯形公式或 Simpson 都得 580；轉角則只要 \(M\) 圖淨面積（\(m=1\)）：\(\tfrac{-25.3+17.0}{2}\times20=-83\)，即 \(83/EI\) 逆時針。}}
這題的兩個坑：(1) 給了四個桿端彎矩，只用得到 CD 兩個（AB 的傾角題目甚至沒給）；(2) \(m\) 的受拉側：柱頂被往右推，受拉的是背離位移的那一側（左側）。\(M\) 與 \(m\) 只要有一個翻號，580 就變成 \(-580\)。

🙈 蓋住重推

Q1　用 S6 推出「三角×三角（反側）」的係數。

\(M\) 三角形面積 \(\tfrac12La\)，形心離 \(M\) 的 0 端 \(\tfrac23L\)；反側時那一端是 \(m\) 的高端，所以形心離 \(m\) 的 0 端只剩 \(\tfrac13L\)，那裡 \(m=\tfrac13c\)。乘起來 \(\tfrac16Lac\)。

Q2　拋物線的 \(\tfrac38\) 是從哪一端量？

從頂點（切線水平的那一端）量。凹角（另一種拋物線三角）則面積 \(\tfrac13bh\)、形心離頂點 \(\tfrac34b\)。

Q3　Simpson 為什麼可以拿來算「拋物線×直線」？

乘積是三次式，Simpson 對 \(1,x,x^2,x^3\) 都精確，疊加後對任何三次式都精確。

Q4　什麼地方要把 \(M(x)\) 分段？

集中力（偶）作用點、均布起訖點、支承、節點、內鉸；\(EI\) 改變處式子不變但積分要拆。

Q5　SA-2016-3：CD 柱 \(M\) 由 \(-25.3\) 到 \(+17.0\)、長 20 m，C 端水平單位力 \(m=y\)，\(EI\Delta=\)？

\(\tfrac{20}{6}[(-25.3)(20)+2(17.0)(20)]=\tfrac{20}{6}(174)=580\)。
