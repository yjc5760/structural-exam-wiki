第 6 章　彎矩＝彎曲：從彎矩圖畫出變形曲線

讀完這一章，你應該能自己寫出： $$\kappa=\frac{1}{\rho}=\frac{M}{EI},\qquad \Delta\theta=\int\frac{M}{EI}\,dx\ (\text{面積}),\qquad \text{偏離}=\int\frac{M}{EI}\,\bar x\,dx\ (\text{面積矩})$$ 並且不算任何數字，就能從彎矩圖畫出變形曲線的樣子：哪裡笑、哪裡哭、哪裡是反曲點、哪裡折角。 要記的是位移鏈的第一顆種子 S4 彎矩＝彎曲。本章範例：SA-2012-1（梁線，第 2、5 章接續）、 SA-2024-1。
本章會長出來的東西與考卷標籤
內容標籤本章
種子 S4：\(\kappa=M/EI\)（第 7、8 章所有位移公式的源頭）必背6.1
凹向與反曲點、各支承的邊界條件（規則）規則6.2
面積法：轉角變化＝\(M/EI\) 面積，偏離＝面積矩（第 7 章共軛梁的前身）—6.3

6.1　種子 S4：彎矩讓一小段梁彎成圓弧

🌱 種子 S4　彎矩＝彎曲
$$\kappa=\frac{1}{\rho}=\frac{M}{EI}\qquad(\text{彎矩越大彎得越兇；}EI\text{ 越大越不彎})$$
{{FIG:fig6_1|圖 6-1｜一小段梁在正彎矩下彎成圓弧，曲率中心在上方：下緣伸長、上緣縮短，中性軸長度不變。三步：幾何（平面保持平面 → 應變與 \(y\) 成正比）、材料（\(\sigma=E\varepsilon\)）、平衡（應力對中性軸的力矩＝\(M\)）。}}

① 幾何：斷面變形後仍是平面，離中性軸 \(y\)（向上為正）的纖維應變 \(\varepsilon=-y/\rho\)（下緣 \(y<0\)，伸長）。

② 材料：\(\sigma=E\varepsilon=-Ey/\rho\)。

③ 平衡：\(M=-\int\sigma y\,dA=\dfrac{E}{\rho}\int y^2dA=\dfrac{EI}{\rho}\ \Rightarrow\ \boxed{\kappa=\dfrac{M}{EI}}\)

極限檢查
・\(EI\to\infty\)（剛梁）：\(\kappa=0\)，完全不彎 ✔　SA-2003-2 的剛梁只會整根轉（第 8 章）。
・\(M=0\) 的地方：\(\kappa=0\)，這一點是直的，也就是反曲點的候選 ✔
・同樣的 \(M\)，\(2EI\) 段的曲率只有一半 ✔　SA-2012-1 的 a–c 段 \(M/EI\) 圖高度要先減半（圖 6-3）。

6.2　看彎矩圖畫變形：笑、哭、反曲點、邊界條件

{{FIG:fig6_2|圖 6-2｜上：\(M>0\) 下緣受拉、凹口向上（笑）；\(M<0\) 上緣受拉、凹口向下（哭）。彎矩圖換號的地方，變形曲線凹向改變，就是反曲點。下：各種支承對變形曲線的要求。}}
畫變形曲線的三步（不用算數字）
① 把彎矩圖分成正段、負段 → 每段笑或哭；② 把支承的條件釘上去（固定端水平長出來、鉸與滾在 0、內鉸可以折角）；③ 用平滑的曲線接起來，凹向換的地方就是反曲點。 最後再用算出來的一兩個數字（第 7、8 章）確認方向和大小。
陷阱：內鉸處的「反曲點」
SA-2012-1 的彎矩只在 c 點（內鉸）由正轉負，所以凹向在 c 改變；但 c 同時是內鉸，曲線在這裡折一個尖角（斜率從 \(+480/EI\) 跳到 \(-480/EI\)，圖 2-7）。 畫圖時兩件事都要表現：凹向換了，而且不是平滑通過。

6.3　面積法：把曲率加起來就是轉角，再加一次就是位移

\(\kappa=d\theta/dx\)（小變形）。從 S4 出發積分兩次，就得到兩條很直觀的規則：

① 積分一次：\(\theta_2-\theta_1=\displaystyle\int_1^2\frac{M}{EI}dx\)＝\(M/EI\) 圖在這一段的面積。

② 再積一次：點 2 偏離「點 1 的切線」的距離 ＝ \(\displaystyle\int_1^2\frac{M}{EI}(x_2-x)\,dx\)＝這段面積對點 2 的矩（面積 × 形心到點 2 的距離）。

③ 白話：轉了多少看面積，偏了多少看面積矩。第 7 章會把這兩句話包裝成「共軛梁」，一次處理所有支承。

貫穿範例（梁線）③　SA-2012-1：c 點上升多少

{{FIG:fig6_3|圖 6-3｜(a) \(M/EI\) 圖：a–c 段是 \(2EI\)，160 變成 80；兩塊面積 \(A_1=320\)（形心距 c 6 m）、\(A_2=160\)（三角形，形心距 c \(8/3\) m）。(b) a 是固定端，切線水平，所以 c 偏離這條水平線的距離就是 \(y_c\)。數值積分 \(\kappa\) 兩次得到同一條曲線。}}

① a 端：固定，\(y_a=0\)、\(\theta_a=0\)（切線水平）。

② c 點左側的轉角：\(\theta_c=A_1+A_2=320+160=480/EI\)（逆時針，往上翹）。

③ c 點位移＝面積對 c 的矩：\(y_c=320\times6+160\times\tfrac83=\dfrac{7040}{3EI}\approx\dfrac{2347}{EI}\)（向上）✔ 和題解第㈣小題相同。

方向檢查
a–c 全段 \(M>0\)（笑），從水平的固定端長出來一定往上翹 ✔。c–e 段 \(M<0\)（哭），又被 d 點擋住，像蹺蹺板一樣把 e 端壓下去 ✔（e 點的數字第 7、8 章用兩種方法算：\(12160/3EI\) 向下）。

範例 ②　SA-2024-1：從彎矩圖讀出變形的樣子

{{FIG:fig6_4|圖 6-4｜SA-2024-1。A 端有 200 kN-m 逆時針力偶，彎矩一開始是 −200（哭），在 \(x=2.67\) m 換號（反曲點）；之後一路為正到 C（內鉸，折角）；C–D 是懸臂，又是負彎矩。所以梁先微微上翹（只有 \(11.6/EI\)），再往下彎，最大向下位移在 B、C 之間的 \(x=5.691\) m（第 7 章精確求出）。}}
陷阱：最大位移在載重點或跨中
SA-2024-1 的最大位移不在 B（載重點），也不在 A–C 中點，而在轉角為 0 的 \(x=5.691\) m。「位移的極值在轉角為 0 的地方」，就像「彎矩的極值在剪力為 0 的地方」（第 5 章），同一個道理換一層。
🧩 30 秒重建卡｜彎矩＝彎曲
  1. 畫：一小段梁彎成圓弧；下緣伸長、上緣縮短。
  2. 種子 S4：\(\varepsilon=-y/\rho\) → \(\sigma=E\varepsilon\) → \(M=EI/\rho\) ⇒ \(\kappa=M/EI\)。
  3. 形狀：\(M>0\) 笑、\(M<0\) 哭；換號處反曲；內鉸可以折角；固定端水平長出來。
  4. 大小：轉角變化＝\(M/EI\) 面積；偏離切線＝面積矩。
  5. 檢查：\(EI\to\infty\) 不彎；\(2EI\) 段曲率減半；位移極值在 \(\theta=0\) 處。

6.4　🙈 蓋住重推

Q1　從「平面保持平面」推出 \(\kappa=M/EI\)。

\(\varepsilon=-y/\rho\)，\(\sigma=E\varepsilon\)，\(M=-\int\sigma y\,dA=(E/\rho)\int y^2dA=EI/\rho\)。

Q2　怎麼從彎矩圖判斷反曲點？SA-2004-1 的梁上反曲點在哪？

彎矩換號處曲率換號，凹向改變。SA-2004-1 梁 \(M=3x-x^2\) 在 \(x=3\) m 由正轉負（第 5 章圖 5-3）。

Q3　用面積法求 SA-2012-1 的 \(y_c\)。

a 端固定、切線水平。\(M/EI\) 在 a–c 段兩塊面積 320、160，對 c 的力臂 6、8/3：\(y_c=1920+1280/3=7040/3EI\)（向上）。

Q4　SA-2024-1 的最大位移為什麼不在載重點 B？

位移極值在轉角為 0 的地方。C 點被懸臂 CD 往下帶、A 端力偶讓左段先上翹，轉角為 0 的點落在 \(x=5.691\) m，B 和 C 之間。

#錯誤做法正確觀念（以及怎麼自己抓出來）
1正彎矩畫成往下凹\(M>0\) 下緣受拉、梁笑；先畫凹向再接支承。
