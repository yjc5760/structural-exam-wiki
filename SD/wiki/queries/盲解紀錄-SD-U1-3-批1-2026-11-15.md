### 所問

### 解法

$$\mathbf M=\begin{bmatrix}M_2&M_2L\\M_2L&I_1+I_2+M_2L^2\end{bmatrix}=\begin{bmatrix}100&300\\300&12900\end{bmatrix},\quad
\mathbf K=\begin{bmatrix}2k&0\\0&k_\theta\end{bmatrix}=\begin{bmatrix}6\times10^4&0\\0&1.2\times10^7\end{bmatrix}$$

特徵方程式：$M_2(I_1+I_2)\omega^4-[2k(I_1+I_2+M_2L^2)+k_\theta M_2]\omega^2+2k\,k_\theta=0$
→ $1.2\times10^6\omega^4-1.974\times10^9\omega^2+7.2\times10^{11}=0$

| 2 | 1099.10 | 33.153 | 5.276 | 0.1895 | (−6.607 m, 1 rad) | (−3.607 m, 1 rad) |

### SD-2003-2（10 分）SDOF 受分段線性外力 最大位移

### 轉錄核對
- 考卷 2003 第 1 頁第二題與題目正本一致（m = 100 kg、k = 100 N/m、ξ = 30%；ta = 0.1、tb = 0.12、tc = 0.2、td = 0.25 s；2000N、−500N）。
- 用 PDF 向量座標再核對一次：原點 x = 221.9、P = 0 線 y = 558.8；上升段 (221.9, 558.0)→(238.2, 481.9)；下降段是一條線 (238.2, 481.9)→(297.7, 577.8)，零交點 x = 285.9（= ta，所以 640 pt/s）；tb 虛線 x = 297.7（換算 0.118 s）、tc x = 349.3（0.199 s）、td x = 381.0（0.249 s）。峰值 x = 238.2 → 圖面比例下是 0.0255 s。與判讀清單 #1 說的一致。

### 判讀表核對
#1–#9 都同意。#1 峰值時刻主解採 0.02 s（由 ta、tb、−500N 定的直線斜率 −25 000 N/s 推得）。

### 所問
全歷時的最大位移（初始靜止）。

### 解法
ω = √(k/m) = 1 rad/s，T = 6.283 s，ωD = ω√(1−ξ²) = 0.95394 rad/s，c = 2ξmω = 60 N·s/m。
荷載長度 td = 0.25 s ≪ T，所以最大值出現在 t > td 的自由振動段。

各段 p = p₀ + rτ，特解 $u_p=(p_0-cr/k)/k+r\tau/k$，齊次解由段首條件決定（對分段線性荷載是精確解）。逐段推得：

| t (s) | u (m) | u̇ (m/s) |
|---|---|---|
| 0.02 | 1.329×10⁻³ | 0.1992 |
| 0.10 | 0.05875 | 0.9627 |
| 0.12 | 0.07754 | 0.9001 |
| 0.20 | 0.13179 | 0.4589 |
| 0.25 | 0.150109 | 0.315880 |

自由振動：$u=e^{-\xi\omega\tau}(u_0\cos\omega_D\tau+B\sin\omega_D\tau)$，$B=(\dot u_0+\xi\omega u_0)/\omega_D$。令 u̇ = 0：
$\tan\omega_D\tau=(\omega_DB-\xi\omega u_0)/(\xi\omega B+\omega_Du_0)$ → τ = 0.9313 s，即 t = 1.181 s
→ **u_max = 0.2936 m**

### 交叉驗算
- 路徑 1：上面的逐段精確解（取樣 1e−4 s）＋ 閉合式自由振動峰值：0.293637 m，t = 1.1813 s
- 路徑 2：scipy.signal.lsim（Δt = 5e−5 s）：0.293637 m，t = 1.1813 s
- 路徑 3：solve_ivp（RK45，max_step 1e−3）：0.293637 m
- 粗估：淨衝量 I = 100 − 5 − 40 − 12.5 = 42.5 N·s，當成在 t = 0 的理想衝量時 u_max ≈ 0.2854 m（低估約 3%，因為荷載長度不是無限短，衝量的時間重心也不在 0）。

### 最終答案
| 項目 | 值 |
|---|---|
| 最大位移 | 0.294 m（293.6 mm），發生在 t ≈ 1.18 s（自由振動段） |

### 不確定處
- 峰值時刻改用圖面比例量的 0.0255 s（或 0.025 s）：u_max = 0.2934 m（差 < 0.1%）。淨衝量不變，所以答案對峰值時刻幾乎不敏感。
- 若只問「強迫段內」的最大位移：u(td) = 0.1501 m（強迫段內單調上升）。

### SD-2003-3（20 分）雷利阻尼：優點、ξ–T 關係、求 ξ2

### 轉錄核對
考卷 2003 第 1 頁第三題與題目正本一致，無附圖。

### 判讀表核對
#1–#4 都同意。

### 所問
㈠ 古典（雷利）阻尼在計算上的優點；㈡ 推導振態阻尼比與週期的關係；㈢ T1 = 2 s、ξ1 = 5%；T3 = 1 s、ξ3 = 5%；T2 = 1.5 s，求 ξ2。

### ㈠ 優點（得分要點）
1. 古典阻尼滿足 $\boldsymbol\phi_m^T\mathbf C\boldsymbol\phi_n=0\ (m\neq n)$（Caughey 條件 $\mathbf{CM^{-1}K}=\mathbf{KM^{-1}C}$；雷利阻尼 C = a₀M + a₁K 一定滿足）。
2. 用無阻尼振態做座標轉換後，阻尼矩陣也是對角，運動方程式完全解耦成 N 個獨立的 SDOF：$\ddot q_n+2\xi_n\omega_n\dot q_n+\omega_n^2q_n=-\Gamma_n\ddot u_g$。
3. 可以用實數、無阻尼的振態與頻率（不必解複數特徵值），直接套 SDOF 結果或反應譜，再做振態疊加（SRSS／CQC）。
4. 只要兩個振態的阻尼比就能定出 a₀、a₁ 並組出整個 C，不必知道每個構件的阻尼（實務上本來就很難量測）。
5. 直接積分法（非線性分析）需要明確的 C 矩陣時，雷利形式也方便。

### ㈡ 推導
$\boldsymbol\phi_n^T\mathbf C\boldsymbol\phi_n=a_0M_n+a_1\omega_n^2M_n=2\xi_n\omega_nM_n$
$$\xi_n=\frac{a_0}{2\omega_n}+\frac{a_1\omega_n}{2}\ ,\quad \omega_n=\frac{2\pi}{T_n}\ \Rightarrow\ \boxed{\xi_n=\frac{a_0T_n}{4\pi}+\frac{\pi a_1}{T_n}}$$
質量比例項與 T 成正比（主控長週期），勁度比例項與 T 成反比（主控短週期）。兩個錨定振態 i、j 的阻尼比相等（都是 ξ）時：
$a_0=\dfrac{2\xi\omega_i\omega_j}{\omega_i+\omega_j}$，$a_1=\dfrac{2\xi}{\omega_i+\omega_j}$，$\xi_n=\xi\left[\dfrac{T_n}{T_i+T_j}+\dfrac{T_iT_j}{(T_i+T_j)T_n}\right]$

### ㈢ 數值
ω1 = π、ω3 = 2π、ω2 = 4π/3 rad/s
a₀ = π/15 = 0.20944 s⁻¹，a₁ = 1/(30π) = 0.010610 s
$\xi_2=0.05\left[\frac{1.5}{3}+\frac{2}{3\times1.5}\right]=0.05\times\frac{17}{18}=\frac{17}{360}=0.04722$

### 交叉驗算
numpy 解 2×2 聯立（ω 形式）＝ sympy 解 T 形式 ＝ 閉合式，都得到 17/360 = 0.047222。合理性：T2 落在兩錨定週期之間，雷利阻尼在兩錨定點之間低於 ξ，所以 ξ2 < 5% 是對的。（T = 0.5 s 時 7.5%、T = 3 s 時 6.11%：區間外變大。）

### 最終答案
| 項目 | 值 |
|---|---|
| a₀ | 0.2094 s⁻¹（π/15） |
| a₁ | 0.01061 s（1/(30π)） |
| ξ2 | 4.72%（17/360） |

### 不確定處
無實質疑義。若錯把題目當作「第 1、2 振態」錨定，會得到不同的結果，但題文清楚寫第三振態。

### 盲分類
主：SD-U1-3；副：SD-U1-1

ω = 8.091 rad/s，**T = 0.7765 s**

### ㈢ 有效質量

$M^*_{eff}=L^2/\tilde M=$ **20 552 kg**（約 20.6 t，為總質量 25 000 kg 的 82.2%）；Γ = L/M̃ = 44.81 m⁻¹（取 u 以 m 計）

- 精確第一振態的有效質量 = 20 581 kg（82.3%），近似值差 0.14%。
- 改用頂層正規化的形狀（u/u5）算 M_eff，結果相同（與正規化無關）✔。

### SD-2007-2　二自由度彈簧質量系統（運動方程式、模態頻率、共振）

### 轉錄核對
- 考卷 2007-p1 第二題原文與題目正本 §1 逐字一致（㈠5／㈡10／㈢10 分）。
- 附圖（2007-p1 右側中段）：頂端剖線固定 → k1 → m1（F1 cos ωf t 向下、y1 向下）→ k2 → m2（F2 cos ωf t 向下、y2 向下），無阻尼器。與判讀清單 #1–#6 一致。**沒有疑義。**

### 各小題所問
㈠ 寫出運動方程式；㈡ 用符號推出兩個模態頻率；㈢ ωf 在什麼條件下會共振。

### 解
㈠ 取靜平衡位置為原點、向下為正（重力與靜伸長互相抵消）：
$$\begin{bmatrix}m_1&0\\0&m_2\end{bmatrix}\begin{Bmatrix}\ddot y_1\\\ddot y_2\end{Bmatrix}+\begin{bmatrix}k_1+k_2&-k_2\\-k_2&k_2\end{bmatrix}\begin{Bmatrix}y_1\\y_2\end{Bmatrix}=\begin{Bmatrix}F_1\\F_2\end{Bmatrix}\cos\omega_f t$$

㈡ $\det(K-\omega^2M)=0$ 展開為 $m_1m_2\omega^4-(k_1m_2+k_2m_1+k_2m_2)\omega^2+k_1k_2=0$（sympy）
$$\omega_{1,2}^2=\frac12\left[\frac{k_1+k_2}{m_1}+\frac{k_2}{m_2}\mp\sqrt{\left(\frac{k_1+k_2}{m_1}+\frac{k_2}{m_2}\right)^2-\frac{4k_1k_2}{m_1m_2}}\right]$$
模態頻率 $f_n=\omega_n/2\pi$；振態 $\phi_n=\{1,\ (k_1+k_2-m_1\omega_n^2)/k_2\}^T$。

㈢ 穩態解 $y_j=Y_j\cos\omega_f t$（sympy 求出）：
$$Y_1=\frac{(k_2-m_2\omega_f^2)F_1+k_2F_2}{\Delta},\quad Y_2=\frac{k_2F_1+(k_1+k_2-m_1\omega_f^2)F_2}{\Delta},\quad \Delta=m_1m_2(\omega_f^2-\omega_1^2)(\omega_f^2-\omega_2^2)$$
- **共振條件：$\omega_f=\omega_1$ 或 $\omega_f=\omega_2$**（Δ=0，無阻尼時振幅無限大，實際上隨時間線性成長）。
- 例外：當 $\phi_n^T\{F_1,F_2\}=0$（外力分佈與第 n 振態正交）時，該模態的參與係數為零，$\omega_f=\omega_n$ 也不會共振（數值核對：分子同時為 0）。
- 補充（加分點）：$F_2=0$、$\omega_f^2=k_2/m_2$ 時 $Y_1=0$，屬於反共振（動力吸振器原理）。

### 交叉驗算
取 m1=2、m2=1、k1=300、k2=100：閉合解 ω² = 63.397、236.603；numpy.linalg.eigvals 得 63.397、236.603，兩者一致。外力與振態正交時，共振點的分子 ≈ 1e-14，確實為 0。

### 最終答案
| 小題 | 答案 |
|---|---|
| ㈠ | 運動方程式見上（M = diag(m1,m2)，K = [[k1+k2, −k2], [−k2, k2]]，右端 {F1, F2}cos ωf t） |
| ㈡ | ω² 為上式 ∓ 兩根（rad²/s²）；f = ω/2π（Hz） |
| ㈢ | ωf = ω1 或 ω2 時共振；外力分佈與該振態正交時除外 |

- ㈢ 若出題者預期的是「一般性回答（ωf = ωn）」，則正交例外與反共振只算補充。

### 轉錄核對

### 解
㈠ $H_u(\Omega)=\dfrac{u}{p_0}=\dfrac{1}{k-m\Omega^2+ic\Omega}$，$|H_u|=\dfrac{1}{k\sqrt{(1-r^2)^2+(2\xi r)^2}}$，其中 $r=\Omega/\omega_n$。
㈡ $H_a=\dfrac{\ddot u}{p_0}=\dfrac{-\Omega^2}{k-m\Omega^2+ic\Omega}$，$|H_a|=\dfrac{r^2}{m\sqrt{(1-r^2)^2+(2\xi r)^2}}$。
㈢ 無阻尼：$\Omega^2\cdot0.1mg/|k-m\Omega^2|\le0.05g\Rightarrow|k-m\Omega^2|\ge2m\Omega^2$。
 - k > mΩ²（勁度控制側）：**k ≥ 3mΩ²**（r ≤ 1/√3）。
 - k < mΩ²：需 k ≤ −mΩ²，不可能。在柔性側，$|\ddot u|=(p_0/m)\,r^2/(r^2-1)>0.1g$ 恆成立，所以永遠不合格。
㈣ $m\Omega^2=1000(2\pi)^2=39{,}478$ N/m；$|k-39478|\ge p_0/u_{max}=100{,}000$
 - **k ≥ 139,478 N/m ≈ 139.5 kN/m**（r = 0.532）；柔性側 k ≤ −60,522 N/m，不可能。

### 交叉驗算
k = 139,478 N/m 時 r = 0.53202，$(p_0/k)/|1-r^2|=0.1000$ m，與限制值一致。

### 最終答案
| 小題 | 答案 |
|---|---|
| ㈠ | H_u = 1/(k − mΩ² + icΩ)；\|H_u\| = (1/k)/√[(1−r²)² + (2ξr)²]（m/N） |
| ㈡ | H_a = −Ω²/(k − mΩ² + icΩ)；\|H_a\| = (r²/m)/√[(1−r²)² + (2ξr)²]（1/kg） |
| ㈢ | k ≥ 3mΩ²（N/m） |
| ㈣ | k ≥ 1.395×10⁵ N/m ≈ 139.5 kN/m |

### 不確定處
- 主解把「最大」解讀為穩態振幅（判讀清單 #7）。替代解讀是由靜止起算、含暫態的總反應（無阻尼），此時 $u_{max}\le\frac{p_0}{k(1-r)}$、$\ddot u_{max}\le\frac{p_0}{m}\frac{r}{1-r}$：㈢ 變成 k ≥ 9mΩ²；㈣ 變成 k ≥ 185,599 N/m（數值時間歷程與閉合式兩條路徑一致）。
- ㈠ 的「轉換函數」可寫成複數形式 H(Ω) 或振幅比，兩者都列出；若出題者要 Laplace 形式，則為 1/(ms² + cs + k)。

### 盲分類
主：SD-U1-3；副：SD-U1-1

### SD-2008-1　二層剪力屋架：由週期反推 k、振態、古典阻尼矩陣

### 轉錄核對
- 2008-p1 第一題原文與題目正本一致。
- 附圖：**u1 標在頂層、u2 標在下層**，柱底為短粗線（固定），與判讀清單 #1、#4 一致。**沒有疑義。**

### 各小題所問
㈠ 求 k = p×10^q 的 p 與 q；㈡ 求兩個振態（u1 分量 = 1）；㈢ 求阻尼係數矩陣 C；㈣ 多振態反應譜疊加法是否必須建立 C。

### 解
自由度順序 [u1（頂）, u2（下）]：M = mI，K = k[[1, −1], [−1, 2]]。
令 a = mω²/k，det = 0 得 $a=(3\mp\sqrt5)/2=0.38197,\ 2.61803$。

㈠ ω1 = 2π/0.197 = 31.894 rad/s → k = mω1²/0.38197 = 3.9948×10⁶ N/m；
 ω2 = 2π/0.0752 = 83.553 rad/s → k = mω2²/2.61803 = 3.9998×10⁶ N/m。
 → **k = 4×10⁶ N/m，p = 4，q = 6**。（T1/T2 = 2.6197，理論值 √(2.618/0.382) = 2.618，兩者吻合。）

㈡ 由第一列 $(k-m\omega^2)\phi_1=k\phi_2$ 得 $\phi_2=1-a$：
 **φ1 = {1, 0.618}ᵀ，φ2 = {1, −1.618}ᵀ**（{u1, u2}，即 {頂, 下}）。

㈢ 古典阻尼：$C=M\Phi\,\mathrm{diag}(2\xi_n\omega_n/M_n)\,\Phi^TM$。取 k = 4×10⁶（ω = 31.914、83.555 rad/s）：
$$C=\begin{bmatrix}6928&-3464\\-3464&10392\end{bmatrix}\ \text{N·s/m}=2000\sqrt3\begin{bmatrix}2&-1\\-1&3\end{bmatrix}\ \text{N·s/m}$$
（直接用題給週期算：[[6926, −3465], [−3465, 10391]] N·s/m，差異 < 0.04%。）

㈣ **不需要**。得分要點：
1. 古典阻尼可以用振態解耦，各振態方程只需要 ξn（題給 5%）。
2. 反應譜本身就以阻尼比為參數（設計譜以 5% 為準，其他阻尼比用 BS、B1 修正）。每個振態直接查 $S_a(T_n,\xi_n)$，乘參與係數 Γn 與 φn，再以 SRSS 或 CQC 組合（CQC 的相關係數也只用 ξn 與頻率比）。
3. 所以全程不出現 C。只有直接積分的時間歷程分析，或非古典阻尼（須用複數模態）時，才需要明確建立 C。

### 交叉驗算
- C 用兩條路徑算：①振態疊加式；②Rayleigh 式 C = a0M + a1K，a0 = 2ξω1ω2/(ω1+ω2) = 2.3094 s⁻¹，a1 = 2ξ/(ω1+ω2) = 8.660×10⁻⁴ s。兩條路徑結果完全相同（二自由度、兩模態阻尼比相同時，Rayleigh 阻尼恰好精確）。
- 回代檢查：ΦᵀCΦ 得 ξ = 0.0500、0.0500。

### 最終答案
| 小題 | 答案 |
|---|---|
| ㈠ | p = 4，q = 6（k = 4×10⁶ N/m） |
| ㈡ | φ1 = {1, 0.618}，φ2 = {1, −1.618}（{u1 頂, u2 下}） |
| ㈢ | C = [[6928, −3464], [−3464, 10392]] N·s/m（= 2000√3[[2, −1], [−1, 3]]） |
| ㈣ | 不需要（反應譜法逐振態只用 ξn） |

### 不確定處
- ㈢ 用 k = 4×10⁶ 一致化後的 ω，或用題給 T，結果差 < 0.04%，主解採一致化的 k。
- 若誤把 u1 當下層，振態會寫成 {1, 1.618}、{1, −0.618}，C 會變成 [[10392, −3464], [−3464, 6928]]（列序對調）。本題已確認 u1 在頂層。

### 盲分類
主：SD-U1-3；副：SD-U1-1

### SD-2008-3　位移放大係數 MF、消能元件效益、BS 與 B1

### 轉錄核對
- 2008-p2 第三題原文、MF 公式與題目正本一致。
- 關係圖：ξ = 0.02 的峰值約 25、0.05 約 10、0.20 約 2.5；r = 1.5 時三條曲線趨近 0.7–0.8，與判讀清單一致。**沒有疑義。**

### 各小題所問
㈠ ξ 由 2% 增為 20% 時的位移比值：r = 1 與 r = 1.5 兩種情況；㈡ 什麼情況下消能元件效益大；㈢ 為何 ξ > 5% 時 BS > B1。

### 解
㈠ r = 1：MF(2%) = 1/(2×0.02) = 25.00，MF(20%) = 2.50 → **比值 = 0.100**（位移減少 90%）。
 r = 1.5：MF(2%) = 1/√(1.5625 + 0.0036) = 0.7991，MF(20%) = 1/√(1.5625 + 0.36) = 0.7212 → **比值 = 0.903**（只減少約 9.7%）。

㈡ 要點：
1. 阻尼只在共振區（r ≈ 1，約 0.8–1.2）主導反應；在這個範圍內比值為 0.10–0.75（腳本列表：r = 0.9 → 0.475，r = 1.1 → 0.440）。
2. 遠離共振時效益很小：r 小時由勁度控制，r = 0.5 → 0.967；r 大時由質量控制，r = 1.5 → 0.903，r = 2 → 0.967。
3. 因此結構週期接近地震主要週期（工址卓越週期）、原本阻尼又小時，加裝消能元件最有效；原阻尼越小，增加阻尼的相對效益越大。
4. 遠離共振的結構，宜改用調整週期（隔震、加勁）等手段。

㈢ 要點：
1. 設計譜分段：短週期平台段（0.2T0 ≤ T ≤ T0）的 $S_{aD}=S_{DS}/B_S$；中、長週期段（T > T0）的 $S_{aD}=S_{D1}/(B_1T)$。
2. 短週期結構的 Tn 落在地震能量集中的頻帶（平台段，結構週期與地震主要週期相近，r ≈ 1 附近）。由 MF 圖可知，此區增加阻尼可大幅壓低反應（r = 1 時 ξ 由 5% 增為 20%，MF 降為 1/4）。所以阻尼修正係數大，BS 大。
3. 長週期結構 Tn 大於地震主要週期（相當於圖中 r > 1 的位移控制區），各阻尼比曲線趨近重合（r = 1.5 時比值 ≈ 0.9），阻尼效益小，所以 B1 較小。
4. 規範表 3-1 的數值：ξ = 10%：BS = 1.33、B1 = 1.25；20%：1.60／1.50；30%：1.79／1.63；40%：1.87／1.70；≥ 50%：1.93／1.75。ξ ≤ 2% 時兩者皆為 0.8，5% 時皆為 1.0，因此只有 ξ > 5% 時 BS > B1。
5. 補充：實際地震不是單一頻率的簡諧外力，而是寬頻、有限延時的激發，阻尼效益比單頻共振（25→2.5 為 10 倍）小得多，所以規範的 BS 只到 1.93 左右。

### 交叉驗算
r = 1 的閉合式 MF = 1/(2ξ)：比值 = 0.02/0.20 = 0.1，與數值結果一致。

### 最終答案
| 小題 | 答案 |
|---|---|
| ㈠ | r = 1：比值 0.100；r = 1.5：比值 0.903（無因次） |
| ㈡ | r 接近 1（共振區）且原阻尼小時效益最大；遠離共振時效益很小 |
| ㈢ | 短週期段結構週期接近地震主要週期，增加阻尼的效益大，所以 BS 大；長週期段在 r > 1 區，各阻尼曲線趨近重合，所以 B1 小（見表 3-1 數值） |

### 不確定處
- ㈢ 規範表的版次：取得的 PDF 頁面沒有印日期，表號為表 3-1、§3.2。我推定 111 年版沿用相同數值，**尚未查證**。
- ㈢ 的論述方式：把長週期結構對應到圖中 r > 1 是物理類比，也可以從「長週期為位移控制、加速度譜受阻尼影響較小」的角度說明。

### 盲分類
主：SD-U1-3；副：SD-U2-2
