## SD-2009-2
### (a) 題意摘要
重 W = 6,500 lb 的篩分析機，未隔振時支承承受幅度 700 lb、頻率 12 Hz 的諧和力；裝彈簧隔振器後，傳到支承的諧和力幅度降為 50 lb；ξ = 0，求隔振彈簧勁度 k。
附圖核對：本題無附圖；考卷第 1 頁 110 dpi 整頁目視，原文與題目正本 §1 一致（「1b」＝lb）。
### (b) 判讀表
| 項目 | 判讀 |
|---|---|
| 支承／自由度 | 機器質量置於彈簧上，垂直單自由度 |
| 載重 | 機器不平衡諧和力 p0 = 700 lb（＝未隔振時傳到支承的力），f = 12 Hz |
| 題給參數 | W = 6,500 lb，F_T = 50 lb，ξ = 0；g 未給 → 取 386.1 in/s² |
| 所求 | 彈簧勁度 k |
### (c) 盲分類
主分類 SD-U1-3（單自由度諧和激振、力傳遞率／隔振）；副分類 SD-U3-2（隔減震原理）。同意索引主分類 SD-U1-3。
### (d) 解題
力傳遞率（ξ = 0）：TR = F_T / p0 = 1/|1 − r²|，隔振須 r > √2，故 r² − 1 = p0/F_T。
- TR = 50/700 = 1/14 → r² = 15，r = 3.873
- ω = 2π(12) = 75.398 rad/s；ωn² = ω²/15 → ωn = 19.468 rad/s（fn = 3.098 Hz）
- m = W/g = 6500/386.1 = 16.835 lb·s²/in
- k = m ωn² = 16.835 × 379.0 = **6,380 lb/in**（＝76.56 kip/ft ≈ 1.117×10⁶ N/m）
- 檢核：靜撓度 W/k = 1.019 in；k 亦可寫成 k = (W/g)(2πf)²/(1+p0/F_T)
**答案彙整**
| 小題 | 答案 |
|---|---|
| k | ≈ 6,380 lb/in（76.6 kip/ft） |
### (e) 不確定處
- 若誤取 r² − 1 = −14（r < 1 分支）則無解（r² 為負），所以只有隔振分支，唯一解。
- g 取 32.2 ft/s² 得 k = 76,505 lb/ft，與上式相同（單位換算）。
- 若有人把 700 lb 視為「機器重量以外」的其他意義，判讀清單已確定為 p0，不另列。

## SD-2010-2
### (a) 題意摘要
懸臂梁 AB（A 固定、B 自由，長 L，EI 常數，梁質量不計），點質量 m 自 B 點上方 h 處靜止釋放落在 B 點並附著一起振動；求 ㈠ 振動頻率 ㈡ 最大振幅。
附圖核對（fig-2 及考卷第 1 頁目視）：A 端垂直粗線加斜線（固定）、B 端自由、h 尺寸線上端對方塊底、下端對梁線、L 由 A 至 B——**與判讀清單一致**。
### (b) 判讀表
| 項目 | 判讀 |
|---|---|
| 支承 | A 固定、B 自由 |
| 自由度 | B 點垂直位移 u（向下為正） |
| 尺寸 | L：A→B；h：方塊底→梁頂 |
| 載重 | 質量 m 自由落體，撞擊速度 v0 = √(2gh)，重量 mg 持續作用 |
| 題給參數 | EI、L、m、h（全符號）；無阻尼 |
| 所求 | ㈠ 頻率；㈡ 最大振幅（主解：繞新靜平衡位置的振幅；另列 B 點自原位置的最大撓度） |
### (c) 盲分類
主分類 SD-U1-3（單自由度自由振動、初始條件反應）；副分類 SD-U1-1（勁度、等效 SDOF）。同意索引主分類 SD-U1-3。
### (d) 解題
㈠ 懸臂端勁度 k = 3EI/L³
- ωn = √(k/m) = √(3EI/(mL³)) rad/s；fn = (1/2π)√(3EI/(mL³)) Hz；T = 2π√(mL³/(3EI))

㈡ 以新靜平衡位置為原點：δst = mg/k = mgL³/(3EI)
- 初始條件（撞擊瞬間）：u(0) = −δst，u̇(0) = √(2gh)（梁無質量，撞擊無動量損失）
- u(t) = −δst cos ωn t + (√(2gh)/ωn) sin ωn t
- 振幅 A = √(δst² + 2gh/ωn²) = √(δst² + 2hδst) = δst√(1 + 2h/δst)
  ＝ **(mgL³/3EI)·√(1 + 6EIh/(mgL³))** ＝ √[(mgL³/3EI)² + 2mghL³/(3EI)]
- B 點自原未變形位置的最大撓度：u_max = δst + A = δst[1 + √(1 + 2h/δst)]
  ＝ (mgL³/3EI)[1 + √(1 + 6EIh/(mgL³))]
- 能量法核對：mg(h + u_max) = ½ k u_max² → 同式。數值例（m=10 kg, EI=2×10⁶ N·m², L=3 m, h=0.05 m）：A = 6.659 mm、u_max = 7.100 mm，以 scipy 數值積分得相同值。
- 若 h ≫ δst：A ≈ √(2hδst)；h = 0：A = δst（突加載重，動力放大 2）。
**答案彙整**
| 小題 | 答案 |
|---|---|
| ㈠ | ωn = √(3EI/mL³)；fn = (1/2π)√(3EI/mL³) |
| ㈡（主解，振幅） | A = (mgL³/3EI)√(1 + 6EIh/(mgL³)) |
| ㈡（另列，最大撓度） | u_max = (mgL³/3EI)[1 + √(1 + 6EIh/(mgL³))] |
### (e) 不確定處
- 「最大振幅」兩種解讀已並列（差一個 δst）。
- 若忽略重力造成的平衡點偏移（只取 u(0)=0、u̇(0)=√2gh），A = √(2gh·mL³/3EI)，為 h ≫ δst 的近似，不採。

## SD-2011-2
### (a) 題意摘要
汽車模擬為 SDOF 質塊 m，以並聯彈簧 k、阻尼 c 支於剛性車輪；車速 v 等速，路面 u_g(x) = u_g0 sin(2πx/L)。㈠ 運動方程式 ㈡ 共振車速 ㈢ 忽略阻尼、非共振車速之穩態反應。
附圖核對（fig-2 及考卷第 1 頁目視）：u^t 垂直向上、v 水平向右、k 與 c 並聯接平板→桿→小圓輪→路面、u_g(x) 向上——**與判讀清單一致**。
### (b) 判讀表
| 項目 | 判讀 |
|---|---|
| 自由度 | 質塊垂直總位移 u^t（向上為正） |
| 支承激振 | 彈簧／阻尼下端隨路面 u_g 運動（輪剛性、貼地） |
| 時間 | x = vt → u_g(t) = u_g0 sin Ω t，Ω = 2πv/L |
| 題給參數 | m、k、c、v、u_g0、L（全符號） |
| 所求 | ㈠ EOM ㈡ 共振車速 ㈢ c = 0 穩態 u^t |
### (c) 盲分類
主分類 SD-U1-3（支承諧和激振）；副分類 SD-U1-2（運動方程式推導）。同意索引主分類 SD-U1-3。
### (d) 解題
㈠ 質塊自由體：彈簧力 k(u^t − u_g)、阻尼力 c(u̇^t − u̇_g)
- m ü^t + c(u̇^t − u̇_g) + k(u^t − u_g) = 0
- ⇒ **m ü^t + c u̇^t + k u^t = k u_g0 sin Ωt + c u_g0 Ω cos Ωt**，Ω = 2πv/L
- 相對位移形式 u = u^t − u_g：m ü + c u̇ + k u = −m ü_g = m u_g0 Ω² sin Ωt

㈡ 共振：Ω = ωn = √(k/m) → **v_res = (L/2π)√(k/m)**（= L·fn = L/Tn）

㈢ c = 0：m ü^t + k u^t = k u_g0 sin Ωt
- **u^t(t) = u_g0 /(1 − r²) · sin(2πvt/L)**，r = Ω/ωn = (2πv/L)√(m/k)
- 即 u^t = k u_g0 /(k − m(2πv/L)²) · sin(2πvt/L)；r > 1 時與路面反相，振幅 u_g0/|1 − r²|
- 相對位移 u = u^t − u_g = u_g0 r²/(1 − r²) · sin Ωt
- 數值例（k=4×10⁴ N/m, m=1000 kg, L=10 m, v=8 m/s）：v_res = 10.07 m/s、r = 0.795、振幅 = 0.0543 m = 2.71 u_g0；scipy 積分（以穩態初始條件）得同值。
**答案彙整**
| 小題 | 答案 |
|---|---|
| ㈠ | m ü^t + c u̇^t + k u^t = k u_g0 sin(2πvt/L) + c(2πv/L) u_g0 cos(2πvt/L) |
| ㈡ | v_res = (L/2π)√(k/m) |
| ㈢ | u^t = u_g0 sin(2πvt/L) / [1 − (2πv/L)² m/k] |
### (e) 不確定處
- ㈡ 有阻尼時，嚴格的位移傳遞率峰值在 r_peak = √(√(1+8ζ²) − 1)/(2ζ)（略小於 1），相對位移峰值在 r = 1/√(1 − 2ζ²)；一般答案取 Ω = ωn，主解採此。
- 若以 x = vt + x0 起算，只差一個相位。

## SD-2012-1
### (a) 題意摘要
單層剪力屋架，k 不變、ζ = 5%；質量 m1 時 T1 = 1.2 s，m2 = m1 + 1806 kg 時 T2 = 1.4 s；反應譜 Sa = 0.2（T ≤ 0.6 s）、0.12/T（T ≥ 0.6 s）。求 ㈠ m1 ㈡ k ㈢ 兩者彈性地震力 ㈣ 兩者最大相對位移 ㈤ 結論。
附圖核對（fig-3 及考卷第 1 頁目視）：兩單跨單層屋架，樓版粗線標 m1、m2，左柱標 k，柱底短粗線——**與判讀清單一致**。
### (b) 判讀表
| 項目 | 判讀 |
|---|---|
| 支承 | 柱底固定，剛性樓版剪力屋架 |
| 自由度 | 樓版水平位移 1 個 |
| 題給參數 | T1 = 1.2 s、T2 = 1.4 s、Δm = 1806 kg、ζ = 5%、Sa 分段式（以 g 計）；g 取 9.81 m/s² |
| 所求 | ㈠ m1 (kg) ㈡ k (N/m) ㈢ V1、V2 (N) ㈣ u1、u2 (cm) ㈤ 結論 |
### (c) 盲分類
主分類 SD-U1-3（SDOF 週期、反應譜應用）；副分類 SD-U2-1（地震力／反應譜）。同意索引主分類 SD-U1-3。
### (d) 解題
㈠ T ∝ √m（k 不變）：(T2/T1)² = m2/m1 = 1 + 1806/m1
- (1.4/1.2)² = 1.36111 → m1 = 1806/0.36111 = **5,001.2 kg（≈5,000 kg）**；m2 = 6,807.2 kg
㈡ k = 4π² m1/T1² = 4π²(5001.2)/1.44 = **1.3711×10⁵ N/m**（以 m2、T2 核對相同）
㈢ T1、T2 皆 ≥ 0.6 s：Sa1 = 0.12/1.2 = 0.100；Sa2 = 0.12/1.4 = 0.08571
- V1 = Sa1 m1 g = 0.1 × 5001.2 × 9.81 = **4,906 N**
- V2 = Sa2 m2 g = 0.08571 × 6807.2 × 9.81 = **5,724 N**
㈣ u = V/k = Sa g T²/(4π²)
- u1 = 4906.2/137111.6 = 0.03578 m = **3.58 cm**
- u2 = 5723.9/137111.6 = 0.04175 m = **4.17 cm**
㈤ 結論（得分要點）：
1. 加質量使週期變長（T ∝ √m），落在反應譜下降段 Sa = 0.12/T，譜加速度降低 14%（0.1→0.0857）；
2. 但質量增加 36%，彈性地震力 V = 0.12mg/T ∝ m/T ∝ T 仍上升 16.7%（V2/V1 = T2/T1 = 1.167）；
3. 位移 u = Sa g T²/4π² ∝ T 亦增加 16.7%（4.17 vs 3.58 cm），層間變位、P-Δ 增大；
4. 故「週期變長、Sa 變小」不代表較安全；增加樓板固定載重（質量）對同一勁度結構不利，地震力與位移皆增加，設計應控制附加質量或相應提高勁度／強度。（等加速度段 T ≤ 0.6 s 時則 V ∝ m，增幅更大。）
**答案彙整**
| 小題 | 答案 |
|---|---|
| ㈠ m1 | 5,001 kg（≈5,000 kg） |
| ㈡ k | 1.371×10⁵ N/m |
| ㈢ V1／V2 | 4,906 N／5,724 N |
| ㈣ u1／u2 | 3.58 cm／4.17 cm |
| ㈤ | 加質量→T 增、Sa 減，但 V 與 u 皆增 16.7%（∝T），對結構不利 |
### (e) 不確定處
- g 取 9.80 時 V1 = 4,901 N、V2 = 5,718 N；u 不受 g 影響（u = Sa g T²/4π² 中 g 已用到，若 g=9.8 則 u1=3.575 cm、u2=4.170 cm，差 <0.1%）。
- 若 m1 取整 5,000 kg：k = 1.3708×10⁵ N/m，V1 = 4,905 N，V2 = 5,723 N（g=9.81），差異可忽略。
- 若把 Sa 解為 m/s²（不乘 g），V 將小 9.81 倍、位移 0.365／0.426 cm，與「係數」文義不合，不採。

## SD-2013-4
### (a) 題意摘要
三個集中質量的懸臂塔（太空火箭塔台簡化），底部固定，節點高 15、30、40 m。題給前兩振態 ω = {5, 12} rad/s、Φ = [1, 1; 0.5, −0.8; 0.25, −0.6]（列序：頂、中、下）。地表加速度 $\ddot v_g = A\sin\bar\omega t$，A = 1.5 m/s²，ω̄ = 8 rad/s；忽略阻尼，只取前兩振態的穩態反應，求底端最大彎矩。塔身重 10 Tf/m。

### (c) 盲分類

### (d) 解題
運動方程式 $M\ddot u + Ku = -M\mathbf 1\ddot v_g$，$u=\Phi q$：
$\ddot q_n+\omega_n^2 q_n = -\Gamma_n A\sin\bar\omega t$，$\Gamma_n = L_n/M_n$，$L_n=\phi_n^TM\mathbf1$，$M_n=\phi_n^TM\phi_n$。
無阻尼穩態：$q_n(t) = \dfrac{-\Gamma_n A}{\omega_n^2-\bar\omega^2}\sin\bar\omega t$。
等效靜力（彈性力）$f_n = K\phi_n q_n = \omega_n^2 M\phi_n q_n$；底彎矩 $M_b(t) = \sum_n \sum_j h_j f_{jn}(t)$。兩振態同頻率、無阻尼，相位只差正負號 → **代數相加**（非 SRSS）。

閉合式：$M_{b,\max}=\left|\sum_n \dfrac{-\Gamma_n A\,\omega_n^2}{\omega_n^2-\bar\omega^2}\sum_j m_j\phi_{jn}h_j\right|$

| 量 | 振態 1 | 振態 2 |
|---|---|---|
| $M_n$ (t) | 90.625 | 184.0 |
| $L_n$ (t) | 150 | −140 |
| $\Gamma_n$ | 1.6552 | −0.7609 |
| $1/(\omega_n^2-\bar\omega^2)$ (s²) | −0.025641 | +0.0125 |
| $q_n$ 振幅 (m)（sin ω̄t 的係數） | +0.06366 | +0.01427 |
| $f_n$ 頂/中/下 (kN) | 79.58 / 99.47 / 59.68 | 102.72 / −205.43 / −184.89 |
| $M_{b,n}$ | +7062 kN·m（719.9 tf·m） | −4828 kN·m（−492.1 tf·m） |

$M_b(t) = (7062-4828)\sin\bar\omega t = 2234.6\sin 8t$ kN·m

**答案彙整**
| 小題 | 答案 |
|---|---|
| 底端最大彎矩 | **≈ 2235 kN·m ≈ 227.8 tf·m** |

**振態正交性檢查（交辦項）**：採 M = diag(50,125,150) t 時
$\phi_1^TM\phi_2 = 50(1)(1)+125(0.5)(-0.8)+150(0.25)(-0.6) = 50-50-22.5 = -22.5$ t ≠ 0，
正規化耦合係數 $M_{12}/\sqrt{M_{11}M_{22}} = -0.174$ → 題給振態對此質量矩陣**不正交**。另 $\Phi\Gamma = \{0.894, 1.436, 0.870\}$，與 {1,1,1} 差很多（3 自由度只取 2 振態本來就不會等於 1，但第 2 列 1.436 顯示截斷/不一致誤差大）。
要正交需 $m_1 = 0.4m_2+0.15m_3$（例：m₂=m₃=150 時 m₁=82.5）；從屬長度分配或「節點以上長度」分配（100,150,150：$\phi_1^TM\phi_2=+17.5$）都不滿足，可見題給 Φ 只是示意值，與塔身實際質量分布不自洽。

### (e) 不確定處與替代解讀
1. **主解法敏感度（同一質量 50/125/150）**：
   - 主解（彈性力 $K\Phi q$ 法）：227.8 tf·m（2235 kN·m）。
   - 用平衡法（總加速度慣性力 $-\sum m_j h_j(\ddot u_j+\ddot v_g)$，含截斷振態的擬靜態部分）：401.0 tf·m。
   - 考慮不正交，用耦合 Galerkin（$\Phi^TM\Phi$ 全矩陣、$K_r=\mathrm{diag}(\omega_n^2M_n)$）再以平衡法求彎矩：592.4 tf·m。

### (d) 解題
設 $v_p=G_1\sin\bar\omega t+G_2\cos\bar\omega t$，代入：
- sin 項：$(k-m\bar\omega^2)G_1-c\bar\omega G_2=P_0$

$$v_p(t)=\frac{P_0}{k}\,\frac{(1-\beta^2)\sin\bar\omega t-2\xi\beta\cos\bar\omega t}{(1-\beta^2)^2+(2\xi\beta)^2}=\rho\sin(\bar\omega t-\theta)$$
$$\rho=\frac{P_0/k}{\sqrt{(1-\beta^2)^2+(2\xi\beta)^2}},\qquad \theta=\tan^{-1}\frac{2\xi\beta}{1-\beta^2}\ (0\le\theta\le\pi)$$
動力放大係數 $D=\rho/(P_0/k)=[(1-\beta^2)^2+(2\xi\beta)^2]^{-1/2}$；β=1 時 $D=1/(2\xi)$、θ=90°。

### (d) 解題

**㈠ 證明**
1. 運動方程（相對座標）：$m\ddot v+c\dot v+kv=-m\{1\}\ddot v_g$。
2. 只取第一振態：$v(t)=\phi_1Y_1(t)$。左乘 $\phi_1^T$，利用正交性（並假設古典阻尼 $\phi_1^Tc\phi_1=2\xi_1\omega_1M_1$）：
$$M_1\ddot Y_1+2\xi_1\omega_1M_1\dot Y_1+\omega_1^2M_1Y_1=-L_1\ddot v_g,\quad \omega_1^2=\frac{\phi_1^Tk\phi_1}{M_1}$$
3. 靜止起始，Duhamel 積分：
$$Y_1(t)=\frac{1}{M_1\omega_D}\int_0^t[-L_1\ddot v_g(\tau)]e^{-\xi_1\omega_1(t-\tau)}\sin\omega_D(t-\tau)d\tau$$
$\xi_1$ 很小 → $\omega_D=\omega_1\sqrt{1-\xi_1^2}\approx\omega_1$，得
$$Y_1(t)=\frac{L_1}{M_1\omega_1}V_1(t)$$
4. 樓層彈性恢復力（等效靜力）：$f_s=kv=k\phi_1Y_1$，由特徵方程 $k\phi_1=\omega_1^2m\phi_1$：
$$f_s(t)=\omega_1^2m\phi_1Y_1(t)$$
5. 基底剪力 = 各樓層彈性力總和：
$$U_0(t)=\{1\}^Tf_s=\omega_1^2\,\{1\}^Tm\phi_1\,Y_1=\omega_1^2L_1Y_1=\omega_1^2L_1\frac{L_1}{M_1\omega_1}V_1=\frac{L_1^2}{M_1}\omega_1V_1(t)\quad\blacksquare$$
（m 對稱，$\{1\}^Tm\phi_1=\phi_1^Tm\{1\}=L_1$。）

得分要點：(i) 運動方程含 $-m\{1\}\ddot v_g$；(ii) 振態座標＋正交解耦得廣義方程；(iii) Duhamel 積分＋$\omega_D\approx\omega_1$；(iv) $k\phi_1=\omega_1^2m\phi_1$ 把彈性力化成慣性分佈；(v) $\{1\}^T$ 加總得 $U_0$。
附註：$L_1^2/M_1$ 即第一振態有效質量 $M_1^*$，$\omega_1V_1=\omega_1^2Y_1^{(SDOF)}$ 為擬加速度，故 $U_0=M_1^*A_1(t)$。基底剪力取柱剪力（彈性力），阻尼力在 $\xi_1$ 小時可忽略。

**㈡ 證明**
由 ㈠步驟 4：第 i 層水平力 $f_{si}(t)=\omega_1^2m_i\phi_{i1}Y_1(t)$；$U_0(t)=\omega_1^2Y_1(t)\sum_jm_j\phi_{j1}$。兩者相除：
$$\frac{f_{si}(t)}{U_0(t)}=\frac{m_i\phi_{i1}}{\sum_jm_j\phi_{j1}}=\frac{m_ih_i/H}{\sum_jm_jh_j/H}=\frac{m_ih_i}{\sum_jm_jh_j}$$
比值與時間無關（所有 $f_{si}$ 與 $U_0$ 都正比於同一個 $Y_1(t)$，同時達到極值），故在 $|U_0|$ 最大時刻：
$$f_{si}=\frac{m_ih_i}{\sum_{j=1}^Nm_jh_j}|U_0(t)|_{\max}\quad\blacksquare$$
此即規範等效側力豎向分配 $F_x=\frac{w_xh_x}{\sum w_ih_i}(V-F_t)$（線性振態、不含頂層集中力 $F_t$）的來源。另可得 $L_1^2/M_1=(\sum m_jh_j)^2/\sum m_jh_j^2$。

數值驗算（Python，隨機 5 層剪力構架）：直接由 $k\phi_1Y_1$ 加總之 $U_0=-8.96443$，公式 $\frac{L_1^2}{M_1}\omega_1V_1=-8.96443$（相同）；$f_s/U_0$ 與 $m_i\phi_i/\sum m_j\phi_j$ 逐層相同。

**答案彙整**
| 小題 | 結果 |
|---|---|
| ㈠ | $U_0(t)=\omega_1^2L_1Y_1=\frac{L_1^2}{M_1}\omega_1V_1(t)$（證畢） |
| ㈡ | $f_{si}=\frac{m_ih_i}{\sum m_jh_j}\lvert U_0\rvert_{\max}$（證畢） |

### (d) 解題

**㈠ 運動方程**
$$\begin{bmatrix}2m&0\\0&m\end{bmatrix}\begin{Bmatrix}\ddot v_1\\\ddot v_2\end{Bmatrix}+\begin{bmatrix}3k&-k\\-k&k\end{bmatrix}\begin{Bmatrix}v_1\\v_2\end{Bmatrix}=\begin{Bmatrix}0\\p(t)\end{Bmatrix}$$
數值：$\begin{bmatrix}4000&0\\0&2000\end{bmatrix}\ddot v+\begin{bmatrix}3\times10^5&-10^5\\-10^5&10^5\end{bmatrix}v=\{0,\ p(t)\}^T$（kg、N/m、N）。

**㈡ 頻率與振態**
令 $\lambda=\omega^2m/k$：$\det\begin{bmatrix}3-2\lambda&-1\\-1&1-\lambda\end{bmatrix}=2\lambda^2-5\lambda+2=0\Rightarrow\lambda=0.5,\ 2$。$k/m=50\ \text{s}^{-2}$：
- $\omega_1^2=25$，$\omega_1=5$ rad/s（$f_1=0.796$ Hz，$T_1=1.257$ s），$\phi_1=\{1,\ 2\}^T$
- $\omega_2^2=100$，$\omega_2=10$ rad/s（$f_2=1.592$ Hz，$T_2=0.628$ s），$\phi_2=\{1,\ -1\}^T$
（Python 驗 $K\phi-\omega^2M\phi\approx0$。）

**㈢ 解耦方程**
$v=\Phi Y$，$M_n=\phi_n^TM\phi_n$：$M_1=6m=12000$ kg、$M_2=3m=6000$ kg；$K_1=3\times10^5$、$K_2=6\times10^5$ N/m；$P_n=\phi_n^T\{0,p\}$：$P_1=2p$、$P_2=-p$。
$$12000\,\ddot Y_1+3\times10^5\,Y_1=2p(t)\qquad(\ddot Y_1+25Y_1=p/6000)$$
$$6000\,\ddot Y_2+6\times10^5\,Y_2=-p(t)\qquad(\ddot Y_2+100Y_2=-p/6000)$$

**㈣ 位移反應（近似解：衝量法）**
可用近似解的原因：$t_d/T_1=0.2/1.257=0.159$、$t_d/T_2=0.2/0.628=0.318$，脈衝延時遠短於（第一振態）或明顯短於（第二振態）自然週期，屬短時脈衝；此時最大反應發生在脈衝結束後的自由振動段（精確解中 $|Y_1|_{\max}$ 在 0.414 s、$|Y_2|_{\max}$ 在 0.257 s，均 > 0.2 s），且最大反應主要只取決於衝量 $I=\int p\,dt$，與脈衝形狀關係很小，故可視為衝量 $I=24000$ N·s 作用於脈衝形心 $t=0.1$ s。

SDOF 衝量反應 $Y_n=\dfrac{P_n\text{之衝量}}{M_n\omega_n}\sin\omega_n(t-0.1)$：
- $Y_1=\dfrac{2(24000)}{12000(5)}\sin5(t-0.1)=0.8\sin5(t-0.1)$ m
- $Y_2=\dfrac{-24000}{6000(10)}\sin10(t-0.1)=-0.4\sin10(t-0.1)$ m

$v=\Phi Y$（$t\ge0.2$ s 時適用）：
$$v_1(t)=0.8\sin5(t-0.1)-0.4\sin10(t-0.1)\ \text{m}$$
$$v_2(t)=1.6\sin5(t-0.1)+0.4\sin10(t-0.1)\ \text{m}$$
最大值（Python 掃時間）：$|v_1|_{\max}=1.039$ m、$|v_2|_{\max}=1.761$ m。（若衝量放在 t=0：$Y_1=0.8\sin5t$、$Y_2=-0.4\sin10t$，最大值相同，只是相位差 0.1 s。）
模態最大值組合參考：ABS $v_1\le1.2$、$v_2\le2.0$ m；SRSS $v_1=0.894$、$v_2=1.649$ m（本題無阻尼、兩模態頻率比 2，直接時間疊加較正確）。

**精確解核對（無阻尼）**：以 (i) 對原 2DOF 方程 solve_ivp 數值積分（rtol 1e-10）、(ii) 各模態 Duhamel 卷積兩法互核，結果一致。對稱三角形脈衝之自由振動段精確解析振幅 $=\dfrac{I_n}{M_n\omega_n}\left[\dfrac{\sin(\omega_nt_d/4)}{\omega_nt_d/4}\right]^2$，相位同樣以 $t=0.1$ 為中心：
- 模態 1 係數 $(\sin0.25/0.25)^2=0.9793$ → $Y_1=0.7835\sin5(t-0.1)$ m
- 模態 2 係數 $(\sin0.5/0.5)^2=0.9194$ → $Y_2=-0.3678\sin10(t-0.1)$ m
- 精確最大位移：$|v_1|_{\max}=0.997$ m（t≈2.197 s）、$|v_2|_{\max}=1.709$ m（t≈0.342 s）
- 近似／精確：$v_1$ 1.039/0.997=+4.2%、$v_2$ 1.761/1.709=+3.1%（衝量法略偏保守）。

### (d) 解題

**計算原理（5 分）**：

**三條正交式**（Python 展開）：
- $\phi_1^Tm\phi_2=-\alpha-2\beta+6000=0$ …(1)
- $\phi_1^Tm\phi_3=\alpha-2\beta+3000=0$ …(2)
- $\phi_2^Tm\phi_3=-\alpha+\beta+2000=0$ …(3)

**主解（依定案：(1)＋(2)）**：(1)+(2)：$-4\beta+9000=0\Rightarrow\beta=2250$ kg；代回 (2)：$\alpha=2\beta-3000=1500$ kg。
