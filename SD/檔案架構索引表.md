## 二、資料夾結構

```
SD/
├── SUBJECT.md               ← 科目層設定（子項表、分類軸現況、單位符號慣例、解題邏輯、CHANGELOG）
├── README.md                ← 冷啟動導覽
├── 知識庫使用說明書.md
├── index.html               ← 離線儀表板（暫用原 repo 版）
├── dashboard-data.js        ← 儀表板資料快照（SD_*）
├── scripts/                 ← SD 專屬腳本：講義附圖產生器 5 支＋structdraw.py、refresh-dashboard.ps1（SD 版儀表板資料）
├── 影片講義/                 ← 影片圖文講義（img/、video/）
│
├── study/                   ← 命題分析、給／背、觀念講義、頻率熱圖、problems-view/、assets/katex/
│
├── raw/
│   ├── exams/               ← SD-YYYY_結構動力分析與耐震設計.pdf（24份）＋命題大綱.pdf
│   ├── json/
│   │   ├── question_index.json   ← 題目總索引 ✏️
│   │   ├── concepts.json         ← 概念定義（備查）
│   │   ├── syllabus_taxonomy.json ← 命題大綱分類樹（副本，正本在根目錄）
│   │   └── pdf_*.txt             ← 考卷文字抽取（備查）
│   └── solutions/
│       ├── SD-YYYY-N/       ← 解析、考卷附圖、figs/
│       └── methods/         ← 解題方法論文件 ✏️（目前是 RC 殘留）
│
├── wiki/
│   └── queries/             ← 查詢結果、稽核報告、log.md（變更紀錄）
│
└── archive/
    ├── README.md            ← 封存說明
    ├── wiki/                ← 2026-11-01 封存的舊 wiki 各層（唯讀）
    └── exam-wiki-SD-root/   ← 搬入前原 repo 根目錄的 CLAUDE*.md、README.md、xcheck.py（唯讀參考）
```

> 共用腳本（render_problem_view、build_frequency、xcheck、audit_classification…）在知識庫根目錄 `scripts/`。
